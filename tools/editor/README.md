# Terra Universalis 편집기

중점(효과·위치), 디시전, 디시전 분류, 국민정신, 지도자·장군, 이벤트를 브라우저에서 만들고 고치는 도구입니다.
`terra_universalis/` 의 게임 파일을 직접 읽고 씁니다. 파이썬 표준 라이브러리만 쓰므로 따로 설치할 것은 없습니다.

## 실행 (exe)
- `tools/editor/dist/TerraEditor.exe` 를 두 번 누르면 주소창 없는 편집기 창이 뜹니다 (Edge, 없으면 Chrome 사용).
  창을 닫으면 편집기도 같이 꺼집니다. 파이썬이 없는 PC 에서도 켜집니다 (검사 실행만 파이썬 필요).
- exe 는 git 에 올리지 않습니다. 각자 `python -I tools/editor/build_exe.py` 로 만듭니다 (PyInstaller 를 알아서 설치).
- exe 는 자기 위치에서 위로 올라가며 저장소를 찾습니다. 저장소 밖에 두면 처음 한 번 폴더를 묻고 기억합니다
  (`%LOCALAPPDATA%\TerraUniversalisEditor\config.json`). 오류 기록은 같은 폴더의 `editor.log`.
- 편집기 코드(`static/`, `server.py` 등)를 고친 뒤에는 exe 를 다시 만들어야 반영됩니다.

## GitHub 패널
위쪽 `GitHub` 버튼:
- **새로 확인 / 최신 받기**: GitHub 의 새 커밋을 확인하고 받습니다 (`git pull --ff-only`). 받은 뒤 열린 파일을 다시 불러옵니다.
- **바뀐 파일**: 체크한 파일만 커밋합니다. 파일 이름을 누르면 바뀐 내용(diff)을 봅니다.
- **커밋하고 업로드**: 기본은 `editor/<이름>-<날짜>` 새 브랜치로 올리고 PR 링크를 보여 줍니다.
  권한이 있으면 `지금 브랜치(main)에 바로 올리기`도 고를 수 있습니다.
- 처음 업로드할 때 GitHub 로그인 창(Git Credential Manager)이 뜹니다. 권한이 없으면 그 이유를 한국어로 알려 줍니다.
- 편집기에 저장하지 않은 내용이 있으면 git 작업을 막습니다. 먼저 저장하세요.

## 실행 (파이썬)
- `tools/editor/run_editor.bat` 을 두 번 누르거나, 저장소 루트에서 `python -I tools/editor/server.py` 를 실행합니다.
- 브라우저에 `http://127.0.0.1:8765/` 가 열립니다. 끝낼 때는 창에서 Ctrl+C 를 누릅니다.
- 다른 포트: `--port 9000`, 브라우저 안 열기: `--no-browser`
- 특정 항목 바로 열기: `http://127.0.0.1:8765/?kind=focus&path=common/national_focus/tu_kaz.txt&sel=focus:TU_KAZ_root`

## 쓰는 법
- 위쪽 버튼으로 종류를 고르고, 왼쪽에서 파일과 항목을 고릅니다.
- **중점**: 가운데 트리에서 중점을 끌면 x/y 가 바뀝니다. 빈 곳을 끌면 화면이 움직이고, 휠로 확대/축소합니다.
  선행 중점은 한 줄에 하나씩 씁니다. 한 줄 안에 ID를 여러 개 쓰면 "그중 하나만 있으면 됨"(OR) 입니다.
- **표시 글자**: 한국어·영어 이름과 설명을 같이 고칩니다. 원래 있던 키는 그 키가 있는 yml 파일에서 고치고,
  새 키는 `localisation/<언어>/tu_editor_l_<언어>.yml` 에 추가합니다.
- **지도자·장군**: `＋ 국가 지도자 / 장군 / 원수 / 제독 / 고문` 버튼으로 역할을 붙입니다.
  새로 만든 캐릭터는 게임에서 나오려면 국가 기록에 `recruit_character` 가 있어야 합니다. 편집 화면의
  `국가 기록에 영입 추가` 버튼이 `history/countries/<태그> - ….txt` 에 그 줄을 넣어 줍니다.
- **효과 사전**: 게임 공식 문서(`documentation/*.md`)에서 효과·조건·모디파이어를 찾습니다. 이름을 누르면
  마지막으로 고르던 입력칸에 들어갑니다. 게임 폴더는 Steam 경로에서 자동으로 찾고, 못 찾으면 환경변수
  `TU_HOI4_DIR` 로 알려 줍니다.
- **검사 실행**: `tools/lint/tu_lint.py` 와 `tools/check_refs.py` 를 돌려 결과를 보여 줍니다.
- 저장은 `저장` 버튼 또는 Ctrl+S. 고친 항목만 그 글자 범위를 바꾸고, 주석·들여쓰기·나머지 항목은 그대로 둡니다.

## 주의
- **생성된 파일**: 위쪽에 노란 띠가 뜨는 파일은 생성 도구가 만든 것입니다 (`tools/focusgen/content/<태그>.py`,
  `merge_focus.py` 의 자동 배치 등). 생성 도구를 다시 돌리면 편집기에서 고친 내용이 덮어써집니다.
  편집기로 손댄 나라는 생성 도구를 다시 돌리지 않거나, 생성 원본에도 같은 내용을 반영해 주세요.
- **백업**: 저장할 때마다 원본을 `tools/editor/_backup/<시각>/` 에 복사합니다 (git 에는 올라가지 않음).
- **동시 편집**: 편집기를 연 뒤 파일이 다른 곳에서 바뀌면 저장을 거부합니다. `되돌리기` 로 다시 불러온 뒤 고치세요.
- 키 이름(디시전·국민정신·캐릭터)이나 중점 ID를 바꾸면, 그 이름을 쓰는 다른 파일은 직접 고쳐야 합니다.
- 아이콘·초상화 그림은 미리보기가 없습니다 (GFX 이름만 보입니다).

## 검사
`python -I tools/editor/test_editor.py`: 모드의 모든 항목을 "바꾼 것 없이 저장"했을 때 글자가 그대로인지,
값·블록 수정, 항목 추가·삭제, 새 중점·디시전·국민정신·캐릭터·이벤트 만들기, 이름 바꾸기, CRLF 유지를 확인합니다
(파일은 쓰지 않음).
