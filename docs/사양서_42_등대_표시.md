# 사양서 42 — 등대 패널 색과 손상 미션

> 작성·구현: Opus 5.5 · 2026-11-05 (`tools/gauges`, `tools/focusgen/content/ibe.py`)

## 1. 패널
- 해안 탭의 등대 칸은 한 줄 전체를 쓴다. 값은 불 밝힌 등대 수와 꺼져 가는(손상된) 등대 수를 함께 보여 준다.
- 칸 색: 금색 온전, 주황 손상 1단계, 빨강 손상 2단계. 뒤쪽 칸부터 물든다.
- `G(..., layers=[(색, 개수 변수)])`로 다른 수치에도 쓸 수 있다.
- 나라 변수 `TU_IBE_lighthouses`, `TU_IBE_lh_damaged`, `TU_IBE_lh_severe`는 상태가 바뀔 때 직접 더하고 빼고, 매달 `TU_IBE_lh_recount`가 다시 맞춘다. 디시전·미션 효과에서는 주 순회를 쓰지 않는다 (툴팁에 주 목록이 나온다).

## 2. 손상 미션
- 표시 디시전을 45일 미션 `TU_IBE_lh_stage1`, `TU_IBE_lh_stage2`로 바꿨다. 빨간 시간 막대가 나온다.
- 미션은 `fire_only_once = yes`로 둔다. `no`이면 취소되거나 끝난 미션이 45일에서 다시 켜져 깜빡였다. 예전 90일 미션의 되풀이도 같은 설정이었다.
  - 효과 문서: `activate_targeted_decision`은 쿨다운과 fire only once를 무시한다. 그래서 같은 등대가 다시 손상되어도 효과로 켤 수 있다.
  - 효과로만 켜는 바닐라 미션(`SPA_*_offensive_mission`, `ITA_conquer_the_north_mission`)도 `fire_only_once = yes`다.
  - 깜빡임의 정확한 엔진 동작은 문서에 없다. 플레이 화면과 위 두 근거에서 판단한 것이다.
- 대상 조건은 취소 조건의 정반대로 쓴다.
- 악화와 붕괴는 미션이 처리한다 (사양서 43).

## 3. 토벌 조건
`TU_IBE_garrison_*`는 해안 주 47개를 나열하던 것을 `ROOT = { army_manpower_in_state = { state = PREV ... } }`로 바꿔 현재 주만 본다. 툴팁은 `custom_trigger_tooltip`으로 한 줄로 보여 준다.
