# 사양서 13 — 염국 정치 루트 리메이크 (황권 강화 / 황제 축출)

> 작성·구현: Opus 5.5 · 2026-11-02
> 사용자 요구: 황권 강화 / 황제 축출 두 갈래. 황제 축출 → 쉐이 집권 → 권력 다툼 → 용의 시대(내전) → 형제 12명 + 파멸의 길 중 택일, 히든 "손에 손잡고".
> 결정: 새 이념 추가, 기존 황좌 갈래는 황권 강화 뒤에 재활용, 내전은 쉐이 형제별 분파 독립, 세부 내용은 설정에 맞춰 채움.

## 1. 새 이념 (`common/ideologies/tu_ideologies.txt`)
- `imperial_house` (황제 일가): 하위 유형 `tu_imperial_rule`(황제 친정), `tu_imperial_regency`(섭정). AI는 비동맹처럼(`ai_neutral`).
- `sui` (쉐이): 하위 유형 `tu_sui_council`(형제 합의제), `tu_sui_rule`(형제 집권), `tu_sui_awakening`(쉐이의 각성). AI는 `ai_fascist`.
- 바닐라 4개 이념은 그대로 두고 옆에 추가한다. 아이콘: `interface/tu_ideologies.gfx` + `gfx/interface/ideologies/*.dds` (모드에서 만든 40×40 그림).
- 염국 시작: 집권당 황제 일가, 지지도 황제 일가 75 / 비동맹 15 / 쉐이 10. `countries.json`의 `ruling_party`, `popularities`로 정한다 (build_countries가 새로 읽음). 황제의 지도자 이념은 `tu_imperial_rule`.
- 지지도 변화는 `<이념>_drift` 모디파이어로 넣었다. 이 모디파이어는 하루 단위라 요구한 "매주 값"을 7로 나눴다 (매주 0.1 → 0.014, 매주 0.5 → 0.071).

## 2. 중점 트리 (`tools/focusgen/yan/p1_politics.txt`)
- 군벌·근위대·신령 갈래(중점 104개)는 지웠다. 황좌 갈래는 그대로 두고 뿌리를 **황권 강화**로 바꿨다.
- **황권 강화** (`TU_YAN_p1_throne_root`): 정치력 +100, 국민정신 "황제께서 우리를 지켜주시리라"(황제 일가 매주 +0.1, 다른 이념 매주 -0.5) + 기존 황좌 국민정신. 뒤는 기존 황좌 갈래.
- **황제 축출** (`TU_YAN_p1_depose_root`): 정치력 +100, 국민정신 "새 지도자를 뽑을 때"(쉐이 매주 +0.5, 황제 일가 매주 -0.5).
  - 요구문에는 "황제일가 지지도 매주 0.5"로 부호가 없었는데, 황제를 몰아내는 갈래라 -0.5로 넣었다.
- **쉐이 집권**: 집권당 쉐이, 쉐이 지지도 +20, "쉐이 형제 회의"가 지도자, 황제 퇴위.
- **권력 다툼**: 국민정신 "형제 간의 권력 다툼"(안정도 -10%, 정치력 -20%).
- **용의 시대**: 국민정신을 "용의 시대"로 바꾸고 이벤트 `tu_yan_dragon.1` → 내전 (3장).
- **택일 13개** (서로 배타): 총웨·링·왕·더스크·슈·니엔·쥔·지에·지·이·팡·위 집권, 파멸의 길로...
  - 형제 집권: 그 형제를 지도자로 올리고 "<형제>의 치세" 국민정신. 각자 후속 중점 2개.
  - 분파로 떠난 형제는 고를 수 없다 (`TU_YAN_sib_<형제>_defected`).
  - 파멸의 길로: 쉐이 본체가 지도자, "깨어나는 쉐이" → 쉐이의 각성("모든 것을 삼키는 쉐이") → 모든 것을 삼키다. AI는 고르지 않는다.
- **히든: 손에 손잡고** (총웨 집권 뒤, `TU_YAN_hand_in_hand_unlocked` 깃발이 있어야 보임) → 열두 형제의 잔치.
- 캐릭터: 종예·니엔·시(Dusk)·링에 지도자 역할 추가, 왕·슈·쥔·지에·지·이·팡·위·쉐이 형제 회의·쉐이 새로 추가 (`common/characters/TU_YAN_sui_siblings.txt`, 초상화는 바닐라 일반 초상화).
  - 중점 이름은 요구문 표기(총웨, 더스크)를 따르고, 캐릭터 이름은 기존 번역(종예, 시(Dusk))을 유지했다.

## 3. 용의 시대 내전 (`common/scripted_effects/tu_yan_dragon_effects.txt`)
- 분파 태그 3개 `YSA`/`YSB`/`YSC` (시작 주 없음). 각 분파마다:
  1. 종예를 뺀 형제 11명 중 아직 안 고른 한 명을 무작위로 고른다.
  2. 염국 주 중 수도·수도 이웃이 아닌 주 하나와 그 이웃 염국 주를 떼어 그 분파에 넘긴다 (핵심주 포함).
  3. 분파: 쉐이 집권, 형제 이름의 외형 태그(`TU_YAN_FAC_<형제>`, 예: "니엔의 염"), 형제 지도자, 주마다 보병 사단 2개, 염국에 전쟁 선포.
- 세계에 뉴스 이벤트 `tu_yan_dragon.2`.

## 4. 히든 루트 "손에 손잡고" (`common/decisions/tu_yan_sibling_decisions.txt`)
- 요구: "내전 때 종예로 내전 중인 국가를 괴뢰국으로 만들고 다시 해방하면 디시전이 열리고, 누르면 해방한 국가를 전부 병합 + 핵심주, 히든 루트 개방".
- 디시전 분류 "쉐이 형제"는 종예 집권 + 용의 시대 뒤에만 보인다.
  - **형제를 놓아주다** (대상 디시전, 정치력 25): 괴뢰로 만든 분파를 독립시키고 표시해 둔다. 괴뢰로 만드는 것은 강화 회의에서 한다.
  - **손에 손잡고** (정치력 50): 남아 있는 분파가 모두 놓아준 분파이고 괴뢰도 아니고 전쟁 중도 아닐 때. 놓아준 분파를 전부 병합하고 그 주에 염국 핵심주를 추가한 뒤 히든 중점을 연다.

## 5. 남은 확인 (PC에서)
- 새 이념이 정치 화면·국가 선택 화면에 제대로 보이는지 (아이콘, 정당 이름, 지지도 그래프).
- 지지도 변화 속도가 의도와 맞는지 (drift 단위가 다르면 값만 고치면 된다).
- 이 모드에서 처음 쓰는 모디파이어: `planning_speed`, `navy_org_factor`, `naval_speed_factor`, `air_defence_factor`, `opinion_gain_monthly_factor`, `justify_war_goal_time`, `attrition`. error.log에 모르는 모디파이어로 나오면 바꿀 것.
- 용의 시대: 분파 셋이 제대로 생기고 수도가 잡히는지, 외형 태그 이름·국기, 분파 지도자.
- 강화 회의에서 분파를 괴뢰로 만든 뒤 "형제를 놓아주다" → "손에 손잡고"가 이어지는지.
