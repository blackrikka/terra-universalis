# 사양서 8 — 디시전 중심 외교 체계 (전 국가 공통)

> 작성: Opus 5.5 · 구현: Haiku 5.5 · 2026-10-31
> 사용자 요구: "디시전 위주로 외교를 하는 모드", "중점이 정치력을 많이 주는 만큼 활용처가 많았으면".
> 개정 2026-10-31 (사용자 지시): 압박 4종·조약 3종·종속 요구 삭제, 외교 관계 3종은 `TU_dip_relations_unlocked`, 방위 동맹은 `TU_dip_alliance_unlocked` 국가 플래그가 있어야 노출, 우호 정당 지원·불안 조장은 정당 2개 이상인 대상만, 무기 원조는 전쟁 중인 대상만 노출. 플래그를 설정하는 포커스는 아직 없다 (§7).

## 0. 원칙
- **모든 국가**(껍데기 포함)가 쓰는 공통 체계. 국가 전용 디시전(로도스 PMC, 카즈델 용병 등)은 그대로 둔다.
- 외교 행동은 **대상 지정 디시전**(targeted decision, 대상 = 국가 `FROM`)으로 한다. 정치력이 주 비용, 일부는 진행 기간(`days_remove`)이 있다.
- 기본 게임 기능만: `target_trigger`, `target_root_trigger`, `days_re_enable`(대상별 재사용 대기), `days_remove`/`remove_effect`, `diplomatic_relation`, `give_guarantee`, `add_to_faction`, `create_faction`, `set_rule`, `send_equipment`, `add_popularity`, `add_opinion_modifier`, `create_wargoal`, `add_state_claim`, `puppet`, `strength_ratio`, `add_timed_idea`. 쓰기 전에 바닐라에서 문법 확인.
- 5단계 함정 목록 준수: `country_exists = TAG`(국가 스코프 안에서는 `exists = yes`), 아이디어 `picture` 접두사 없음, 한국어 파일 PowerShell 왕복 금지, 게임 실행 금지.
- 디시전 이름은 대상 이름을 넣는다: `TU_dip_send_envoy:0 "[FROM.GetName]에 사절단 파견"` / `"Send Envoys to [FROM.GetName]"`.

## 3. 호감 수정치 (`common/opinion_modifiers/tu_opinion_modifiers.txt`)
`TU_dip_envoy` +15 (월 -1 점감), `TU_dip_trade` +20 (점감 없음, 365일 후 만료: `months = 12`), `TU_dip_culture` +10 (점감), ~~`TU_dip_tension` -25 (점감)~~ 삭제, `TU_dip_subversion` -15 (점감), ~~`TU_dip_vassal_refused` -50 (점감)~~ 삭제, `TU_dip_aid` +20 (점감). 바닐라 opinion modifier 문법(`value`, `decay`, `months` 등) 확인 후 작성.

## 4. AI
- `ai_will_do`: 관계·조약은 base 1~5(호감이 높을수록·이웃일수록 증가), 압박·공작은 base 0 + 전쟁 지지·힘 비율이 높을 때만 증가, `TU_dip_war_justification`은 매우 낮게(전쟁 남발 방지, `TU_dip_demand_vassal`은 삭제). 국정 운영은 정치력 > 150일 때 증가.

## 7. 개정 이력 (2026-10-31)
- 삭제: `TU_dip_non_aggression`, `TU_dip_military_access`, `TU_dip_guarantee`, `TU_dip_border_tension`, `TU_dip_justify_claims`, `TU_dip_demand_vassal` (디시전 블록과 로컬라이제이션 키 함께 삭제). 카테고리는 남은 디시전이 있어 유지: `TU_dip_pressure_category` (`TU_dip_war_justification`), `TU_dip_treaty_category` (`TU_dip_defense_pact`).
- 삭제된 호감 수정치: `TU_dip_tension`, `TU_dip_vassal_refused` (참조 디시전 없음).
- 노출 조건 추가 (`target_root_trigger` / `target_trigger`):
  - `TU_dip_send_envoy`, `TU_dip_trade_agreement`, `TU_dip_cultural_exchange`: ROOT에 `TU_dip_relations_unlocked` 국가 플래그.
  - `TU_dip_defense_pact`: ROOT에 `TU_dip_alliance_unlocked` 국가 플래그.
  - `TU_dip_fund_party`, `TU_dip_destabilize`: FROM에 `TU_dip_has_multiple_parties` (바닐라 이념 4종 중 2개 이상 지지율 > 0.05).
  - `TU_dip_arms_aid`: FROM이 전쟁 중 (`has_war = yes`).
- 플래그를 설정하는 포커스는 아직 추가하지 않음. 기존 포커스 후보 (읽기만 확인):
  - `TU_dip_relations_unlocked`: `TU_URS_foreign_ministry` (외무부, 정치력 +50), `TU_URS_kazimir_diplomacy`, `TU_URS_lei_diplomacy`, `TU_URS_noble_envoy_office` (정치력 +25, 이념 `TU_URS_p3_envoy_network`).
  - `TU_dip_alliance_unlocked`: `TU_URS_w4_pact_charter` (진영 `TU_URS_w4_northern_pact` 생성, KAZ/KJE/SAM 편입).
  - 위 후보는 모두 URS 포커스 트리에 있다. 다른 국가는 같은 플래그를 받을 포커스가 없으므로 국가별 포커스 보상이 따로 필요하다.
- `TU_dip_war_justification`: 조건 유지. 전쟁 중 아님, ROOT 전쟁 지지 > 0.29 (표의 ≥ 30%와 다름, 코드 기준), FROM 소유 주 중 하나가 ROOT의 영유권 요구 대상. 요구를 만드는 `TU_dip_justify_claims`가 삭제되어 이 모드 안에서는 요구를 얻는 경로가 없다.
