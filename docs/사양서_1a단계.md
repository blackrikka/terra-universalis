# 1a단계 구현 사양서 — 지도 생성기 + 합성 테스트 지도

> 작성: Opus 5.5 · 구현: Haiku 5.5 · 검증: Opus 5.5
> 목적: 테라 지도를 그리기 전에, **마스크 → HOI4 지도 전체**를 만드는 생성기를 작게 검증한다.
> 1b(테라 마스크)와 1c(본 지도)는 이 생성기를 그대로 재사용한다.

## 0. 조사로 확정한 사실 (바닐라 1.19.3 / Equestria at War 기준)

| 항목 | 사실 |
|---|---|
| provinces.bmp | 24bit RGB, 지도 크기. 크기는 가로·세로 모두 256의 배수 |
| heightmap.bmp | 8bit `L`, 지도 크기. 바다 약 89, 해수면 95, 육지 96 이상. 게임 높이 y ≈ 값/10 |
| terrain.bmp | 8bit `P`, 지도 크기, **바닐라 팔레트 그대로** 사용. 인덱스: plains 0, forest 1, hills 17, mountain 11, desert 3, marsh 9, jungle 21, urban 13, lakes 14, ocean 15, 설산(perm_snow) 16, 설원(perm_snow) 19 |
| rivers.bmp | 8bit `P`, 바닐라 팔레트. 육지 **255**(흰색), 물 **254**(회색). 강 없음 |
| cities.bmp | 8bit `P`, 바닐라 팔레트, 전부 **15** (도시 없음) |
| trees.bmp | 8bit `P`, 바닐라 팔레트, 크기 = round(지도/3.4133). 0 = 없음, 숲 6, 정글 28 |
| world_normal.bmp | 24bit RGB, **지도의 절반 크기**. 평지 = (128,128,255). R=x, G=y, B=위쪽 |
| map/terrain/*.dds | `colormap_rgb_cityemissivemask_a`(절반), `colormap_water_0/1/2`(1/2, 1/4, 1/8), `fow_rgb_waterspec_a`(절반). **비압축 32bit BGRA**: flags 0x100F, pitch = w*4, mipmapcount 1, pf flags 0x41, bitcount 32, mask R 0x00FF0000 G 0x0000FF00 B 0x000000FF A 0xFF000000, caps 0x1000 |
| 좌표계 | x = 열(col), **z = H − 1 − 행(row)** (게임은 아래쪽이 0), y = 높이맵/10 (물 위 오브젝트는 최소 9.5) |
| definition.csv | `id;r;g;b;type;coastal;terrain;continent`. 첫 줄 `0;0;0;0;land;false;unknown;0`. id는 1..N 연속. type은 land/sea/lake. 바다 terrain=ocean, continent=0 |
| 호수 | 전략 지역에는 포함하고, 주(state)에는 포함하지 않음 |
| buildings.txt | `state_id;type;x;y;z;rotation;인접바다프로빈스(없으면 0)`. 주 단위 6개, 프로빈스 단위는 소속 주 id로 표기 |
| unitstacks.txt | `province;type;x;y;z;rotation;0.00`. type 0~38, 육지·바다 프로빈스 모두 |
| supply_nodes.txt | 줄마다 `1 <province>` |
| railways.txt | `level count p1 p2 ... pn` (서로 인접한 프로빈스가 연속) |
| weatherpositions.txt | `strategic_region_id;x;y;z;small` |
| adjacencies.csv | 헤더 `From;To;Type;Through;start_x;start_y;stop_x;stop_y;adjacency_rule_name;Comment` 한 줄 |
| 시작일 | `common/defines`의 `NDefines.NGame.START_DATE` 덮어쓰기 |

## 1. 파일 배치

```
tools/mapgen/
├── mapgen.py            # 마스크 + 설정 → 지도 전체 생성 (재사용 핵심)
├── validate_map.py      # 생성 결과 정적 검사
├── build_countries.py   # countries.json + state_index.json → 국가·북마크·깃발·로컬라이제이션
├── dds.py               # 비압축 32bit DDS 쓰기 (위 헤더 사양)
├── test/
│   ├── make_test_masks.py   # 합성 테스트 마스크 생성
│   ├── regions.png          # (생성물)
│   ├── regions.json         # 지역 정의
│   └── countries.json       # TUA, TUB
└── out/state_index.json # (생성물) 주 목록 — build_countries가 읽음
```

- 모든 스크립트는 `python -I`로 실행한다. numpy 2.2, scipy 1.15, Pillow 12 사용 가능.
- 난수는 `--seed`(기본 1097)로 고정해서, 같은 입력이면 같은 결과가 나오게 한다.
- 출력 대상은 `--mod` 인자(기본 `terra_universalis`)로 받는다.

## 2. 입력 형식

**regions.png** (RGB): 색 하나가 지역 하나다. 지역은 `regions.json`에 정의한다.

```json
{
  "map_size": [512, 768],
  "regions": [
    {"color": [0,0,128], "id": "sea", "kind": "sea", "prov_size": 3000},
    {"color": [200,60,60], "id": "tua_core", "kind": "land", "owner": "TUA",
     "terrain": "plains", "prov_size": 500, "state_size": 6},
    {"color": [150,150,150], "id": "waste_imp", "kind": "impassable", "owner": "TUA",
     "terrain": "mountain", "prov_size": 1500, "state_size": 4},
    {"color": [180,160,100], "id": "waste_pass", "kind": "wasteland", "owner": "TUB",
     "terrain": "desert", "prov_size": 700, "state_size": 5}
  ],
  "strategic_land_states": 6,
  "strategic_sea_provinces": 8
}
```

- `kind`: `land`(일반 영토) / `wasteland`(통행 가능 황무지) / `impassable`(통행 불가) / `sea` / `lake`
- `terrain`: plains, forest, hills, mountain, desert, marsh, jungle, urban, snow_plains, snow_mountain

## 3. mapgen.py 처리 순서

1. **마스크 정리:** regions.json에 없는 색은 오류로 처리한다. 64픽셀 미만인 연결 성분은 둘러싼 지역 중 다수 색으로 바꾼다.
2. **프로빈스 분할** (지역의 연결 성분마다):
   - 씨앗은 포아송 디스크 방식으로 뽑는다. 반경은 `0.9*sqrt(prov_size)`, 성분마다 최소 1개.
   - 지역 내부에서만 4방향 **다중 시작 BFS**로 픽셀을 배정한다. 그래야 모든 프로빈스가 한 덩어리가 된다.
   - `prov_size*0.25` 미만인 프로빈스는 같은 지역에서 경계를 가장 길게 맞댄 이웃에 합친다.
   - **X-교차 제거:** 2×2 블록에 서로 다른 프로빈스가 4개 있으면 픽셀 하나를 이웃 색으로 바꾼다. 없어질 때까지 반복하되, 합병 때문에 연결성이 깨지면 안 된다.
3. **ID와 색:** id는 육지(land, wasteland, impassable) → 호수 → 바다 순서로 1..N을 매긴다. 색은 고유한 무작위 RGB로 정하고 (0,0,0)은 쓰지 않는다.
4. **definition.csv:** 육지 terrain은 HOI4 타입으로 바꿔 쓴다 (snow_plains→plains, snow_mountain→mountain). `coastal`은 바다 프로빈스와 4방향으로 맞닿았으면 true. continent는 육지 1, 물 0.
5. **주(state):** 같은 지역 안에서 인접 프로빈스를 `state_size`개씩 묶는다. 씨앗을 최원점 방식으로 고르고 BFS로 키운다. 주 id는 1..S로 매긴다.
   - `impassable` → `impassable = yes`, state_category `wasteland`, manpower 1000, infrastructure 0
   - `wasteland` → state_category `pastoral`, manpower 5000, infrastructure 1
   - `land` → state_category `town`, manpower 50000, infrastructure 2
   - 소유: `owner = <owner>`, `add_core_of = <owner>`
   - 주의 **중심 프로빈스**: 주 픽셀 무게중심에 가장 가까운 프로빈스. land 주는 `victory_points = { <중심> 1 }`
   - 파일: `history/states/<id>-STATE_<id>.txt` (형식은 바닐라와 동일, 탭 들여쓰기, ASCII만)
6. **전략 지역:** 육지 주를 인접한 것끼리 `strategic_land_states`개씩 묶는다 (그 주들의 프로빈스 전부). 바다와 호수 프로빈스는 `strategic_sea_provinces`개씩 묶는다. 모든 프로빈스가 정확히 하나의 지역에 속해야 한다.
   - 파일: `map/strategicregions/<id>-STRATEGICREGION_<id>.txt`
   - weather는 바닐라 `map/strategicregions/1-*.txt`의 weather 블록을 그대로 복사한다.
7. **supplyareas:** `map/supplyareas/1-SupplyArea.txt` 하나만 만든다. id=1, value=10, states={1}.
8. **보급·철도:**
   - 국가 수도 = 그 국가 land 주 가운데 면적이 가장 큰 주. 수도 주 중심 프로빈스와, land/wasteland 주 3개마다 하나씩의 중심 프로빈스에 보급 노드를 둔다.
   - 철도(level 1): 국가별로 land/wasteland 주 중심 프로빈스들의 최소 신장 트리를 만든다. 간선마다 같은 소유국의 통행 가능 프로빈스만 지나는 BFS 최단 경로로 잇는다. 경로가 없는 간선은 생략한다.
9. **높이맵:**
   - 바다는 해안 거리에 따라 94→80. 육지 기본값: plains/marsh/desert 100, forest 103, hills 112, snow_plains 104, mountain/snow_mountain 140, impassable 지역은 +40.
   - 여기에 저주파 노이즈 ±6을 더하고, 가우시안 σ=2로 흐린다. 그 뒤 육지 최소 96, 물 최대 94로 다시 고정한다.
10. **world_normal.bmp:** 높이맵 기울기로 법선을 계산해 절반 크기로 저장한다. 법선 = normalize(−dh/dx·k, −dh/dz·k, 1), k=0.5. 인코딩 (n+1)/2·255.
11. **terrain/rivers/cities/trees.bmp:** 표의 인덱스와 바닐라 팔레트를 쓴다(바닐라 파일에서 `getpalette()`로 복사).
12. **DDS 5종:**
    - colormap 육지: 바닐라 colormap을 terrain.bmp 인덱스별로 평균 낸 RGB. 바다 RGB (40,60,80). A = 0.
    - colormap_water_0/1/2: 바닐라 colormap_water_0(DXT5, Pillow로 읽기 가능)의 바다 픽셀 평균 RGBA로 채움.
    - fow_rgb_waterspec_a: 바닐라 파일의 전체 평균 RGBA로 채움.
13. **buildings.txt, unitstacks.txt, weatherpositions.txt:** 0절 형식대로 만든다.
    - 위치는 프로빈스의 **경계에서 가장 먼 픽셀**(거리 변환)이다. 주 단위 건물은 그 주 안의 무작위 내부 픽셀.
    - 해안 건물(coastal_bunker, naval_base_spawn, naval_headquarters, naval_supply_hub, floating_harbor)은 바다와 맞닿은 해안 픽셀에 두고, 마지막 칸에 그 바다 프로빈스 id를 쓴다.
    - 주 단위 종류와 개수: arms_factory 6, industrial_complex 6, air_base 1, anti_air_building 3, fuel_silo 1, nuclear_reactor_spawn 1, radar_station 1, rocket_site_spawn 1, stronghold_network 1, synthetic_refinery 1, 해안 주는 dockyard 1
    - 프로빈스 단위 종류(육지 전부): bunker, supply_node, special_project_facility_spawn
    - unitstacks: type 0~38을 모두 같은 지점에 두고 rotation 0
14. **기타 map 파일:**
    - `adjacencies.csv`: 헤더만
    - `adjacency_rules.txt`, `ambient_object.txt`, `positions.txt`: 빈 파일
    - `continent.txt`: `continents = {\n\tterra\n}`
    - `default.map`, `seasons.txt`, `colors.txt`, `cities.txt`: 만들지 않음 (바닐라 사용)
15. **출력물:**
    - `tools/mapgen/out/state_index.json`: 주 목록 `[{id, owner, kind, provinces, center, coastal}]` + 국가별 capital_state
    - 로컬라이제이션 `localisation/{korean,english}/tu_map_l_{korean,english}.yml`: `STATE_n` ("주 n" / "State n"), `STRATEGICREGION_n` ("전략 지역 n" / "Strategic Region n"), `VICTORY_POINTS_<prov>` ("거점 <prov>" / "Point <prov>"), `terra` ("테라" / "Terra"). UTF-8 BOM 필수
16. 생성 전에 mapgen이 만드는 출력 폴더(`map/`의 해당 파일, `history/states/`, `map/strategicregions/`, `map/supplyareas/`, `tu_map_*.yml`)는 비운 뒤 다시 쓴다. 그 밖의 모드 파일은 건드리지 않는다.

## 4. 합성 테스트 마스크 (make_test_masks.py)

- 크기 512×768, 테두리 24px 이상은 바다
- 노이즈 섞인 큰 대륙 하나 (육지 약 45%) + 작은 섬 하나
- 대륙 서쪽은 TUA land(plains, 북쪽 일부 forest), 동쪽은 TUB land(hills, 남쪽 일부 desert)
- 가운데에 남북으로 통행 불가 산맥(impassable, owner TUA)을 두고, 그 사이에 폭 약 40px짜리 통행 가능 황무지 회랑(wasteland, owner TUB)을 하나 낸다
- 섬은 TUB land(jungle)
- 지역 7개 정도. regions.json도 함께 생성한다

## 5. build_countries.py

`countries.json`:

```json
[
  {"tag":"TUA","name_ko":"테스트 서국","name_en":"Test West","adj_ko":"서국","adj_en":"Western","color":[200,60,60]},
  {"tag":"TUB","name_ko":"테스트 동국","name_en":"Test East","adj_ko":"동국","adj_en":"Eastern","color":[60,90,200]}
]
```

생성할 파일:
- `common/country_tags/00_countries.txt`: `TUA = "countries/TUA.txt"` 형식. 바닐라 `common/country_tags/zz_dynamic_countries.txt`는 그대로 복사
- `common/countries/<TAG>.txt`: graphical_culture = western_european_gfx, graphical_culture_2d = western_european_2d, color = rgb { r g b }
- `common/countries/colors.txt`: 국가마다 `TAG = { color = rgb {..} color_ui = rgb {..} }`
- `history/countries/<TAG> - <name_en>.txt`:
  - capital = state_index의 capital_state
  - set_research_slots = 3
  - set_politics = { ruling_party = neutrality last_election = "1096.1.1" election_frequency = 48 elections_allowed = no }
  - set_popularities = { neutrality = 100 }
- `common/bookmarks/tu_bookmarks.txt`: name TU_BOOKMARK_1097_NAME, desc TU_BOOKMARK_1097_DESC, date = 1097.1.1.12, picture = "GFX_select_date_1936", default_country = "TUA", default = yes, 모든 태그를 `TAG = { history = "OVERVIEW_TAG" ideology = neutrality }`로 나열
- `common/defines/tu_defines.lua`: `NDefines.NGame.START_DATE = "1097.1.1.12"`, `NDefines.NGame.END_DATE = "1120.1.1.1"`
- 깃발 `gfx/flags/<TAG>.tga` 82×52, `gfx/flags/medium/<TAG>.tga` 41×26, `gfx/flags/small/<TAG>.tga` 10×7: 32bit 단색 TGA
- 로컬라이제이션 `tu_countries_l_{korean,english}.yml`: TAG, TAG_DEF, TAG_ADJ, TAG_neutrality, TAG_neutrality_DEF, TAG_neutrality_ADJ, OVERVIEW_TAG, TU_BOOKMARK_1097_NAME ("테라력 1097년" / "Terra Year 1097"), TU_BOOKMARK_1097_DESC

## 7. validate_map.py — 정적 검사 (전부 통과해야 완료)

1. 이미지 크기: provinces/heightmap/terrain/rivers/cities = 지도 크기, world_normal = 절반, trees = round(/3.4133), DDS 크기와 헤더가 0절 사양과 일치
2. provinces.bmp의 고유 색 집합과 definition.csv(0번 제외)가 1:1로 맞고, id는 1..N 연속
3. 모든 프로빈스가 4방향 연결 기준으로 한 덩어리
4. X-교차 0개
5. land 프로빈스는 정확히 1개 주에 속하고, 바다·호수 프로빈스는 어느 주에도 속하지 않음. 주 id는 1..S 연속
6. 모든 프로빈스가 정확히 1개 전략 지역에 속함
7. coastal 플래그가 픽셀 인접 관계와 일치
8. 철도에서 연속한 프로빈스는 실제로 인접하고, 보급 노드는 land 프로빈스에 있음
9. buildings: 모든 주에 주 단위 종류가 다 있고, 모든 land 프로빈스에 bunker가 있음. unitstacks: 모든 land·sea 프로빈스에 type 0~38이 다 있음. 모든 좌표가 지도 범위 안이고, 해당 좌표 픽셀이 그 프로빈스(또는 그 주)에 속함
10. 높이맵: 모든 land 픽셀 ≥ 96, 모든 물 픽셀 ≤ 94
11. 모든 주의 owner가 countries.json에 있음
12. `tools/lint/tu_lint.py`가 errors=0

출력: `MAPCHECK ok` 또는 `MAPCHECK FAIL` + 항목별 오류. 종료 코드 0/1.
