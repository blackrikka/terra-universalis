# 사양서 34 — 힘의 균형(세력 균형, Balance of Power) 시스템 삭제

> 작성·구현: Opus 5.5 · 2026-11-05
> 사용자 요구: "모든 나라에서 힘의균형 시스템을 없애자"

## 1. 지운 것
- `common/bop/` 5개 파일: 우르수스(황제파·구귀족파 등), 빅토리아(대공·아슬란), 로도스 아일랜드(아미야·박사), 카시미어(상업 연합회·기사), 이베리아(심판소·왕관).
  - `descriptor.mod`의 `replace_path="common/bop"`은 그대로 둔다. 따라서 바닐라 세력 균형도 불러오지 않는다.
- 국가 history의 `set_power_balance` 5개, 중점·디시전·이벤트의 `add_power_balance_value` 339개.
- 세력 균형 이름·단계 현지화 키, 설명문의 "BoP가 …쪽으로 기운다" 문장.

## 2. 대신한 것
- 세력 균형 단계 조건이 걸려 있던 노선 끝 중점 4개는 조건 없이 고를 수 있다. 서로 상호 배타라 노선은 하나만 고를 수 있다.
  - 이베리아: 심판관의 나라, 왕관의 부활
  - 카시미어: 주주의 나라, 기사의 나라
- 이벤트 "심판관의 과잉 진압"(tu_ibe_ev.31)의 조건: 심판소 2단계 이상 → 중점 "신앙 법" 완료.
- 세력 균형만 움직이던 선택지·디시전에는 작은 효과를 넣었다.

| 대상 | 새 효과 |
|---|---|
| tu_ibe_ev.22 왕관을 지지한다 / 심판소의 판단을 따른다 | 정치력 +25 / 안정도 +2% |
| tu_ibe_ev.24 거절한다 | 안정도 +2% |
| tu_ibe_ev.34 무시한다 | 안정도 +1% |
| tu_kaz_ev.1 연합회 / 기사도 | 정치력 +20 / 전쟁 지지도 +2% |
| tu_urs_ev.13.b 교역로를 통행료로 묶다 | 정치력 +15 |
| tu_urs_ev.25.c 답을 미루다 | 정치력 +10 |
| 빅토리아 디시전 대공 연회 / 대공 회담 / 아슬란파 회유 | 안정도 +3% / 안정도 +3% / 전쟁 지지도 +3% |

- 세력 균형 단계 보너스(안정도·정치력·공격력 등)는 사라졌다. 각 노선의 국민정신과 중점 보상은 그대로 남는다.

## 3. 생성기
- `content_lib.set_bop()`은 아무것도 만들지 않는다.
- 효과 목록의 빈 문자열은 `ind()`가 건너뛴다.
- `content/kaz.py`의 `U`/`K`, `content/ibe.py`의 `INQ`/`CROWN`은 빈 효과를 돌려준다.
- 중점 부품 파일(`tools/focusgen/{urs,vic,rho,ibe,kaz}/*.txt`)과 `tools/mapgen/country_history`에서도 같은 블록을 지웠다. 다시 생성해도 세력 균형이 돌아오지 않는다.

## 5. 추가 정리 (사용자 보고: "이베리아에 권력의 균형이 남아있어")
- 이베리아 디시전 분류 "심판소와 왕관"이 남아 있었다. 원래 세력 균형을 양쪽으로 밀던 디시전 7개가 효과만 빠진 채 남아 있었다:
  심판소 설교, 왕관 지지 집회, 이단 재판, 왕실 순행, 귀족 과세, 왕실 혼사, 심판소 감사.
  - 7개와 분류를 지웠다.
  - 사단을 만드는 "심판관 모집"은 "해안" 분류로 옮겼다. 이베리아 디시전은 27개에서 20개가 되었다.
- 카시미어 "연합회와 기사" 분류("저울을 움직인다")는 "카시미어 정무"로 바꿨다.
  - 이제 효과가 0인 "연합회 로비 수용"(정치력 25를 내고 25를 받음)은 지웠다.
- 로도스·우르수스·빅토리아 설명문의 "균형이 …쪽으로 기웁니다 / the balance tilts …" 문장 25개를 지웠다.
- 모드 폴더를 덮어쓰기로 갱신하면 지운 파일이 PC에 남는다. 설치된 모드의 `common/bop` 폴더가 남아 있으면 지운다.
  git pull로 갱신하면 자동으로 지워진다.
