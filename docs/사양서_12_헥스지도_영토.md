# 사양서 12 — 헥스 지도 기준으로 국가 영토 다시 그리기

> 작성·구현: Opus 5.5 · 2026-11-02
> 사용자 요구: Arknights Fandom Wiki의 헥스 지도(`reference/Terra_hex_map_fandom.png`)대로 영토를 수정.
> 결정: 회색 땅 = 회색 중립국 소유 + 통행 불가. 국가 색은 기존 유지.

## 1. 바뀐 것
- **국가 영토**: 손으로 그린 다각형(`COUNTRY_POLYS`) 대신 헥스 지도의 색칠된 헥스를 쓴다 (`extract_masks.py`의 `HEX_COUNTRIES`).
  - 헥스 지도(821×1024)를 참고 지도에 겹치는 정렬값 `HEX_AFFINE`은 두 지도 육지 마스크의 IoU를 최대화해 구했다 (IoU 0.80).
  - 해안선·호수·지형은 예전처럼 고해상도 참고 지도(`Terra_world_map_redrawn_v.3.png`)를 쓴다.
  - 국가 헥스 위의 흰 글자·문장은 그 국가로 채운다. 헥스 지도에서는 바다지만 참고 지도에서는 육지인 해안은 헥스 1칸 거리 안이면 가까운 국가.
  - 국가에 닿은 회색 조각이 헥스 약 2칸보다 작으면 그 국가 땅 (헥스 사이 틈).
- **회색 땅**: 전부 통행 불가, 새 중립 태그 `WLD`(무주지 / Terra Wilds) 소유. 국가 선택 화면에 나오지 않는다 (`countries.json`의 `"filler": true`).
  - HOI4는 수도가 통행 불가 주면 곤란하므로, 어느 나라와도 붙지 않은 남쪽 외딴 섬 하나(`FILLER_CAPITAL_ISLAND`)만 통행 가능 땅으로 두고 WLD 수도로 쓴다.
  - 공통 외교 디시전 8개의 대상에서 WLD를 뺐다 (`tu_diplomacy_decisions.txt`).
  - 빙원·미지 영역은 눈 지형, 푀엔 열지는 사막 지형 (헥스 지도의 흰색/검은색, 갈색 헥스).
- **헥스 1칸뿐인 나라**: 카즈델은 수도와 정박지 두 주가 들어가야 해서 헥스 주변으로 조금 넓혔다 (`KZD_GROW_REF`). 크제라그·라테라노·미노스는 그림대로 아주 작다. 시에스타 헥스는 빅토리아 땅.
- **이름 있는 주·정박지 점**: 소유국 땅 밖에 있으면 그 나라의 가장 가까운 땅으로 옮긴다 (`resolve_owned`). 용문은 염국 땅에서 떼어 낸다.

## 3. 헥스 프로빈스 (사용자 요구: "프로빈스를 전부 육각형으로", 해안선은 유지, 바다도 같은 크기)
- 헥스 지도의 헥스 격자를 측정했다: 위가 뾰족한 정육각형, 가로 간격 9.846px, 행 간격 8.525px, 0행 0열 중심 (2.3, 6.5) (`HEX_LATTICE`). 헥스 사이 밝은 틈을 기준으로 맞췄다.
- 게임 픽셀마다 이 격자의 가장 가까운 칸을 정해 `tools/mapgen/terra/hexcells.png`(칸 번호를 RGB로)에 쓴다. 헥스 1칸 ≈ 게임 1,258px.
- 칸 안의 육지는 다수결로 지역(나라·지형) 하나가 되어, 국경이 헥스 경계를 정확히 따른다. 바다·호수와 해안선은 픽셀 단위 그대로.
- `mapgen.py`: config에 `cells`가 있으면 무작위 분할 대신 (지역 성분 ∩ 칸)을 프로빈스로 쓴다 (`split_by_cells`). 해안선 때문에 칸이 갈라진 조각과 작은 조각은 기존 규칙(면적 25% 미만 합병, X-교차 제거)으로 정리.
- 결과: 프로빈스 10,682개 (육지 4,529, 바다 5,916, 호수 237), 주 621개. 통행 불가 주는 프로빈스 30개, 바다 전략 지역은 프로빈스 120개 단위.
- 이름 있는 주·정박지 점은 칸 판정 뒤에 소유국 육지 칸의 중심으로 다시 놓는다 (서로 다른 칸, 해안에 잘린 작은 칸 제외).

## 4. 국가끼리 육지로 다 이어지게 (사용자 요구: "모든 나라가 최소 1개 이상 인접하게")
- 헥스 지도대로면 이베리아·크제라그·카즈델·라테라노·미노스·림 빌리튼·사르곤이 어느 나라와도 붙지 않고, 나머지도 4개 덩어리로 나뉜다.
- `connect_countries`: 국가 인접 그래프가 하나의 덩어리가 될 때까지, 덩어리 사이 가장 짧은 무주지 칸 길을 국가 땅으로 바꾼다. 길의 앞 절반은 출발 국가, 뒤 절반은 도착 국가 (두 나라가 직접 맞닿음).
- 길과 양 끝 칸은 육지가 칸의 60% 이상인 칸만 쓴다 (`CORRIDOR_MIN_LAND`). 해안에 걸친 칸으로 이으면 실제 지도에서 끊어졌다.
- 연 통로 10개 (칸 수): 우르수스–염국 1, 우르수스–라이타니엔 1, 염국–카즈델 1, 미노스–사르곤 1, 카시미어–크제라그 2, 크제라그–컬럼비아 2, 시라쿠사–림 빌리튼 2, 사르곤–이베리아 2, 컬럼비아–미노스 3, 빅토리아–라테라노 3.
- 결과 확인: 최종 provinces.bmp에서 통행 가능한 국가 프로빈스끼리의 인접으로 모든 국가(WLD 제외)가 하나로 이어짐.
- 한 나라 안의 떨어진 조각(사르곤·컬럼비아 등의 흩어진 헥스)은 그대로 둔다.

## 5. 빌드 도구 수정
- `tools/mapgen/make_vanilla_shim.py` (새 파일): 바닐라 설치가 없는 환경에서 모드 산출물로 대체 바닐라 폴더를 만든다. `build_terra.py --vanilla <폴더> --skip-check-refs`로 쓴다.
  - 대체 폴더를 쓰면 validate 17번(초상화 GFX가 바닐라에 정의됐는지)은 실질적으로 검사되지 않는다. 실제 PC에서 다시 돌릴 것.
- `mapgen.py`: X-교차 제거가 마지막 라운드에 끝난 경우를 실패로 보던 문제 수정, 최대 라운드 200 → 1000.
- `extract_masks.py`: 통행 불가 지역의 가는 지형 띠 정리, 지역 마스크에서 대각선으로만 닿는 모양 제거 (둘 다 X-교차가 풀리지 않는 원인이었음).

## 6. 남은 확인 (PC에서)
- 프로빈스 1만 개 규모에서 게임 속도·불러오기 시간.
- 게임 시작·국가 선택 화면에 WLD가 안 나오는지, 정치 지도에서 회색 땅이 무주지 색으로 보이는지.
- `check_refs.py`(바닐라 documentation 필요)와 validate 17번.
- AI가 WLD 수도 섬을 상륙전으로 점령하면 강화 회의에서 통행 불가 땅을 넘겨받을 수 있다. 문제가 되면 WLD에 전쟁 선포 불가 처리를 추가한다.
