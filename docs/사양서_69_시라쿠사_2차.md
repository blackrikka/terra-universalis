## 1. 패밀리 장치 정리: 집권 패밀리와 경쟁 패밀리
예전에는 루트를 고른 뒤 세 패밀리 영향력 수치가 거의 쓸모가 없었다.
- 루트를 고르면 그 패밀리가 **집권 패밀리**: 영향력 100 고정, 거래·단속 대상에서 빠진다. (법·늑대 루트는 세 패밀리 모두 경쟁자)
- **경쟁 패밀리**는 매달 +1. 60 이상이 되면 '패밀리 전쟁' 이벤트가 반복된다 (집권 패밀리가 100 이라 경쟁자 하나만 60 을 넘어도 터진다).
- 새 디시전 **'<패밀리> 굴복시키기'** (정치력 75, 영향력 20 이하): 그 패밀리는 0 으로 고정되고 다시 자라지 않는다.
  보상: 벨로네 민간 공장 2 / 감비노 인력 2만·경험치 30 / 살루초 정치력 150·연구 보너스.
- 루트마다 마지막 **통일 중점** (결말 뒤, 경쟁 패밀리를 모두 굴복시켜야 함): 국민정신 '하나의 시라쿠사'
  (안정도 +10%, 정치력 +10%, 조직력 +5%, 전쟁 지지 +5%), 오메르타 제거.

## 2. 디시전 분류 '집권 사업': 루트별 3개
| 루트 | 디시전 |
|---|---|
| 벨로네 | 건설 수주 (인프라, 120일 건설 +15%) / 신도시 누오바 볼시니 (180일 민간 공장 2개 사용 → 공장 3·수도 칸 +3) / 벨로네 채권 (정치력 +100, 소비재 +3%) |
| 감비노 | 행동대 소집 (정예 사단 1) / 보호비 징수 (정치력 +80, 안정도 -3%) / 구역 확장 (결말 뒤, 이웃에 병합 명분) |
| 살루초 | 살루초 은행 지점 (나라 대상, 영토 밖 민간 공장 +1, 4곳까지) / 카지노 수익 재투자 (민간 공장) / 연구 후원 |
| 법 | 공개 재판 (법 +10) / 패밀리 자산 몰수 (법 60, 민간 공장, 세 패밀리 -5) / 법 집행관 양성 |
| 늑대 | 사냥의 밤 (전쟁 지지·경험치) / 늑대 무리 소집 (기병 사단 1) / 늑대 군주의 가호 (90일 공격 +10%) |

새 사단 틀: `TU_SIR_enforcers` (보병 6 + 포병 1), `TU_SIR_wolf_pack` (기병 4 + 보병 2 + 포병 1) — 둘 다 10폭 (tools/templates.py).

## 3. 이벤트
- 루트별 2개 (중점이 부른다, 선택지 2개): 새 도시의 설계도 / 건설부 장관의 죽음, 구역 다툼 / 행동대장의 야심,
  살루초의 만찬 / 장부의 구멍, 라비니아의 판결 / 증인의 죽음, 늑대의 주인의 속삭임 / 무리의 서열.
- 텍사스의 귀향 (`tu_sir_ev.27`): 루트를 고른 뒤 평균 150일. 받아들이면 텍사스가 장군·참모로 합류. (예전에는 시작부터 있었다)
- 키아베 일당의 귀향 (`tu_sir_ev.50`): '시라쿠사 군 사령부' 10일 뒤. 키아베(참모)·아오스타·브로카(장군) 합류.

## 6. 게임에서 확인할 것
- 굴복시키기 → 통일 중점이 열리는지. 집권 패밀리 수치가 100 으로 표시되는지.
- 행동대·늑대 무리 사단이 수도에 생기는지. 살루초 은행 지점의 영토 밖 공장.
- 설정 표기(누오바 볼시니, 늑대의 주인 등)가 한국 서버 번역과 다르면 알려 주면 고친다.
