# 사양서 55 — 시작 공장·사단이 지어지지 않던 문제

> 작성·구현: Opus 5.5 · 2026-11-06
> 사용자 보고: "나라별 공장 갯수가 반영이 안 되는 것 같아..."

## 1. 원인
- 체급 효과 `TU_tier_<TAG>`(사양서 51)는 게임 시작(`on_startup`) 때 `<TAG> = { TU_tier_<TAG> = yes }`로 부른다.
- 효과 안에서는 "그 주를 `ROOT`가 가지고 있으면 공장을 짓고 사단을 만든다"로 확인했다.
- 그런데 이렇게 나라 범위로 감싸 불러도 **`ROOT`는 그 나라로 바뀌지 않는다.** `on_startup`을 일으킨 쪽(플레이어 나라 등)으로 남는다.
  - 그래서 조건이 대부분의 나라에서 거짓이 되어, 공장과 사단이 지어지지 않았다.
  - 사양서 48에서 넣은 "한 번만" 깃발 때문에, on_startup이 나라마다 한 번씩 불리더라도 첫 번째 나라 것만 남는다.
- 염국 시작 효과(`TU_YAN_startup`)의 수도 옆 두 주 사단 배치 조건(`71`, `61 = { is_owned_by = ROOT }`)도 같은 문제였다.

## 2. 고친 것
- `tools/mapgen/tiers.py`: 조건을 `is_owned_and_controlled_by = <TAG>`처럼 태그를 직접 쓰게 바꿨다. 19개국 효과를 다시 생성했다.
- `common/scripted_effects/tu_yan_effects.txt`: `is_owned_by = YAN`.
- 다른 시작 효과(카즈델·로도스·우르수스·빅토리아·용문·컬럼비아)는 `ROOT`를 쓰지 않아 그대로 둔다.

## 3. 확인
- `tu_tier_effects.txt`에 `ROOT` 조건 0개. tu_lint errors=0.
- PC에서 확인할 것: 새 게임 시작 직후 각 나라의 민간·군수 공장 수와 사단 수가 사양서 51의 표와 맞는지.
  - 확인하는 법: 외교 화면에서 그 나라를 보거나, 콘솔에서 `tag <태그>`로 바꿔 생산 화면을 본다.
