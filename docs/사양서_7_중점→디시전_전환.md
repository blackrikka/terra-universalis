# 사양서 7 — 중점을 디시전으로 전환 (전 국가)

> 작성: Opus 5.5 · 구현: Haiku 5.5 · 2026-10-31
> 사용자 결정: 디시전에 맞는 중점은 **중점을 삭제**하고 디시전으로 옮긴다. 범위 = 전 국가(URS·RHO·KZD·YAN·LGM·VIC·REU).

## 1. 전환 대상 (분류 규칙)

중점의 `completion_reward`를 보고 아래 순서로 첫 번째로 맞는 분류를 정한다. **전환** 분류만 디시전으로 옮긴다.

| 순서 | 조건 (reward 안에 해당 키가 있으면) | 분류 | 처리 |
|---|---|---|---|
| 1 | set_politics, promote_character, recruit_character, create_faction, set_autonomy, end_puppet, annex_country | 정치·정체성 | 유지 |
| 2 | add_ideas, swap_ideas, remove_ideas | 국민정신 | 유지 |
| 3 | create_wargoal | 전쟁 계획 | **전환 → 확장 카테고리** |
| 4 | add_state_claim | 영토 요구 | **전환 → 확장 카테고리** |
| 5 | diplomatic_relation, give_guarantee, add_opinion_modifier | 외교 | **전환 → 외교 카테고리** |
| 6 | create_unit, add_equipment_to_stockpile | 병력 | **전환 → 건설 카테고리** |
| 7 | add_building_construction, add_offsite_building, add_extra_state_shared_building_slots, add_resource | 건설 | **전환 → 건설 카테고리** |
| 8 | 그 밖 (add_tech_bonus, add_power_balance_value, PP·안정도·경험치만) | 유지 | 유지 |

추가 제외: 트리의 **뿌리**(prerequisite 없는 중점)와 **정치 선택 4개**(TU_URS_emperor_rule, military_junta, noble_compromise, reform_path), 그리고 다른 국가 파일이 `has_completed_focus`로 참조하는 중점은 전환하지 않는다(목록으로 보고).

예상 개수: URS 137, RHO 2, KZD 2, YAN 4, LGM 1, VIC 1, REU 2.

## 2. 디시전 생성 규칙 (의미 보존)

- **디시전 id = 원래 중점 id.** 로컬라이제이션은 기존 키(`<id>`, `<id>_desc`)를 그대로 쓴다(새 키 불필요).
- `icon`: 바닐라 `GFX_decision_generic_*` 중 분류에 맞는 것 (확장 `GFX_decision_generic_military`류, 외교 `GFX_decision_generic_political_discourse`류, 건설 `GFX_decision_generic_construction`류 — 실제 존재하는 이름을 바닐라 interface에서 확인).
- `cost`: 중점 cost 5 → 25, 10 → 50, 15 → 75 정치력.
- `fire_only_once = yes`.
- `visible`과 `available`: 원래 중점의 prerequisite를 그대로 옮긴다.
  - prerequisite 블록 여러 개 = AND, 블록 안 focus 여러 개 = OR.
  - 유지되는 중점 → `has_completed_focus = X`, 전환된 중점 → `has_country_flag = TU_DEC_X`.
  - `visible`에는 prerequisite만, `available`에는 prerequisite + 원래 중점의 `available` 내용.
- `complete_effect`: 원래 `completion_reward` 전체 + `set_country_flag = TU_DEC_<id>`.
- `ai_will_do`: 원래 중점 것 (없으면 `base = 1`).
- `allowed = { original_tag = <TAG> }`.
- **상호배타**: 원래 mutually_exclusive 상대가
  - 유지 중점이면 → 디시전 `available`에 `NOT = { has_completed_focus = 상대 }`, 그리고 상대 중점의 `available`에 `NOT = { has_country_flag = TU_DEC_<id> }` 추가하고 상대의 mutually_exclusive에서 이 id를 뺀다.
  - 전환 디시전이면 → 양쪽 디시전 `available`에 `NOT = { has_country_flag = TU_DEC_상대 }`.

## 3. 남는 중점 고치기

- 유지 중점의 prerequisite가 전환된 중점 X를 가리키면: X를 **X의 prerequisite 블록 내용으로 바꾼다**(트리 선 연결용, 여러 단계 전환이면 유지 중점이 나올 때까지 거슬러 올라감). 그리고 그 중점의 `available`에 X 조건(`has_country_flag = TU_DEC_X`)을 넣어 원래 순서 요구를 보존한다(OR 블록이면 OR로).
- 모드 전체(`common/**`, `events/**`)에서 `has_completed_focus = X`(X 전환됨)를 `has_country_flag = TU_DEC_X`로 바꾼다.
- 좌표: 삭제로 생긴 빈칸은 이번에 메우지 않는다(나중 배치 단계). 단 린트 C3·C5는 통과해야 한다(place_continuous 재실행).

## 4. 파일

- 도구: `tools/focusgen/focus_to_decision.py`
  - `--dry-run`: 전환 목록(국가, id, 분류, cost)과 제외 목록을 출력만.
  - 실행: 우르수스는 **조각 파일**(`tools/focusgen/urs/*.txt`)을 고친 뒤 `merge_urs.py` 실행. 다른 국가는 `terra_universalis/common/national_focus/tu_<tag>.txt`를 직접 고친다.
  - 디시전 출력: `terra_universalis/common/decisions/tu_<tag>_converted_decisions.txt`.
  - 카테고리: `terra_universalis/common/decisions/categories/tu_converted_categories.txt` — 국가별 `TU_<TAG>_expansion_category`, `TU_<TAG>_diplomacy_category`, `TU_<TAG>_construction_category`(그 국가에 해당 디시전이 있을 때만), `allowed = { original_tag = <TAG> }`, 바닐라 아이콘. 카테고리 로컬라이제이션 `localisation/{korean,english}/tu_converted_l_*.yml` (한: "제국 확장"/"외교"/"건설·동원", 영: "Expansion"/"Diplomacy"/"Construction & Mobilisation" — 국가 이름 없이 공통 문구, 키는 국가별).
  - 실행 전 백업: 고칠 파일 전부를 `docs/_backup/focus_to_decision/` 에 복사.
- 멱등성: 이미 전환된 상태에서 다시 실행하면 바뀌는 것 없음.

## 5. 검증
- `merge_urs.py` (MERGE_URS ok), `place_continuous.py --check`, `tu_lint.py` errors=0, `--selftest`.
- 전환 전후 비교: (전환 수) + (남은 중점 수) = (원래 중점 수). 모든 전환 디시전의 complete_effect가 원래 reward를 포함. 남은 트리에 없는 id를 가리키는 prerequisite/mutually_exclusive/has_completed_focus = 0.
- 게임은 실행하지 않는다.
