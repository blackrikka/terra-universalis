# 사양서 11 — 한쪽만 짧은 중점을 성능 양자택일로 재설계

> 작성: Opus 5.5 · 구현: Haiku 5.5 · 2026-11-01
> 사용자 요구: "한쪽만 짧은 중점이 많이 보이는데, 성능으로 양자택일을 할 수 있는 중점으로 만들면 좋겠다".

## 1. 찾을 대상 (탐지 도구 `tools/focusgen/find_lopsided.py`가 자동으로 찾음)
- **A. 불균형 상호배타 쌍**: 같은 주 부모를 가진 mutually_exclusive 쌍 (A, B)에서 한쪽 하위 트리 깊이가 다른 쪽보다 2 이상 깊다 (예: B는 막다른 잎, A는 계속 이어짐).
- **B. 매달린 잎**: 상호배타가 없는 잎 중점 L이, 다른 자식이 계속 이어지는 부모 S에 매달려 있다 (줄기 옆에 혼자 붙은 짧은 가지).
- 제외: 뿌리, 정치 루트 선택 중점(국가별 4택), 다른 파일에서 has_completed_focus로 참조되는 중점은 구조를 바꾸지 말고 보상만 조정.

## 2. 고치는 방법
- **A의 경우**: 짧은 쪽 B를 진짜 대안으로 만든다.
  - A만 선행으로 하던 A의 자식들(이어지는 줄기)의 prerequisite를 `focus = A focus = B`(같은 블록 = OR)로 바꿔, 어느 쪽을 골라도 다음으로 진행되게 한다.
  - A와 B의 보상을 **같은 가치, 다른 성격**으로 맞춘다: 비용 동일, 정치력 차이 ±25 이내, 각자 뚜렷한 장점 1개 (아래 3장 짝 예시).
- **B의 경우**:
  - 같은 부모에 매달린 잎이 2개 이상이면 그중 성격이 대비되는 두 개를 상호배타 쌍으로 묶는다 (보상을 3장 규칙으로 조정).
  - 잎이 1개뿐이면 **대안 중점을 1개 새로 만들어** 상호배타 쌍으로 만든다 (id `<원래 id>_alt`, 로컬라이제이션 한·영 이름·설명 작성, 아이콘은 바닐라).
  - 두 잎이 줄기의 다음 중점 선행이 아니면 그대로 끝나도 된다 (양자택일 보너스 자체가 목적).
- 효과 종류 규칙은 기존과 같다: 중점에는 건설·외교·영토·전쟁목표·병력 생성 금지 (디시전으로). 장점은 국민정신(add_ideas 새 아이디어 또는 기존 재사용), add_tech_bonus, 경험치, 안정도·전쟁 지지, 정치력으로.

## 3. 양자택일 짝 예시 (같은 가치, 다른 장점)
| 선택 1 | 선택 2 |
|---|---|
| 산업: 공장 생산 효율 +5% 국민정신 | 군사: 육군 공격 +5% 국민정신 |
| 공세: 공격 +5% | 수세: 방어 +5% / 참호 +1 |
| 연구: 연구 속도 +3% | 생산: 건설 속도 +5% |
| 인력: 징집 +1% (conscription_factor 0.01) | 질: 경험치 획득 +10% |
| 안정: 안정도 +5% | 결속: 전쟁 지지 +5% |
| 정치: 정치력 +0.1/일 대체로 political_power_factor 0.1 | 외교: 정치력 즉시 +100 |
- 모디파이어·아이디어 그림은 바닐라에 실제 있는 것만. 아이디어는 `common/ideas/tu_<tag>_choice_ideas.txt` (국가별 새 파일), id `TU_<TAG>_choice_<이름>`.

## 4. 파일·절차
- 수정 대상은 **조각 파일**(`tools/focusgen/<tag>/*.txt`, 우르수스는 `tools/focusgen/urs/*.txt`)과 새 아이디어·로컬라이제이션 파일(`localisation/{korean,english}/tu_<tag>_choice_l_*.yml`)뿐. merge는 Opus가 한다.
- 각 국가: `find_lopsided.py --tag <TAG>`로 목록을 뽑고, 전부 처리한 뒤 다시 돌려 남은 것 0 (제외 항목은 보고).
- 검사: `merge_focus.py --tag <TAG> --check <part>` 오류 0, `tu_lint.py` 자기 파일 오류 0.
