# 사양서 41 — 바다의 위협 조정

> 작성·구현: Opus 5.5 · 2026-11-05 (`tools/focusgen/content/ibe.py`)

## 1. 월간 변화
매달 +4, 온전한 등대 하나마다 -1 (두 배). 온전한 등대가 4개면 멈추고 5개면 매달 1 내려간다.

## 2. 중점·이벤트의 위협 감소
중점과 이벤트의 감소량을 절반으로 줄였다 (소수는 올림).

| 전 | 후 |
|---|---|
| -20 | -10 |
| -15 | -8 |
| -10 | -5 |
| -5 | -3 |
| -2 | -1 |

중점 8곳, 이벤트 8곳이다. 디시전(해안 순찰, 정화 작전, 사냥꾼 지원, 경고 공유, 토벌)과 등대 복원의 -5는 그대로 두었다. 위협이 오르는 효과도 그대로다.
