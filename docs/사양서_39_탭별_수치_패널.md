# 사양서 39 — 수치 패널을 디시전 탭 안으로 옮기기

> 작성·구현: Opus 5.5 · 2026-11-05

## 1. 배경
수치 패널이 두 벌이었다.
- 사양서 22의 패널: 조건이 걸린 첫 분류에 붙어 시작할 때 안 보이고, 너비 590px이라 오른쪽이 잘렸다.
- `tu_status`의 '국가 현황': 항상 보이지만 수치를 다루는 디시전과 다른 탭에 있었다.

## 2. 바꾼 것
- 수치 패널은 `tools/gauges` 하나로 합쳤다. 수치마다 그 수치를 가장 많이 다루는 탭에 놓는다 (`countries.py`의 `TABS`).
- 별도 분류 `TU_<태그>_status_category`는 없앴다.
- 패널이 있는 탭 27개는 항상 보인다 (`visible_when_empty = yes`).
- 조건이 있던 탭 21개의 조건은 안의 디시전 166개의 `visible`로 내렸다. 중점을 찍기 전에는 탭과 수치만 보이고, 디시전은 전처럼 중점으로 열린다.
- 패널이 없는 탭은 조건을 그대로 둔다.
- `build_panels.py`에는 육상함과 용의 시대 패널만 남겼고 너비를 470px로 줄였다.
- 이베리아 `TU_IBE_restore_lighthouse`는 `on_map_mode = map_only`다. 탭 목록에 나오지 않고 지도 버튼으로만 뜬다. `content_lib`의 `d(..., map_only=True)`로 쓴다.

## 4. 빌드
수치나 탭을 바꾸면 `tools/gauges/build_gauges.py`를 돌린다. 탭 목록을 바꾸면 `tools/focusgen/content/<태그>.py`도 다시 돌린다. 카즈델·로도스의 분류 파일에는 `scripted_gui` 줄을 손으로 넣어 두었다.

눈금은 `check_variable`에서 뽑되 `common/scripted_guis`는 건너뛴다. 패널의 칸 조건을 게임 규칙으로 읽으면 눈금이 틀어진다.
