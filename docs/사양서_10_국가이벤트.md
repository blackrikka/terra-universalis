# 사양서 10 — 국가 이벤트 + 중점 이벤트 (7개국)

> 작성: Opus 5.5 · 구현: Haiku 5.5 · 2026-10-31
> 사용자 요구: "국가의 이벤트들을 추가할것, 중점에 이벤트도 추가할것".

## 0. 공통 규칙
- 5단계·9단계 사양서의 함정 목록 준수: `country_exists = TAG`, 숫자 주 스코프, 아이디어 picture에 `GFX_idea_` 없음, `news = yes` 금지(뉴스는 `news_event = { ... }` 블록 종류로), 한국어 파일 PowerShell 왕복 금지, **게임 실행 금지**.
- 모든 이벤트 `is_triggered_only = yes`. 폴링(mean_time_to_happen) 금지.
- 그림은 바닐라 `GFX_report_event_*` 중 실제 존재하는 것(interface\*.gfx grep), 뉴스는 `GFX_news_event_*` 중 존재하는 것.
- 선택지마다 `ai_chance`. 효과는 정치력·안정도·전쟁 지지·국민정신(시한 아이디어 add_timed_idea 포함)·경험치·BoP 이동·플래그. 다른 나라 대상은 country_exists로 감싼다.
- 이벤트 id: 네임스페이스 `tu_<tag>_ev` (예: `add_namespace = tu_vic_ev`, `tu_vic_ev.1`). 기존 네임스페이스(tu_rho, tu_crisis 등)와 겹치지 않게.
- 로컬라이제이션: `<id>.t`, `<id>.d`, 선택지 `<id>.a`, `.b`, `.c` — 한국어·영어 둘 다 (UTF-8 BOM, `localisation/{korean,english}/tu_<tag>_events_l_*.yml`). 설명문(.d)은 3~5문장으로 원작 분위기를 살린다.

## 1. 이벤트 종류와 개수 (국가별)
| 종류 | 발동 방법 | URS·VIC·YAN | KZD·RHO | LGM·REU |
|---|---|---|---|---|
| **중점 이벤트** | 중점 `completion_reward`에 `country_event = { id = ... }` (정치 루트 선택, 갈래 핵심 중점, 지도자 교체 중점 등 중요한 중점) | 15 | 10 | 6 |
| **뉴스 이벤트** | 루트 완성·지도자 교체 같은 큰 사건 중점에서 `every_country = { news_event = { id = ... } }` | 4 | 3 | 2 |
| **정기 이벤트** | `common/on_actions/tu_<tag>_ev_on_actions.txt`의 `on_monthly_<TAG>` 대신 `on_monthly = { random_events = { 1000 = 0 3 = tu_<tag>_ev.N ... } }` 형식(바닐라 on_actions에서 random_events 문법 확인)으로 국가 조건(`tag = <TAG>`)을 이벤트 `trigger`에 둔다. 한 번만 발생하는 것은 플래그로 막는다 | 8 | 5 | 3 |
| **연쇄 이벤트** | 이벤트 선택지에서 다른 이벤트 `days = N` 예약 (2~3단계 이야기) | 2개 체인 | 1개 체인 | 1개 체인 |

## 2. 국가별 소재 (원작 설정)
- **URS 우르수스**: 황제와 대공들의 알력, 근위대, 체르노보그 감염자, 학생자치단, 북방 원정, 리유니온.
- **VIC 빅토리아**: 공석의 왕좌, 대공 회의, 시즈와 글래스고 갱단, 더블린·타라 봉기, 론디니움 점령(카즈델), 스팀 나이트.
- **YAN 염국**: 조정과 지방관, 세(歲) 형제(니엔·시·링·종예), 용문, 대운하·이동도시, 신령 숭배.
- **KZD 카즈델**: 테레시스와 사르카즈 씨족, 육왕, 바벨의 기억, 용병 계약, 황무지.
- **RHO 로도스 아일랜드**: 아미야와 닥터, 켈시, 광석병 연구, 육상함 도약, 오퍼레이터 영입, 구호 지부.
- **LGM 용문**: 웨이옌우, 근위국(첸·호시구마·스와이어), 무역 도시, 리유니온 국지전(체르노보그 사태 플래그와 연결), 염국과의 관계.
- **REU 리유니온**: 탈룰라, 프로스트노바·패트리어트, 감염자 해방, 체르노보그 이동도시, 내부 노선 갈등.

## 3. 파일 소유 (에이전트별)
- 이벤트: `terra_universalis/events/tu_<tag>_events.txt` (신규)
- 정기 이벤트 온액션: `terra_universalis/common/on_actions/tu_<tag>_ev_on_actions.txt` (신규)
- 아이디어(이벤트용 시한 아이디어가 필요할 때): `terra_universalis/common/ideas/tu_<tag>_ev_ideas.txt`
- 로컬라이제이션: `localisation/{korean,english}/tu_<tag>_events_l_*.yml`
- **중점 조각 수정**: 중점 이벤트를 걸 중점의 `completion_reward`에 `country_event = { id = ... }`(필요하면 `news_event`) **한 줄만 추가**한다. 우르수스는 `tools/focusgen/urs/*.txt`, 다른 국가는 `tools/focusgen/<tag>/*.txt`. 다른 줄은 바꾸지 않는다. **merge는 실행하지 않는다**(Opus가 마지막에 함).

## 4. 검증
- `python -I tools\focusgen\merge_focus.py --tag <TAG> --check <part>` (수정한 조각마다) 오류 0
- `python -I tools\lint\tu_lint.py` 자기 파일 오류 0
- 이벤트 id 참조 검사: 중점·이벤트·온액션에서 부르는 모든 이벤트 id가 정의돼 있는지 스크립트로 확인해 보고.
