# 사양서 52 — 기본 편제와 전투 폭 통일

> 작성·구현: Opus 5.5 · 2026-11-06
> 사용자 요구: "추가적으로 기본편제와 넓이도 손보자"

## 1. 문제
- 시작 편제의 전투 폭이 나라마다 제각각이었다: 4, 8, 12, 13, 15, 21, 24폭.
  - B·C급 나라의 기본 보병은 보병 4개(8폭)라 전선에서 너무 약했다.
  - 육상함 전대 폭은 지형 폭과 맞지 않았다.

## 2. 규칙 (`tools/templates.py`)
- 폭: 보병·기병·경전차 연대 2, 포병 3.

| 폭 | 용도 | 편제 |
|---|---|---|
| 20 | 모든 나라의 주력 보병 | 보병 7 + 포병 2, 지원 공병·정찰 (우르수스·빅토리아는 공병·지원 포병) |
| 20 | 정예 | 우르수스 근위 사단: 보병 4·기병 2·경전차 1·포병 2 / 카즈델 정예 근위: 보병 5·기병 2·포병 2 |
| 10 | 정예·특수 | 빅토리아 스팀 나이트(보병 2·경전차 3), 용문 근위국, 로도스 오퍼레이터·호위대, 컬럼비아 블랙스틸, 이베리아 심판관, 카시미어 기사(기병 4·보병 1), 라테라노 근위대, 사르곤 용병(보병 3·기병 2), 염국 분파 근위대 |
| 20 / 30 / 40 | 육상함 | 경육상함 전대(보병 4·포병 4) / 중육상함 전대(6·6) / 도시급(8·8) |

- 10·20·30·40 단계라 한 전투에 섞어 넣기 쉽다.

## 3. 적용
- `TEMPLATES`(이름 → 연대·지원 중대)와 `LINE`(모든 `TU_<TAG>_line_infantry`)을 한 곳에 둔다.
- `apply_text()`가 `division_template` 블록을 이름으로 찾아 regiments / support를 바꾼다. 다시 돌려도 결과가 같다.
- 적용 위치:
  - `tiers.py`: 나라별 기본 보병 OOB
  - `content_lib.py`: 나라별 효과 파일 (컬럼비아·이베리아·카시미어·라테라노·사르곤 특수 부대)
  - 손으로 만든 OOB와 효과(우르수스·빅토리아·카즈델·염국·용문·로도스, 육상함, 염국 분파): `python -I tools/templates.py`로 한 번 적용
- 바뀐 편제 32개.

## 4. 그대로 둔 것
- 지형별 전투 폭(평지·숲·산 등의 combat_width)은 바닐라 값을 쓴다.
  - 바꾸려면 바닐라 `common/terrain/00_terrain.txt` 전체를 모드에 복사해 고쳐야 한다. 이 환경에는 바닐라 원본이 없어서 하지 않았다.
  - 지형 폭을 바꾸려면 바닐라 파일이 필요하다.
- 사단이 커져서(보병 6→7, 포병 추가) 사단마다 인력이 더 든다. 사양서 51에서 인구를 늘려서 보충할 수 있다.
