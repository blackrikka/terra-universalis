# 사양서 26 — 클라리사이드를 내해(바다)로, 남은 호수 섬 잇기

> 작성·구현: Opus 5.5 · 2026-11-05
> 사용자 요구: 클라리사이드는 원작 지도에서 내해가 맞다. 미개척지(황야)는 원작대로 통행 불가로 둔다.
> 결정: 클라리사이드 호수(프로빈스 78개)를 바다로 바꾸고, 그 안의 섬을 사양서 20의 해협 연결로 잇는다. 황야는 건드리지 않는다.

## 1. 문제
- 사양서 20 뒤에도 빅토리아 호수 섬 3덩어리(주 122, 123, 124·125·134)와 이베리아 호수 섬 5곳(주 202, 205, 206, 208, 209)이 본토와 떨어져 있었다.
- 모두 클라리사이드 한 호수에만 닿아 있다. HOI4의 호수 칸은 해협(`adjacencies.csv`의 sea 연결)의 Through로 쓸 수 없어서 `fix_exclaves.py`가 잇지 못했다.
- 원작 이름은 "Sea of Clariside"(내해)인데 `extract_masks.py`는 바다와 이어지지 않은 물을 모두 호수로 만든다 (`LAKE_SEEDS` 첫 번째 (430, 780)).

## 2. 바꾸는 것 (`tools/mapgen/lake_to_sea.py`, 지도 생성 뒤 · `fix_exclaves.py` 앞에 실행)
- `INLAND_SEAS`에 적은 게임 좌표(클라리사이드: 1321, 2417)의 프로빈스가 호수면, 그 호수 덩어리 전체를 바다로 바꾼다. 이미 바다면 아무것도 하지 않는다 (다시 돌려도 같다).
- `definition.csv`: 그 프로빈스들을 `sea;<coastal>;ocean;0`으로. 닿는 육지 프로빈스는 coastal = true (validate 7번 규칙).
- `terrain.bmp`: 그 프로빈스 픽셀을 lakes(14) → ocean(15).
- `unitstacks.txt`: 바다 프로빈스마다 type 0~38 (프로빈스 경계에서 가장 먼 픽셀, 높이 max(9.5, heightmap/10)). 호수에는 없던 줄이다.
- `buildings.txt`: 새로 해안이 된 육지 프로빈스마다 해안 건물 위치 5종(coastal_bunker, naval_base_spawn, naval_headquarters, naval_supply_hub, floating_harbor), 새로 해안이 된 주마다 dockyard 위치 1개. 마지막 칸은 붙어 있는 바다 프로빈스 id (mapgen.py와 같은 규칙). 해군은 사양서 18로 막혀 있으니 위치만 있다.
- 전략 지역: 클라리사이드는 이미 혼자 전략 지역 171이고 바다·호수 전략 지역의 형식은 같다. 다른 프로빈스가 섞여 있으면 도구가 멈춘다.
- heightmap은 그대로 둔다 (호수 90, 해안 바다 94 모두 물 높이 94 이하).
- 바다와 이어지지 않은 바다 덩어리가 된다. 해군이 없으니 함대 이동 문제는 생기지 않는다.

## 3. 섬 잇기
- 이어서 `python -I tools/mapgen/fix_exclaves.py`를 다시 돌리면, 바다 한 칸을 사이에 둔 같은 나라 땅끼리 해협(Type sea)을 만든다. 집 PC에서 크래시 없이 확인된 연결 형식(사양서 20의 771-766)과 같다.
- 이베리아 남쪽 바다 섬(주 212·214, 4프로빈스)은 본토까지 바다 두 칸 이상이라 이번에도 이어지지 않는다 (별도 결정 필요).

### 결과 (2026-11-05)
- `lake_to_sea.py`: 호수 78 → 바다, 새 해안 육지 79, unitstacks +3,042줄, 해안 건물 위치 +395, dockyard 위치 +51. 다시 돌리면 "이미 바다".
- `fix_exclaves.py`: 해협 8개 (기존 771-766 포함).
  - 빅토리아: 호수 섬 3덩어리 모두 본토와 연결 (463-481, 464-481, 465-460).
  - 이베리아: 클라리사이드 섬 5곳(주 202·205·206·208·209)은 서로만 연결된다. 내해 한가운데라 본토까지 바다 두 칸 이상.
- validate_map: 바꾸기 전과 오류 목록이 같다. 17번 52건은 원래 있던 것으로, 사양서 23의 캐릭터 구성(`cast`)을 검사 도구가 아직 모르는 것. tu_lint errors=0.
- 남은 이베리아 섬 두 무리(클라리사이드 5곳, 남쪽 바다 4프로빈스)는 결정이 필요하다: 그대로 둠 / 바다 두 칸 이상 해협(PC 확인 필요) / 무주지로.

## 4. 순서
`build_terra.py`(지도를 다시 만들 때) → `lake_to_sea.py` → `fix_exclaves.py` → `validate_map.py` → `tu_lint.py`

## 5. 남은 확인 (PC에서)
- 클라리사이드가 지도에 바다로 그려지는지, 섬으로 해협을 건너 부대가 걸어가는지.
- 해안이 된 주의 건설 메뉴·해안 요새에 이상이 없는지, error.log에 바다 관련 오류가 없는지.
