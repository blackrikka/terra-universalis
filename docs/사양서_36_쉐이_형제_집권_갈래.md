# 사양서 36 — 쉐이 내전: 형제 집권 갈래 늘리기

> 작성·구현: Opus 5.5 · 2026-11-05
> 사용자 요구: "염국 쉐이 내전루트에 지도자 중점 아래에 더 만들어줘"

## 1. 되살린 것
- 사양서 35의 중점 정리(`slim_focuses.py`)가 형제마다 있던 2단 갈래 24개, "삼켜진 형제"(ruin_devour), "재건"(rebuild)을 일반 중점으로 보고 부모 중점에 합쳤다.
  - 예: 링 집권 → 취중의 시 → 꿈의 정원
  - 그래서 집권 중점에 정치력 +60이 세 번 겹쳐 있었다.
- `yan/p1_politics.txt`를 정리 직전으로 되돌리고 현지화 26개를 되살렸다.
- `slim_focuses.py`는 이제 `allow_branch`로 숨겨진 갈래 아래의 중점은 합치지 않는다. 지도자 집권 갈래, 히든 갈래 등이 해당한다.

## 2. 새 갈래 (`tools/focusgen/yan_sui_rulers.py`)
형제마다 집권 → A1 → A2 → B → C1 / C2(둘 중 하나) → F, 모두 6단이다.
- A1·A2: 기존 두 중점. 이름은 그대로 두고 보상과 설명을 형제 성격에 맞게 바꿨다. 비어 있던 설명도 채웠다.
  - 지에의 "항구의 수호"는 해군이 없어서 "나루터의 수호"로 바꿨다.
- B·C1·C2·F: 새 중점 48개.
  - F는 집권 때 받은 치세 국민정신을 강화판(`TU_YAN_idea_rule_<형제>_2`)으로 바꾸고 정치력 +50을 준다.
