# 사양서 18 — 해군 기능 삭제, 국가 체급별 시작 군대·공장

> 작성·구현: 2026-11-04
> 사용자 요구: 명일방주 설정에 맞춰 해군·조선소·해군기지 기능을 전부 삭제. 국가 체급마다 시작 군대와 공장 수를 배정.

## 1. 해군 삭제

설정: 테라의 바다는 해사(Sea Terror)의 영역이라 어떤 나라도 함대를 띄우지 못한다. (이베리아·에기르 이야기는 해안 방어로 남긴다.)

### 1.1 막는 장치
- 국민정신 `TU_sea_terror` "심해의 위협" (`common/ideas/tu_world_ideas.txt`): 모든 나라가 시작부터 가짐 (build_countries 가 history 에 넣음), 없앨 수 없음.
  - `production_speed_dockyard_factor = -1`, `production_speed_naval_base_factor = -1` → 조선소·해군 기지 건설이 진행되지 않음.
  - `industrial_capacity_dockyard = -1` → (혹시 생긴) 조선소 생산 0.
- 주 history 에는 원래 조선소·해군 기지가 없다. 시작 함대도 없다.
- 해군 연구 탭은 바닐라 기술 파일이라 남지만, 배를 지을 곳이 없으므로 쓸모가 없다.

### 1.2 중점 정리
- 군함·조선소·해군기지 중점은 트리에서 지운다: `theme_effects.WARSHIP_RE`
  (naval, navy, fleet, battleship, cruiser, destroyer, submarine, carrier, torpedo, gunboat, galley, dockyard, shipyard,
  marine corps, amphibious, landing force, ironclad, wolfpack … / 비행선 airship 과 로도스 아일랜드(육상함 도크)는 제외).
- 지운 중점의 앞뒤는 다시 잇는다 (`tools/focusgen/focus_drop.py`): 선행 블록이 비면 지운 중점의 선행을 대신 넣고,
  양자택일에서 빼고, `has_completed_focus = <지운 중점>` 은 남는 조상으로 바꾼다.
  - 13개국(content 트리): `content_lib.Country.write` 가 자동으로.
  - 기존 7개국 트리 조각: `python -I tools/focusgen/drop_focuses.py --tag <TAG>`.
  - 공통 트리 `generic.txt`: 해군 갈래 8개 (naval_effort ~ NAV_effort) 삭제.
- 지운 수: 빅토리아 26, 미노스 17, 극동 14, 이베리아 13, 컬럼비아 11, 시라쿠사 6, 염국 6, 우르수스 4, 카즈델 2, 볼리바르·림·용문 1, 공통 8.
- 테마: navy → `harbour` (항구·해안·해협·바다 이름) = 정치력 + 산업 연구. 해군 경험치·구축함/순양함 연구·해군 교리 할인은 어디에도 없다.
  옛 navy 정규식이 Citizenship·Seal·Doctors·Portrait 를 잘못 잡던 것도 고침.

### 1.3 그 밖
- `TU_build_dockyard` 효과 삭제 → 쓰던 곳은 `TU_build_civ_factory`.
- 디시전의 조선소/해군 기지/해군 시설 건설 → 민간 공장 또는 기반시설 (이름·설명도 바꿈).
- 국민정신의 해군 모디파이어 → 육군·생산·해안 요새 모디파이어. 해군 전용 국민정신(대함대 등) 삭제.
- 미노스: "함대 건조법" → "항만 건설법", "호위 함대 파견" → "상단 호위대 파견" 등 이름 정리.

(레유니온은 시작 땅이 없고, 쉐이 12국·황야는 내전/특수 태그라 뺐다.)

- 공장: 시작할 때(`on_startup`, `tu_tier_on_actions.txt`) `TU_tier_<TAG>` 가 수도에 절반, 인력이 큰 주 최대 3곳에 나눠
  공유 슬롯을 늘리고 즉시 짓는다. 지도 생성 때 수도마다 들어간 민간 2·군수 1 은 합계에 포함.
- 사단: 같은 주들에 `create_unit`. 이미 시작 효과로 사단을 만드는 6개국(우르수스 8, 빅토리아 12, 카즈델 6, 염국 10, 용문 3, 로도스 3)은 모자란 만큼만.
  OOB 가 없던 13개국은 `history/units/<TAG>_1097.txt` 에 보병 틀(S·A: 보병 6 + 포병, B·C: 보병 4, 지원 공병·정찰).
- 시작 기술 (전에는 어떤 나라도 기술이 없어 장비를 만들 수 없었다): 체급별로 보병 장비, 지원·공병·정찰, 포병,
  (A 이상) 전차·전투기·차량화, (S) 폭격기·연료 저장소, 기초 공작 기계.
- `tools/mapgen/tier_history/<TAG>.txt` 를 build_countries 가 history/countries 끝에 붙인다 (연구 슬롯, 기술, oob).
- 순서: `tiers.py` → `build_countries.py`.

## 3. 남은 확인 (PC에서)
- 시작 직후 공장 수·사단 수가 표와 맞는지, 사단 장비가 채워지는지.
- 조선소·해군 기지 건설이 실제로 막히는지 (진행률 0).
- 기술 id 가 1.19 에서 모두 유효한지 (오류 로그).
