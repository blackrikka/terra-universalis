# 사양서 53 — 대대 기본 전투 폭 (보병 1, 기병 1, 포병 4, 전차 4)

> 작성·구현: Opus 5.5 · 2026-11-06
> 사용자 요구: "사단 기본 넓이도 바꾸자 … 기본 보병 1개의 넓이를 수정하고 싶어" → "보병1 기병1 포병 4 전차 4"

## 1. 원본
- 사용자가 올린 바닐라 `common/units` 파일 45개를 `reference/vanilla_units/`에 보관한다.
- `tools/unit_widths.py`가 대상 대대가 든 파일 13개만 `terra_universalis/common/units/`에 같은 이름으로 복사한다. 같은 이름이라 바닐라 파일을 대신한다.
  - 각 대대 블록의 `combat_width` 줄만 바꾸고, 나머지는 원본 그대로다 (확인: infantry.txt는 폭 줄 말고 원본과 같다).
- 게임이 업데이트되어 바닐라 대대 파일이 바뀌면, 새 파일을 다시 받아 이 도구를 돌려야 한다.

## 4. 확인
- 대대 파일 13개 괄호 균형, tu_lint errors=0. 편제 32개 폭: 20폭 22개, 10폭 9개, 30·40폭 각 1개.
- 그대로 둔 것: 지형별 전투 폭(바닐라). AI 편제 설계(`ai_templates`)는 바닐라를 쓰므로 AI가 새로 만드는 사단 폭은 다를 수 있다.
- PC에서 확인할 것:
  - 편제 화면의 대대 폭과 사단 폭
  - 전투 폭 초과 페널티
  - AI 사단 구성
