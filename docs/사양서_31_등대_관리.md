# 사양서 31 — 등대 관리: 시테러 손상, 해안 요새, 수비대

> 작성·구현: Opus 5.5 · 2026-11-05 (`tools/focusgen/content/ibe.py`, `tools/focusgen/content_lib.py`)
> 손상 진행과 복원 공사는 사양서 40이 대신한다 (90일 미션 없음).
> 사용자 요구: 등대를 관리하지 않으면 시테러가 손상시키고, 시간제한 안에 고치지 않으면 무너진다. 보수는 정치력과 공장, 또는 군대 배치로 토벌.
> 기본 손상 확률은 높이고 해안 요새로 낮출 수 있게. 등대가 있는 주마다 위협 수준(매우 높음·높음·보통·낮음·없음)을 디시전 탭에 글로 보여 준다.
> 군대를 두어도 완전히 막지는 못하고, 해안 수비대는 가끔 습격으로 소모된다.

## 1. 손상 확률 (주 변수 `TU_IBE_lh_risk`, 월간 %)
`위협 ÷ 4 × (1 − 0.15 × 요새 평균 단계) × 수비대 보정`, **최소 2%** (`LH_MIN_RISK`), 이샤믈라 루트만 0. 매달, 그리고 등대 복원·요새 완공 때 다시 계산한다.
- 요새 평균 단계 (주 변수 `TU_IBE_lh_fort`, `TU_IBE_lh_fort_measure`): 그 주 해안 프로빈스들의 실제 해안 요새 단계 평균, 0~3.
  한 프로빈스에 도배해도 소용없게 프로빈스마다 3단계까지만 센다 (사용자 요구). HOI4 에는 프로빈스 스코프가 없어
  `any_province_building_level = { province = { id = N } ... }` 를 해안 프로빈스(사양서 33 헥스 해안선 뒤 70개)마다 펼친다. 변수로 따로 세지 않는다.
  프로빈스 번호를 직접 쓰므로 **지도가 바뀌면(사양서 33처럼 번호를 옮기는 후처리 포함) ibe.py 를 다시 돌린다.**
- 수비대 보정은 그 주에 있는 이베리아 사단의 **실제 병력**(`army_manpower_in_state`)으로 정한다: 1만 이상 ×0.8 / 2만 이상 ×0.6 / 4만 이상 ×0.45 (`LH_GARRISON`). 완전히 막지는 못한다.
- 병력이 깎인 사단은 적게 세므로 습격 피해를 보충할 때까지 방어 효과도 약해진다. 주마다 배치된 장비를 세는 조건은 없어 장비는 보지 않는다 (사용자 제안: 바닐라 독일 안슐루스 쪽 조건을 PC에서 확인해 볼 것).

| 예 | 확률 |
|---|---|
| 위협 40, 요새 0, 수비대 없음 | 10% (높음) |
| 위협 40, 요새 3, 병력 4만 | 2.5% (낮음) |
| 위협 80, 요새 0 | 20% (매우 높음) |

위협 구간: 매우 높음 15% 이상 / 높음 9~15 / 보통 4~9 / 낮음 2 초과~4 / 매우 적음 2 (최소값).
숨은 루트(이샤믈라)의 0%도 "매우 적음"으로 보인다. 화면 문구에 숨은 루트를 언급하지 않는다 (사용자 요구).

## 2. 매달 (`TU_IBE_lighthouse_monthly`, `TU_IBE_monthly` 맨 앞)
- 등대 수 `TU_IBE_lighthouses`와 손상 수 `TU_IBE_lh_damaged`를 주 깃발로 다시 센다 (주를 잃어도 숫자가 맞는다).
- 손상·보수 중이 아닌 등대마다 0~100 난수 < 확률이면 손상: 주 깃발 `TU_IBE_lh_damaged`, 미션 시작, 이벤트 tu_ibe_ev.50.
- 해안 요새 파손: 요새가 있는 등대 주는 손상 확률과 같은 확률로, 그 주 해안 프로빈스 하나(무작위)의 해안 요새에
  `damage_building = { type = coastal_bunker damage = 1 province = N }`. 수리는 건설 슬롯이 자동으로 한다 (유지비).
- 바다의 위협 증가 감소는 **온전한** 등대만 (등대 수 − 손상 수) × 0.5.
- 수비대(병력 1만 이상)가 있는 등대 주는 **상시** 손상 확률의 절반으로, 등대가 손상된 동안은 그 3배(`LH_RAID_DAMAGED_MULT`, 손상 확률의 1.5배)로 습격: `damage_units`로 그 주의 사단 조직력 −30%, 내구도 −5% (`TU_IBE_raid_damage`). 국가 비축을 직접 빼지 않고, 사단이 회복하면서 국가 인력·장비를 끌어다 채운다. 이벤트 tu_ibe_ev.52: 육군 경험치 +2, 위협 −2.

## 3. 디시전 (분류 "해안", 모두 주 대상 · 지도 버튼)
| 디시전 | 대상 | 내용 |
|---|---|---|
| 등대 복원 | 등대 없는 해안 주 | 사양서 29 그대로 + 위협 계산 |
| `[주] 등대 — 시테러 위협: ○○` ×5 | 등대 있는 주, 위협 구간마다 하나만 보임 | 표시 전용 (누를 수 없음). 설명에 확률 구간과 계산식 |
| 해안 요새 보강 | 등대 있는 주 | 정치력 40, 45일 동안 민간 공장 2개 사용 → 그 주의 모든 해안 프로빈스에 해안 요새 +1 (평균 3단계 미만일 때). 실제 건물이라 등대가 무너져도 남음 |
| 등대가 무너진다 (미션) | 손상된 등대 | 90일. 보수 시작·토벌·주 상실이면 취소, 시간이 다 되면 등대 붕괴 (등대 −1, 위협 +5, 이벤트 tu_ibe_ev.51). 다시 복원 가능 |
| 등대 보수 | 손상된 등대 | 정치력 25, 30일 동안 민간 공장 2개 사용. 시작하면 미션이 멈춘다 |
| 해안 토벌 | 손상된 등대, 그 주에 병력 3만 이상 | 정치력 10, 바로 복구, 위협 −3, 육군 경험치 +2 |

- 기간이 있는 디시전(요새·보수)은 진행 중에 대상 조건이 거짓이 되면 취소될 수 있어, 매달 바뀌는 위협 구간은 표시 전용 디시전으로 뗐다. 보수의 대상 조건은 "손상됨"이고 손상 깃발은 보수가 끝날 때 지운다.
- AI: 보수 10, 토벌 5, 요새 2.

### 위협을 깎는 반복 디시전 정리 (2026-11-05)
반복 디시전 7개를 다 돌리면 위협이 매달 약 −11씩 줄어 0에 붙고, 등대 관리가 사실상 꺼졌다 (사용자 결정: 종류를 줄인다).
- 남김: 해안 순찰(−10 / 90일), 정화 작전(−20 / 240일), 사냥꾼 지원(−15 / 180일) → 최대 매달 약 −8.
- 삭제: 해변 방어 시설(해안 요새 보강이 대신), 바다를 향한 철야 기도.
- 바다의 경고 공유: 한 번만. 심해 연구 지원: 위협 감소를 빼고 연구 보너스만.

## 4. 생성기 변경 (`content_lib`)
- `d(..., modifier={...})`: days_remove 동안의 모디파이어 (`civilian_factory_use`).
- `d(..., mission={"days", "timeout", "cancel", "good"})`: 시간제한 미션. activation 은 막아 두고 효과에서 `activate_targeted_decision` 으로 켠다. `cost=None` 이면 비용 줄 없음.
- `Country.triggers` → `common/scripted_triggers/tu_<tag>_triggers.txt`.
- 로컬라이제이션의 줄바꿈 문자를 `\n` 으로 쓴다. 다른 12개국은 다시 생성해도 바뀌는 내용이 없음을 확인했다.
- 수비대 조건 `TU_IBE_garrison_10k/20k/30k/40k`와 습격 피해 `TU_IBE_raid_damage`: `army_manpower_in_state`·`damage_units` 는 주 번호를 받아서, 지도의 통행 가능한 해안 주(44개)마다 펼친다. **지도를 다시 만들면 ibe.py 도 다시 돌린다.**

## 5. 남은 확인 (PC에서) — 바닐라 파일 없이 쓴 문법
- `any_province_building_level = { province = { id = N } building = coastal_bunker level > K }` (파손된 요새도 단계로 세는지),
  `damage_building = { type = coastal_bunker damage = 1 province = N }` (단계가 줄어드는지, 수리 대기열에 들어가는지),
- `army_manpower_in_state = { state = N amount > K }`, `damage_units = { state = N org_damage str_damage ratio army }` (다른 나라 사단도 맞는지), `set_temp_variable_to_random`, `activate_targeted_decision = { target = PREV ... }`, `add_building_construction` 의 `limit_to_coastal`, 디시전 이름의 `[FROM.GetName]`, 이벤트의 `[tu_ibe_lh_state.GetName]`.
- 위협 표시 디시전이 등대 있는 주에만, 구간에 맞게 하나씩 뜨는지. 요새 공사·보수 중에 디시전이 취소되지 않는지.
- 손상 빈도가 체감상 적당한지 (위협 40, 등대 5, 요새·수비대 없음이면 평균 2달에 한 번).
- 필요한 병력(1만/2만/4만, 토벌 3만)이 너무 많으면 `LH_GARRISON`·`LH_PURGE_MP`를 줄인다 (사용자 메모).
