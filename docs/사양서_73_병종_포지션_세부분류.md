# 사양서 73 — 병종 이름: 포지션과 세부 분류 (사양서 60 대체)

> 2026-11-10. 요청: 큰 병종은 명일방주 위키, 세부 병종은 나무위키 표기. 배정표를 사용자가 확인한 뒤 적용.
> 생성기: `python -I tools/unit_names.py` → `localisation/*/replace/tu_units_l_*.yml`

## 출처
- 포지션 8개와 세부 분류 영문: Arknights Terra Wiki, Class 문서 (arknights.wiki.gg/wiki/Class).
- 세부 분류 한국어 표기: 나무위키 '명일방주/포지션' (사용자가 저장해 올린 HTML 에서 읽음. 나무위키는 자동 접속을 막는다).

## 배정 (이름 형식: `<포지션> <세부 분류> 대대/중대`, 캐스터·메딕은 세부 분류만)
| 포지션 | 게임 병종 | 세부 분류 |
|---|---|---|
| 뱅가드 | 기병 / 차량화 / 기계화 / 정찰 / 기동 정찰 | 돌격수 / 척후병 / 기수 / 에이전트 / 전술가 |
| 가드 | 보병 / 산악 | 드레드노트 / 소드마스터 |
| 디펜더 | 경장갑 / 중(中)장갑 / 중(重)전차 | 프로텍터 / 저거너트 / 포트리스 |
| 스나이퍼 | 포병 / 대공 (대대·지원·기동) | 포격사수 / 명사수 |
| 캐스터 | 대전차 (대대·지원·기동) / 아츠 캐스터 / 아츠 로켓 대대 | 코어 캐스터 / 스플래시 캐스터 / 블래스트 캐스터 |
| 메딕 | 야전 병원 | 멀티 타겟 메딕 |
| 서포터 | 통신 / 정비 | 음유시인 / 기능공 |
| 스페셜리스트 | 공수 / 헌병 / 공병 / 군수 | 처형자 / 매복자 / 함정술사 / 상인 |

- 능력치는 그대로다 (tools/unit_roles.py, 사양서 61). 포지션이 바뀐 아츠 로켓(스나이퍼→캐스터)·군수(서포터→스페셜리스트)도 이름만 바뀐다.
- 지원 중대 `rocket_artillery` 는 기술 `rocket_artillery` 와 이름 키가 같아 따로 이름을 줄 수 없다: 둘 다 "아츠 로켓".
- 해병(marine)은 연구할 수 없어 예전 이름 그대로.

## 포지션 아이콘
- 사용자가 준 포지션 아이콘 8개 (한 줄 그림)를 잘라 `reference/class_icons/<포지션>.png` 에 두었다 (흰 아이콘, 투명 배경, 약 28px).
- 게임 병종 아이콘(사단 편성 화면·지도 카운터·글 속 아이콘)으로 넣으려면 바닐라 아이콘 파일의 크기와 프레임 배치를 알아야 한다.
  바닐라 견본 3개를 받은 뒤 `tools/unit_icons.py` 로 만든다 (다음 작업).
