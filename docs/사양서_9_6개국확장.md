# 사양서 9 — 6개국 중점·디시전 확장 (우르수스 수준, 국력별 차등)

> 작성: Opus 5.5 · 구현: Haiku 5.5 · 2026-10-31
> 사용자 결정: 구현된 6개국 먼저, 규모는 국력별 차등 — 강대국(빅토리아·염국) ~350, 중견국(카즈델·로도스) ~200, 소국(용문·리유니온) ~100.

## 0. 우르수스에서 배운 규칙 (전부 지킬 것)

1. **중점에 넣지 말 것 → 디시전으로**: 건설(add_building_construction, add_offsite_building, add_extra_state_shared_building_slots, add_resource), 외교(diplomatic_relation, give_guarantee, add_opinion_modifier), 영토 요구(add_state_claim), 전쟁 목표(create_wargoal), 병력 생성(create_unit). 이런 효과는 국가별 디시전 카테고리 `TU_<TAG>_expansion_category` / `TU_<TAG>_diplomacy_category` / `TU_<TAG>_construction_category`(없으면 `common/decisions/categories/tu_<tag>_ext_categories.txt`에 새로 만듦)에 디시전으로 만들고, **중점은 그 디시전을 해금**한다(디시전 `visible`에 `has_completed_focus = <중점>`).
2. **중점 보상은 정치력이 중심**: 일반 중점 정치력 +25~+75, 갈래 핵심 중점 +100. 이 정치력은 디시전(외교·건설·확장·국정 운영)에 쓰인다. 그 밖에 국민정신, 안정도·전쟁 지지, add_tech_bonus, 경험치, BoP 이동.
3. **외교 디시전 해금 중점 (국가마다 필수)**: 초반(뿌리에서 2~3단계)에 `set_country_flag = TU_dip_relations_unlocked` 하는 "외교 관계 수립" 성격 중점 1개, 중반에 `set_country_flag = TU_dip_alliance_unlocked` 하는 "동맹 탐색" 성격 중점 1개.
4. **영토 요구의 출처**: 공통 "영토 요구 정당화" 디시전은 삭제됐다. 확장 대상국마다 국가 전용 디시전 "영토 요구"(add_state_claim, 정치력 50~100, 중점으로 해금)를 만든다. 공통 "전쟁 명분 확보"는 이 요구가 있어야 쓸 수 있다.
5. 함정 목록(5단계 사양서 0장) 준수: `country_exists = TAG`, 숫자 주 스코프(event_target 금지), 아이디어 picture에 `GFX_idea_` 없음, BoP side마다 icon, 기간 효과는 days_remove, 한국어 파일 PowerShell 왕복 금지, `news = yes` 금지, dynamic modifier에 icon, **게임 실행 금지**.
6. 캐릭터: 장군·고문은 국가 히스토리(`tools/mapgen/country_history/<TAG>.txt`)에서 recruit. 중점에서 recruit_character는 **국가 지도자 교체**(쿠데타·즉위)일 때만, recruit 후 promote_character.
7. 모든 식별자는 바닐라에 실제로 있는 것만 (G:\SteamLibrary\steamapps\common\Hearts of Iron IV grep). 다른 나라 대상은 country_exists로 감싼다.
8. 비용: 일반 중점 10, 갈래 시작 5, 핵심 15. `ai_will_do = { base = 1 }` 이상.
9. 좌표는 신경 쓰지 않아도 된다 — 합치기 단계에서 자동 배치(autolayout)가 다시 놓는다. prerequisite·mutually_exclusive만 정확히.
10. 로컬라이제이션: 중점·디시전·아이디어마다 이름과 `_desc`, 한국어·영어 둘 다 (UTF-8 BOM). 한국어는 자연스럽게.

## 1. 조립 방식
- 국가마다 `tools/focusgen/<tag>/` 폴더에 조각 파일. 기존 트리는 T0가 `p0_existing.txt`로 옮긴다(id·효과 유지). 에이전트는 자기 조각만 쓴다.
- 합치기: `python -I tools\focusgen\merge_focus.py --tag VIC` (merge_urs.py 일반화, T0 작성) → `common/national_focus/tu_<tag>.txt` 생성 → autolayout → place_continuous. `--check <part>`는 쓰기 없이 검사 (id 중복, 참조 존재, 로컬라이제이션 키, 괄호, ASCII). 좌표 밴드 검사는 없음.
- 다른 조각의 중점을 prerequisite로 쓸 수 있는 것은 `p0_existing`의 중점과 같은 국가의 "정치 선택" 중점뿐.

## 3. 파일 소유
- 조각: `tools/focusgen/<tag>/<part>.txt` (자기 part만)
- 아이디어: `common/ideas/tu_<tag>_<part>_ideas.txt`
- 디시전: `common/decisions/tu_<tag>_<part>_decisions.txt`, 카테고리가 필요하면 `common/decisions/categories/tu_<tag>_ext_categories.txt`(국가 첫 에이전트 V2/Y2/K2/R2/L1/U1만 작성, 다른 에이전트는 그 카테고리 id를 사용 — 카테고리 id는 위 0장 규칙 1 이름 고정이므로 먼저 만들어도 됨: 없으면 만들고, 있으면 쓴다. 충돌 방지를 위해 **카테고리 파일은 V2·Y2·K2·R2·L1·U1만** 쓴다)
- 캐릭터: `common/characters/TU_<TAG>_<part>.txt`, 히스토리 추가분은 보고서에 "Opus 요청"으로 적는다(country_history 파일은 Opus가 합침)
- 로컬라이제이션: `localisation/{korean,english}/tu_<tag>_<part>_l_*.yml`

## 4. 순서
1. T0: merge_focus.py, 6개국 p0_existing 분리, URS에 외교 해금 플래그 연결(TU_URS_foreign_ministry → relations, 새 중점 TU_URS_alliance_search(w4, 북방 협약 앞) → alliance).
2. 12개 에이전트 병렬 (V1~V3, Y1~Y3, K1~K2, R1~R2, L1, U1). 각자 `merge_focus.py --tag <TAG> --check <part>` 오류 0까지.
3. Opus: 국가별 merge → lint → 참조 검사 → 미리보기 검토.
