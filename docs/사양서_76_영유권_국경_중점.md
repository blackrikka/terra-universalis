# 사양서 76 — 영유권·국경 분쟁·국경 조약 중점

> 2026-11-10. 요청: 디시전만이 아니라 이름이 영토 요구인 기존 중점이 실제로 영유권·국경 분쟁을 주게.
> 점검: 126개 후보 중 영토 성격인 것은 26개 (대부분 국경 감시·요새·정찰 같은 방어 중점이라 건드리지 않음).
> 이 중점들은 "정치력 + 안정도"뿐이었고, 설명의 "영토 요구 디시전"이 쓰는 전쟁 목표(`take_claimed_state`)는
> 영유권이 없어 쓸 수 없었다. 이제 이어진다.

## 종류와 대상 (`tools/focusgen/claim_focuses.py` 의 TABLE)
| 종류 | 효과 | 중점 |
|---|---|---|
| 영유권 | 대상 나라의 주 최대 6곳에 영유권 | 카즈델: 론디니움 수복 주장(빅토리아) · 북부 영토 주장(우르수스) · 레이타니엔 국경 주장 · 리유니온 영유권 주장 / 빅토리아: 론디니움 수복 명분(카즈델) · 라이타니엔 영토 반환 요구 · 컬럼비아 연안 명분 · 볼리바르 자원지 반환 요구 · 우르수스 옛 영토 요구 · 카시미어 영토 요구 / 염국: 옛 국경 문서(우르수스) · 극동 국경 문서 / 로도스: 카즈델 수복 준비 / 리유니온: 북부·남부·동부 영토 요구(우르수스) |
| 국경 분쟁 | 영유권 + 대상과 관계 -25 + 긴장도 +2 | 염국: 국경 압박(우르수스) / 용문: 국경 분쟁 계획(리유니온 땅) |
| 전쟁 목표 | 영유권 + '영유권 주 획득' 전쟁 목표 | 카즈델: 론디니움 진격 / 빅토리아: 카시미어 병합 계획 |
| 국경 조약 | 대상 땅의 영유권을 버리고 서로 관계 +20 | 카즈델: 국경 협정·국경 안정화(우르수스) / 빅토리아: 북방 국경 정상회담(우르수스) / 용문: 염국 국경 회담 / 사미: 개척민 협약(우르수스) |

## 주 고르기
- 대상 나라 땅 가운데 **우리와 맞닿은 주를 먼저, 없으면 가장 가까운 주** 6곳 (지도에서 계산해 주 번호로 적는다). 이미 우리 땅이면 건너뜀.
- 론디니움(빅토리아 수도 주 117)이 걸린 중점은 117 이 맨 앞.
- 리유니온 땅 = 체르노보그와 주변 8개 주 (봉기 때 핵심주가 되는 곳). 우르수스를 대상으로 하는 영유권에서는 이 주들을 뺀다.
- 리유니온 북·남·동부 요구: 체르노보그를 중심으로 방향별. 남부·동부는 지도에 그쪽 우르수스 땅이 2·1곳뿐이라 가까운 주로 3곳까지 채웠다.
- 대상 나라가 지금 없어도 (리유니온) 주 번호로 적기 때문에 나중에 생겨도 동작한다.

## 구현
- `merge_focus.py` 가 트리를 쓴 뒤 `claim_focuses.apply()` 를 부른다 (다시 돌려도 같다: 툴팁 키가 이미 있으면 건너뜀).
  툴팁 문구는 `localisation/*/tu_claims_l_*.yml` (`<중점 id>_claim_tt`).
- 영토 분쟁 디시전(사양서 75)의 `add_threat` 는 이 게임에 없는 효과라 `add_named_threat` 로 고쳤다.

## 게임에서 확인할 것
- 중점을 끝낸 뒤 지도에서 영유권 표시, '압박과 요구'의 전쟁 명분 디시전이 열리는지.
- 영유권이 지나치게 넓어 AI 전쟁이 늘지 않는지 (숫자는 claim_focuses.py 의 MAX_STATES).
