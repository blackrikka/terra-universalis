# 사양서 43 — 등대 손상을 바닐라 미션으로 처리

> 작성·구현: Opus 5.5 · 2026-11-05 (`tools/focusgen/content/ibe.py`). 사양서 40의 일수 변수를 대신한다.

## 1. 바꾼 것
- `TU_IBE_lh_days`, `on_daily_IBE`, `TU_IBE_lighthouse_daily`를 없앴다.
- `TU_IBE_lh_stage1`의 `timeout_effect`는 `TU_IBE_lh_worsen`, `TU_IBE_lh_stage2`의 `timeout_effect`는 `TU_IBE_lh_collapse`다.
- 단계 간격은 미션 기간 그대로 45일이다.

## 2. 진행
- 매달 `on_monthly`에서 손상 판정을 한다. 손상되면 1단계 미션을 켠다.
- 1단계 미션이 끝나면 2단계 깃발을 꽂고 2단계 미션을 켠다.
- 2단계 미션이 끝나면 등대가 무너진다.
- 보수를 시작하거나 주를 잃으면 미션이 취소된다.

## 3. 주를 되찾을 때
매달 손상된 등대의 현재 단계 미션을 다시 켠다. `activate_targeted_decision`은 이미 켜진 미션에는 아무 일도 하지 않는다. 되찾은 등대의 타이머는 그 단계의 45일부터 다시 시작한다.

보수를 시작한 등대는 보수가 끝나면 손상이 사라지므로 미션이 다시 켜지지 않는다.

## 4. 주의
미션은 `fire_only_once = yes`여야 한다 (사양서 42). 타이머가 멈추거나 되돌아가면 등대가 무너지지 않으므로, 미션을 고칠 때 플레이로 확인한다.
