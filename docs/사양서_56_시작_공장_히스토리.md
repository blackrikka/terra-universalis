# 사양서 56 — 시작 공장·사단을 히스토리 파일로

## 문제
사양서 55(ROOT 수정) 뒤에도 게임에서 나라별 공장 수가 3개(수도 기본값)로 나왔다.
on_startup 효과로 공장·사단을 더하는 방식은 실행 시점·범위 문제로 반영되지 않았다.

## 바꾼 것
- `tools/mapgen/tiers.py` 가 체급 공장을 **주 히스토리**(`history/states/*.txt`)의 `buildings` 블록에 바로 쓴다.
  - 수도: 기본 민수 2 · 군수 1 + 체급 몫, 나머지는 수도 + 상위 3개 주에 나눈다.
  - 슬롯이 모자라면 `add_extra_state_shared_building_slots` 를 넣는다.
- 체급 사단은 **OOB**(`history/units/<TAG>_1097.txt`)의 `units` 블록에 쓴다.
- `tu_tier_effects.txt`, `tu_tier_on_actions.txt` 삭제. KZD/RHO/URS/VIC/YAN on_actions 의 on_startup 사단 생성도 OOB 로 옮겼다.
- `validate_map.py` 규칙 9: 모든 주에 민수·군수 공장 허용, 수도는 기본값 이상, 슬롯 검사는 모든 주에서 `범주 슬롯 + 추가 슬롯` 기준.

## 결과
tiers: 공장 382개, 사단 259개 추가. 게임 시작(로드) 시점에 바로 반영된다.
