# 사양서 20 — 떨어진 영토 잇기, 육상함·이동도시

> 작성·구현: 2026-11-04
> 사용자 요구: 자기 땅인데 프로빈스가 떨어진 것을 전부 붙이기 (내전 때 이동 불가 문제). 육상함 시스템.

## 1. 떨어진 영토 (`tools/mapgen/fix_exclaves.py`, 지도 생성 뒤에 실행)
- 원인: 나라 땅 사이를 통행 불가 황야(WLD) 주가 가르고 있었다. 황야 주는 401개 모두 impassable 이라 주를 통째로 넘겨도 소용없다.
- 육지: 떨어진 덩어리마다 황야 프로빈스만 지나 본토(수도 덩어리)에 닿는 가장 짧은 길을 찾아, 그 황야 프로빈스(1~3칸)를
  떨어진 쪽 주에 붙였다 → 통행 가능한 회랑. 다른 나라 땅은 지나지 않는다. 1-프로빈스여야 하는 정박지 주에는 붙이지 않는다.
  - 고친 곳: 볼리바르, 컬럼비아 2, 이베리아 1, 카시미어, 라이타니엔 2, 사르곤 9, 우르수스 4, 염국 3.
- 섬: 이베리아 섬 7곳, 빅토리아 섬 3곳은 바다로 떨어져 있어 `map/adjacencies.csv` 에 연결 10개
  (바다 한 칸이면 sea 해협, 아니면 가장 가까운 해안끼리 육상 연결 Type 비움). 해군이 없어도 걸어서 건넌다.
- 회랑 때문에 조각난 황야 주의 작은 조각은 이웃 황야 주에 붙였다 (통행 불가라 놀이 영향 없음).
- `map/buildings.txt` 의 건물 위치 주 번호를 고치고, 위치를 잃은 황야 주에는 남은 프로빈스 위치로 다시 만들었다.
- 결과: 모든 나라의 통행 가능한 땅이 하나로 이어진다 (섬은 연결로). validate_map 통과 (환경 오류 1개 제외).
- 염국 내전 12국 분할은 이웃 주로 번지는 방식이라 각 세력 땅이 이어지게 만들어진다.

## 2. 육상함·이동도시 (오리지늄 공학 탭 + 디시전 "육상함·이동도시")
| 기술 | 시대 | 여는 것 |
|---|---|---|
| 육상함 설계 `tu_landship_1` | 1100 | 육상함 취역 (경육상함 전대, 최대 2) |
| 중육상함 `tu_landship_2` | 1106 | 중육상함 전대 (최대 4), 이동도시 이전, 연료 소모 −5% |
| 이동도시급 육상함 `tu_landship_3` | 1112 | 이동도시급 육상함 (최대 6), 연료 소모 −5% |
| (이동도시 동력 `tu_ori_mobile_cities`) | 1112 | 도시 주행 / 도시 정박 전환 |

- 육상함 취역 (정치력 100, 120일마다): 수도에 고정 편제(편집 불가) 정예 사단 하나.
  - 경: 보병 4 + 포병 2 + 공병·정찰 (경험 50%) / 중: 보병 6 + 포병 3 (60%) / 이동도시급: 보병 6 + 포병 4 + 공병·정찰·지원 포병 (80%).
  - 취역 수는 변수 `TU_landships` (잃어도 줄지 않는다 — 한도는 '취역한 수').
- 이동도시 이전 (정치력 150, 1년마다, 평화 때): 고른 자기 주로 수도를 옮기고 기반시설 +1, 90일 '이동 중인 도시'
  (공장 효율 증가 −10%, 건설 −20%, 안정도 −5%). 로도스 아일랜드는 자기 방주 장치가 있어 제외.
- 도시 주행: 육군 속도 +5%, 보급 소모 −10%, 건설 −15% / 도시 정박: 건설 +10%, 공장 생산 +5%, 육군 속도 −5%.
- S·A 체급은 육상함 설계를 갖고 시작.

## 3. PC에서 확인
- 해협/육상 연결로 섬에 부대가 걸어서 건너가는지, 회랑 프로빈스가 지도에 제대로 그려지는지.
- `set_capital = { state = FROM }` (주 대상 디시전)과 `division_template` 효과가 1.19 에서 동작하는지.
