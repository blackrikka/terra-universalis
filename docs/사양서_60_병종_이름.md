# 사양서 60 — 오퍼레이터 클래스로 병종 이름 바꾸기

> 작성·구현: Opus 5.5 · 2026-11-06. 기획서 3.3의 1차 단계. `localisation/*/replace/tu_units_l_*.yml`

바닐라 병종의 이름과 설명만 바꾼다. 능력치, 장비, 아이콘, 기술은 그대로다.

| 클래스 | 병종 |
|---|---|
| 뱅가드 | 정찰, 기동 정찰, 차량화, 기계화 |
| 가드 | 보병, 산악, 해병 |
| 디펜더 | 경·중·중전차 |
| 스나이퍼 | 포병, 로켓포, 대공포 (지원·대대·기동) |
| 캐스터 | 대전차포 (지원·대대·기동) |
| 메딕 | 야전 병원 |
| 서포터 | 통신, 군수 |
| 스페셜리스트 | 공수, 헌병 |

공병과 정비 중대는 원본 표에 없어서 그대로 둔다.
