# 사양서 15 — 쉐이 내전 12국, 극동 이름

> 작성·구현: Opus 5.5 · 2026-11-02
> 사용자 요구: 쉐이 내전은 스페인 내전처럼 12개로 나뉘게, 지도자를 고르면 그 국가로 바뀌어 플레이, 중점은 이어지게. 히가시 → 극동.

## 1. 흐름
1. 용의 시대 중점 → 이벤트 `tu_yan_dragon.1` (형제 12명 + "누구도 아니다. 쉐이가 깨어날 것이다.").
2. 고른 형제의 나라가 곧 염국이 된다: 염국(YAN)에 외형 태그 `TU_YAN_FAC_<형제>`("<형제>의 염", 국기), 그 형제가 지도자.
   - 태그는 YAN 그대로라 중점 트리 진행이 이어진다 (다른 태그로 옮기면 중점 진행이 남지 않음). 그 형제의 "~집권" 갈래만 보인다 (사양서 14).
3. 나머지 형제 11명은 각자 태그(YCH 총웨, YLI 링, YWA 왕, YDU 더스크, YSH 슈, YNI 니엔, YJN 쥔, YJE 지에, YJI 지, YYI 이, YFA 팡, YYU 위)로 독립해 염국에 전쟁을 건다. 염국까지 12개 나라.
   - 파멸의 길: 염국이 "깨어난 쉐이"가 되고 형제 12명이 모두 독립 (13개 나라).
4. 히든 "손에 손잡고"는 그대로 (총웨를 고른 경우, 분파를 괴뢰로 만든 뒤 놓아주고 디시전).

## 2. 땅 나누기 (`common/scripted_effects/tu_yan_dragon_effects.txt`)
- 염국 육지 주는 29개뿐이라, 형제마다: 씨앗 주 1개(수도 아님. 가능하면 수도·다른 분파와 붙지 않은 주, 없으면 아무 빈 주) + 이웃 주 1개.
- 남은 주(수도와 그 주변)는 염국. 분파는 주마다 보병 사단 2개, 쉐이 집권, 형제 지도자.
- 분파끼리는 서로 싸우지 않고 모두 염국과 싸운다.
- 이전의 무작위 분파 3개(YSA/YSB/YSC)는 없앴다.

## 3. 극동
- 히가시(HIG) 한국어 이름을 극동으로 (국가 이름과 다른 문장 속 이름). 영어는 Higashi 그대로.

## 4. 남은 확인 (PC에서)
- 이벤트 선택지 13개가 화면에 다 보이는지.
- 11개 분파가 모두 땅을 받고 생기는지, 염국에 남는 땅이 적당한지 (주가 커서 분파당 1~2주).

## 5. 화면 넘침 수정 (사용자 보고: 국가 선택 화면이 옆으로, 지도자 선택 이벤트가 아래로 넘침)
- 국가 선택: 19개국이 모두 주요국(위쪽 큰 아이콘)이라 옆으로 넘쳤다. 이제 상세 구현 국가 6개(로도스·우르수스·카즈델·빅토리아·염국·용문)만 주요국이고, 나머지 13개는 `"---" = { history = "OTHER_GAMEPLAY" }` 뒤에 `minor = yes`로 목록에 나온다 (build_countries).
- 지도자 선택 이벤트: 선택지 13개가 아래로 넘쳤다. 두 단계로 나눴다.
  - `tu_yan_dragon.1`: 형제 넷씩 묶은 3개 무리(총웨·링·왕·더스크 / 슈·니엔·쥔·지에 / 지·이·팡·위) + 파멸의 길 = 선택지 4개.
  - `tu_yan_dragon.4/.5/.6`: 각 무리의 형제 4명 + "다른 형제를 본다"(첫 이벤트로 돌아감) = 선택지 5개.
  - 세계 뉴스(`tu_yan_dragon.2`)는 지도자를 고른 뒤에 보낸다 (돌아가기를 눌러도 두 번 가지 않게).

## 6. 내전 중 중점이 안 보이던 문제
- 사용자 보고: 염국 내전 중 중점이 계속 안 보임.
- 원인: 집권 갈래는 `allow_branch = { has_country_flag = TU_YAN_chosen_<형제> }`로 숨겨져 있는데, HOI4는 게임 중 깃발이 바뀌어도 `allow_branch`를 다시 계산하지 않는다. 깃발을 세운 뒤 `mark_focus_tree_layout_dirty = yes`를 불러야 트리를 다시 그린다.
- 수정: 지도자를 고르는 효과 13개(`TU_YAN_become_*`)와 히든 루트를 여는 디시전(`TU_YAN_hand_in_hand_decision`)에서 깃발 뒤에 `mark_focus_tree_layout_dirty = yes`.
