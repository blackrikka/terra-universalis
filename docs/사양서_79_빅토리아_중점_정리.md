# 사양서 79 — 빅토리아 중점 정리

> 2026-11-10. 요청: 빅토리아 중점이 너무 중구난방. 사용자 선택: 약 160개, 큰 갈림길만 남기기, 초반 이벤트로 노선 고르기, 외교·확장은 구조 유지.

## 문제 (222개)
- 정치 노선 4개가 118개 (각 27~31개). 노선이 서로 다른 깊이에서 갈렸다: 대공 노선은 '현상 유지' 안, 의회 노선은 첫 칸.
- 대립(택일) 55쌍 중 **27쌍이 중간 단계마다 있는 A/B 선택** (대공 공방/영지 결속, 길드 협약/해체 …).
- 경제·군사·항공·학회 갈래 49개가 곁가지처럼 흩어져 있었다.

## 바꾼 것 (222 → 159, 한 판에 보이는 것은 약 110)
1. **노선은 이벤트로 고른다.** '대공 회의 소집'을 끝내면 이벤트 `tu_vic_ev.40` "왕위의 향방"에서 넷 중 하나를 고른다:
   대공 의회(17) / 아슬란 복위(16) / 드라코와 타라(17) / 빅토리아 의회(16).
   고른 노선의 중점만 보인다 (`allow_branch = TU_VIC_route_<duk|asl|drc|par>`, 노선 안 모든 중점에 달았다). 노선끼리의 택일은 없앴다.
2. **네 노선이 같은 자리에 겹친다** (`tools/focusgen/block_layout.py` 의 VIC 설정, 시라쿠사와 같은 방식). 빈 칸이 남지 않는다.
3. **중간 A/B 택일 21쌍을 하나로 합쳤다.** 지우는 쪽의 공장·국민정신·이벤트 효과를 남기는 쪽에 모으고 설명도 합쳤다 (연구 보너스 같은 일반 보상은 중복하지 않음).
   남긴 큰 갈림길 4쌍: 의회 표결 장악/공개 자문회의 (대공), 충성 귀족 회유/귀족 재산 몰수 (아슬란), 더블린 진압/타협 (드라코), 자유 무역/보호 관세 (의회) + 기존 경제의 소비재 시장/전시 공장 전환,
   외교의 공세 계획/평화 교섭 (6개국).
4. **곁가지 42개를 지웠다**: 자식은 지운 중점의 부모 아래로. 지운 중점을 조건으로 쓰던 디시전 6개는 남은 부모 중점으로 옮겼다
   (예: 정유·병기 계약·도시 주택 → 부모 중점, 현상 유지 → 대공 의회 과두 선언).
5. 설명의 "~와 상호 배타" 문장을 지웠다 (남은 쌍은 유지).
