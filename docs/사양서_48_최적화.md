## 2. 고친 것 1 — 게임 시작 효과의 중복 실행 방지
- `on_startup`은 멀티플레이(플레이어마다)나 불러오기 때 다시 실행될 수 있다.
- 시작 공장·사단(체급 효과)과 나라별 시작 효과에 한 번만 실행되는 장치가 없어서, 다시 실행되면 공장·사단 209개가 겹쳐 쌓이고 게임이 느려질 수 있었다.
- 전역 깃발로 한 번만 실행하게 했다:

| 대상 | 깃발 |
|---|---|
| 체급 효과 (공장·사단, `tools/mapgen/tiers.py`가 생성) | `TU_tiers_applied` |
| 카즈델·로도스·우르수스·빅토리아·염국(+용문) 시작 효과 | `TU_<TAG>_startup_done` |
| 컬럼비아 첫 선거 예약 (`content/col.py`) | `TU_COL_first_election_scheduled` |

- 체르노보그 사건 예약은 원래부터 깃발로 막혀 있었다.

## 3. 고친 것 2 — 같은 세계 뉴스가 나라 수만큼 반복되던 문제
- `major = yes` 뉴스는 어느 나라에 보내든 모든 플레이어에게 보인다.
- 그런데 `every_country = { news_event = ... }`로 모든 나라에 하나씩 보내서, 플레이어 화면에 약 30번 떴다.
- 한 번만 보내도록 바꿨다:

| 뉴스 | 어디서 |
|---|---|
| `tu_yan_dragon.2` 용의 시대 — **쉐이 내전 시작 뉴스** | `tu_yan_dragon_effects.txt` (내전 분할 효과) |
| `tu_yan_ev.16` | 염국 노선 마지막 중점 |
| `tu_rho_ev.11`·`12`·`13` | 로도스 아일랜드 노선 중점 |

- `major = yes`가 아닌 뉴스는 나라마다 자기 사본만 보므로 그대로 둔다.
