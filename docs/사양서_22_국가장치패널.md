# 사양서 22 — 국가 고유 장치 패널 (scripted GUI)

> 작성·구현: 2026-11-04. 사용자 요구: 주요 컨텐츠의 GUI 만들기.

생성기: `python -I tools/guigen/build_panels.py` (나라별 변수 표 `PANELS` 를 고치고 다시 돌린다)

- 각 나라 첫 디시전 분류 위에 패널 (content_lib 가 분류에 `scripted_gui = TU_<TAG>_panel` 을 넣는다). 육상함·이동도시 분류에도 하나.
- 줄마다: 이름 · 칸 막대(칸 수 = min(최대값, 10), 변수가 최대값의 (k+1)/칸수 이상이면 칸 k 채움) · 수치 `[?변수|0] / 최대`.
- 칸 그림(빈 칸 + 초록·빨강·금색·파랑·보라)은 생성기가 DDS 로 직접 그린다 (`gfx/interface/tu/seg_*.dds`). 창 배경은 바닐라 `GFX_tiled_window_2b_border`.
- 14개 패널, 34줄:
  카시미어 기사 명성 / 컬럼비아 과학 성과 / 라테라노 교황청 영향력·순례자 / 시라쿠사 법과 질서·3대 패밀리 /
  사르곤 영주 충성·황금 / 이베리아 바다의 위협·등대 / 라이타니엔 선제후·공명·마왕 유물 / 쉐라그 근대화 /
  극동 개항장·외세 영향·닌자 / 미노스 민회 지지·교역 항로 / 림 빌리튼 갱도·광석·감염률·정착지 /
  사미 숲의 은총·정령 계약·부족 회의·외부 접촉 / 볼리바르 장악도·전쟁 피로·컬럼비아/빅토리아 의존 / 육상함 취역 수.
- 세력 균형(BoP)이 있는 나라는 게임 기본 세력 균형 막대가 따로 뜬다.

## PC에서 확인
- 디시전 화면에서 해당 분류를 펼쳤을 때 패널이 뜨는지, 막대 칸과 수치가 변수 값과 맞는지.
- 패널 폭(590px)이 분류 칸에 맞는지 (넘치면 WIDTH 를 줄인다).
