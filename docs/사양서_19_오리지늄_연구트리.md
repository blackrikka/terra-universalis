# 사양서 19 — 해군을 오리지늄 시스템으로 대체, 테라 연구 트리 전면 개편

> 작성·구현: 2026-11-04
> 사용자 요구: 해군·조선소를 오리지늄 공장 같은 새 시스템으로 대체. 기본 연구 트리를 전부 손보고, 총은 라테라노만 연구할 수 있게.

생성기: `python -I tools/techgen/build_techs.py` (시안: `python3 tools/techgen/render_techs.py <out.html>`)

## 1. 바닐라 연구의 문제 (고친 것)
- 바닐라 기술은 시작 연도가 1918~1950 인데 게임은 1097년에 시작한다 → 모든 기술에 '수백 년 앞선 연구' 벌칙이 붙어 사실상 연구 불가.
- 이제 `replace_path="common/technologies"` 로 바닐라 기술을 모두 지우고 테라력(1090~1112) 기술만 쓴다.

- 시대: E0 1090 (시작 전), E1 1097, E2 1100, E3 1103, E4 1106, E5 1109, E6 1112.
- 장비·부대를 여는 기술은 바닐라 id 를 다시 써서 아이콘이 그대로 붙는다 (이름·설명은 replace 로컬라이제이션).
  테라 고유 기술 23개는 새 id, 아이콘은 `interface/tu_technologies.gfx` 가 바닐라 그림을 빌린다.
- **총기는 라테라노만**: `tu_lat_firearms_1~4` 는 `allow_branch = { original_tag = LAT }`. 다른 나라 보병 장비 이름은 "석궁과 도검/보병 장구".
  라테라노는 시작부터 산크타 총기 1단계를 가진다.
- 해군 기술·해군 폭격기·항모기·상륙 부대는 없다.
- 기술 분류: 바닐라 분류 이름은 모두 남기고(다른 파일 호환) `tu_originium_tech`, `tu_oripathy_tech`, `tu_lat_firearms_tech` 추가.
  중점 테마 보상: research → 전자 + 오리지늄 공학 연구 보너스, medical → 광석병 의학 연구 보너스 추가.

## 3. 오리지늄 시스템 (조선소 대체)
- 새 건물 **오리지늄 정제소** (`common/buildings/tu_buildings.txt`): 공유 슬롯, 주당 최대 6, 원석 정제 기술로 2/4/6단계까지 열림.
  - 단계마다 (국가 전체) 연구 속도 +0.4%, 공장 생산 +0.4%, 연료 +1, **안정도 −0.4% (광석병 위험)**.
  - 광석병 의학 탭의 기술이 안정도를 되돌려 준다 → 정제소를 많이 지을수록 의학 연구가 필요.
- 조선소·해군 기지는 "심해의 위협"(사양서 18)으로 건설이 막혀 있다.

## 4. 체급별 시작 기술 (`tools/mapgen/tiers.py` 갱신)
- 모두: 석궁과 도검, 지원 장비, 공성 노포, 증기 기관차, 광석병 연구 + (체급별) 공병·정찰·의무대·공작 기계·건설·아츠 이론 …
- A·S: 원석 정제(정제소), 화물 차량, 증기 장갑차, 정찰 드론, 전기 공학. S: 차량화·폭격 비행선·연료 저장소·채굴.
- 라테라노 산크타 총기, 림 빌리튼 원석 정제, 로도스 아일랜드 억제제·야전 아츠 치료.

## 5. 남은 것 / PC에서 확인
- 연구 화면 그림은 바닐라 GUI 를 그대로 쓴다: 옛 해군 탭 아이콘(배)·배경(군함 도면)·탭 안의 연도 글자(1936 등)는 그대로 보인다.
  바닐라 `interface/countrytechtreeview.gui` 를 `reference/vanilla/` 에 넣어 주면 연도 글자·배경을 테라식으로 바꾼 덮어쓰기 파일을 만들 수 있다.
- 건설 메뉴에 조선소·해군 기지 항목은 남는다(건설 불가). 바닐라 `common/buildings/00_buildings.txt` 를 주면 목록에서 아예 뺄 수 있다.
- 장갑 차량·항공은 전차/항공기 설계 DLC 없이 쓰는 옛 장비(light_tank_equipment, fighter_equipment …)를 연다. DLC 가 있어도 생산되는지 확인.
- 부대 이름(artillery_brigade, anti_tank_brigade, anti_air_brigade, rocket_artillery_brigade …)이 1.19 에서 맞는지 오류 로그 확인.
