# 사양서 25 — 국가 지도자 특성

> 작성·구현: 2026-11-04 (`tools/chargen/leader_traits.py` → `build_characters.py`)

- 테라 전용 지도자 특성 65개 (`common/country_leader/tu_leader_traits.txt`), 지도자 80명에게 1~2개씩.
- chargen 캐릭터뿐 아니라 손으로 만든 기존 캐릭터(우르수스 황제, 테레시스, 빅토리아 지도자들, 위옌우, 탈룰라, 아미야,
  염국 황제와 쉐이 형제 등)에도 넣는다: 캐릭터 파일의 country_leader 블록 traits 를 덮어쓴다 (다시 돌려도 같다).
- 예: 상업 연합회 의장 = 연합회의 대주주 + 상인 군주 / 믈리나르 = 기사의 명예 / 마거릿 = 빛나는 기사 + 감염자의 대변인 /
  테레시스 = 살카즈의 섭정왕 / W = 용병왕 / 이샤믈라 = 타락한 심장 / 실버애쉬 = 칼란 무역의 주인 + 개혁가 /
  프라마닉스 = 성녀의 축복 / 라비니아 = 법의 판관 / 탈룰라 = 용의 불꽃 + 감염자의 대변인 / 종예 = 쉐이의 형제 + 무의 극의 /
  니엔 = 대장장이의 불 / 더스크 = 그림 속의 세계 / 링 = 술과 꿈 / 진짜 세 = 깨어난 세.
- 특성 표를 고치려면 leader_traits.py 를 고치고 build_characters.py 를 다시 돌린다.
