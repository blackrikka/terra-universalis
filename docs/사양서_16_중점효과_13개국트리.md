# 사양서 16 — 중점 이름에 맞는 효과, 나머지 13개국 컨셉 트리

> 작성·구현: Opus 5.5 · 2026-11-02
> 사용자 요구: 나머지 국가들도 컨셉에 맞게 중점을 만들자. 각 중점의 이름에 걸맞는 효과를 주자 (예: 기동전 → 기동전 교리, 트럭·기계화 보병 연구 속도).

## 1. 테마 규칙 (`tools/focusgen/theme_effects.py`)
- 중점 영어 이름을 정규식 목록에 위에서부터 맞춰 테마 하나를 정한다. 아무것도 맞지 않으면 politics.
- 테마별 보상 (cost 5 / 10 / 15 이상에 따라 작음·보통·큼):

  | 테마 | 대표 낱말 | 보상 |
  |---|---|---|
  | mobile_city | mobile city, landship | 건설·차량 연구 보너스 |
  | armor | armour, tank | 기갑 연구 보너스 + 지상 교리 할인 |
  | mobile | mobile, motorised, mechanised, cavalry, raid | 차량(트럭·기계화) 연구 보너스 + 지상 교리 할인 |
  | air | air, fighter, bomber | 전투기·전술폭격기 연구 + 공군 교리 할인 + 공군 경험치 |
  | navy | naval, navy, fleet, harbour, coast | 구축함·순양함 연구 + 해군 교리 할인 + 해군 경험치 |
  | artillery | artillery, siege, cannon | 포병 연구 + 육군 경험치 |
  | infantry_weapons | arms, weapon, forge, steel, firearm | 보병 장비 연구 + 육군 경험치 |
  | doctrine | doctrine, tactics, training, drill, academy, knight | 지상 교리 할인 + 육군 경험치 |
  | coastal_fort | coastal fortress, harbour fort, island fortress, sea wall | 해안 주 1/2/3곳에 해안 요새 2/2/3단계 (`TU_build_coastal_forts_N`) |
  | rail | rail, railway, gauge, track (sabotage·guard·battery·fortress 제외) | 수도→주요 도시 철도 건설, 있으면 한 단계 올림 (`TU_build_railway`, 큼은 2번) |
  | fort | fortress, fort, wall, bastion, citadel, bunker, trench, defence line | 국경 주 1/2/3곳의 국경 프로빈스에 육상 요새 2/2/3단계 (`TU_build_forts_N`) |
  | defense | defence, border, garrison, shield, patrol, watchtower | 건설 연구 + 육군 경험치 (예전 fort 보상) |
  | war | war plan, operation, offensive, invasion, occupy | 육군 경험치 + 전쟁 지지 + 지상 교리 할인 |
  | medical | medical, oripathy, refugee, housing | 안정도 + 인력 |
  | research | research, arts, originium, science, school | 전자·산업 연구 보너스 |
  | intel | intelligence, secret, police, security | 레이더·전자 연구 + 안정도 |
  | manpower | levy, militia, mercenary, guard, army | 인력 + 육군 경험치 |
  | industry | industry, factory, mining, supply, survey | 산업·건설 연구 보너스 |
  | trade | trade, market, bank, tax, company | 정치력 + 산업 연구 |
  | diplomacy | envoy, pact, treaty, alliance, neutrality | 정치력 + 안정도 |
  | propaganda | propaganda, loyalty, faith, saint, rites | 전쟁 지지 + 안정도 |
  | politics | (그 밖) | 정치력 + 안정도 |

- 교리는 바닐라 1.19처럼 `add_doctrine_cost_reduction`, 장비는 `add_tech_bonus`. 보너스 이름은 중점 id (툴팁에 중점 이름).

- 철도·요새 효과는 `tools/mapgen/rail_effects.py`가 지도 데이터로 만든다 (`common/scripted_effects/tu_rail_fort_effects.txt`, 2026-11-04).
  - 철도: 시작 수도 주마다 블록 하나. 수도에서 자기 땅으로 이어진 주 가운데 승점·인력이 큰 4곳까지 `build_railway level 1` (수도·목표 모두 장악할 때만).
    같은 효과를 다시 부르면 같은 노선의 레벨이 오른다. 목록에 없는 수도(한 주짜리 나라 등)는 기반시설 1단계로 대신.
  - 철도 중점에 붙어 있던 기반시설 건설(`TU_build_infrastructure`)은 뺐다 (content 트리: `content_lib.f`, 기존 트리: `retheme.py`).
  - 요새: 국경 주가 없으면 수도에, 해안 주가 없으면 육상 요새로 대신.

## 2. 기존 7개국 트리 다시 쓰기 (`tools/focusgen/retheme.py`)
- 각 중점 `completion_reward`의 맨 위 단계에서 일반 보상(정치력, 안정도, 전쟁 지지, 경험치, 인력, 연구 보너스, 교리 할인)만 지우고 테마 보상을 넣었다.
- 깃발, 이벤트, 이념·인물, 국민정신, 건설(`TU_build_*`), if 블록 등은 그대로.
- 사용자가 효과를 직접 정한 중점(황권 강화, 황제 축출: 정치력 +100)은 건드리지 않는다 (`PRESERVE`).
- 다시 돌려도 결과가 같다.

## 3. 나머지 13개국 트리 (`tools/focusgen/minor_trees.py`)
- 라이타니엔, 이베리아, 라테라노, 카시미어, 극동, 컬럼비아, 사르곤, 미노스, 볼리바르, 시라쿠사, 사미, 쉐라그, 림 빌리튼. 각 29개 (모두 377개).
- 모양: 시작 중점 → 갈래 4개 (정치 + 나라 특색 2~3 + 경제). 갈래 = 중점 6개 사슬, 4번째 자리는 양자택일. 갈래 끝 중점이 그 갈래 국민정신(`common/ideas/tu_<tag>_concept_ideas.txt`)을 준다.
- 나라 특색 갈래 예: 라이타니엔 아츠·음악, 이베리아 심판소·바다의 위협, 라테라노 총기·하늘의 사도, 카시미어 기사단·상업 연합회, 극동 해군·무사, 컬럼비아 과학·공군, 사르곤 사막 기병·황금 무역, 미노스 함대·철학, 볼리바르 내전 종식·재건, 시라쿠사 패밀리, 사미 숲·정령 아츠, 쉐라그 설산·칼란 무역, 림 빌리튼 광산·광석병.
- 경제 갈래는 공장·기반시설 건설을 더한다 (사양서 14 규칙).
- 이 나라들은 이제 공통 트리(generic.txt) 대신 자기 트리를 쓴다 (`original_tag`에 가중치 10).

## 4. 중점 배치 단 접기 (`tools/focusgen/bandpack.py`, 2026-11-04)
- 예전 배치는 갈래를 한 줄로 늘어놓아 폭 55~170칸, 깊이 8~20줄이었다. 갈래 묶음(뿌리를 뺀 연결 덩어리)을 파일 순서대로 여러 단으로 접어 쌓는다.
- 단 수는 화면 비율(가로:세로 ≈ 1.8)에 가장 가까운 값. 아래 단 묶음은 그 열들의 위 단 바닥 아래로 빈 줄 하나를 두고 붙는다.
- 아래 단 갈래 머리와 뿌리는 위에 중점이 없는 열에 둔다 → 뿌리에서 내려오는 선이 다른 상자를 지나지 않는다.
- 결과 (폭): 볼리바르 90→41, 카시미어 55→36, 미노스 80→47, 우르수스 173→72, 염국 144→91, 빅토리아 124→92.

## 5. 남은 확인 (PC에서)
- 단 접기 배치에서 뿌리→아래 단 선이 어떻게 그려지는지 (꺾이는 위치).
- 철도 중점: 철도가 실제로 깔리고 두 번째에는 레벨이 오르는지, 툴팁.
- 요새 중점: 국경 프로빈스에 요새가 지어지는지.
- 13개국 트리가 국가 선택 뒤 제대로 뜨는지, 아이콘·이름.
- 툴팁의 연구 보너스·교리 할인 이름이 보이는지.
