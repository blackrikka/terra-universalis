# 사양서 61 — 클래스 역할 수치와 아츠 캐스터

> 작성·구현: Opus 5.5 · 2026-11-06. 기획서 3.3의 다음 단계. `tools/unit_roles.py` (unit_widths.py 다음에 돌린다)

공격·방어 값은 장비 능력치에 더하는 배율이다. 값은 계산으로 정한 시작값이고 플레이로 조정한다.

| 클래스 | 병종 | 변경 |
|---|---|---|
| 뱅가드 | 정찰 / 기동 정찰 | 정찰 1→1.5 / 1.5→2, 주도권 +5% |
| 뱅가드 | 차량화, 기계화 | 돌파 +10% |
| 가드 | 보병 | 대인 공격 +15%, 조직력 60→65 |
| 가드 | 산악, 해병 | 대인 공격 +20% |
| 디펜더 | 중·중전차 | 방어 +20%·+25%, 장갑 +5%, 속도 -10% |
| 스나이퍼 | 포병 대대 | 대인 공격 +10% |
| 스나이퍼 | 대공 대대 | 대공 공격 +20% |
| 캐스터 | 대전차 대대, 기동 대대 | 관통 +15% |
| 메딕 | 메딕 중대 | 부상병 복귀 20%→30% |
| 서포터 | 통신 / 군수 | 주도권 10%→15% / 보급 소모 -10%→-15% |
| 스페셜리스트 | 강하 / 헌병 | 돌파 +15% / 진압 20%→30% |

경전차, 지원 중대, 로켓포, 기동 포병, 기동 대공은 바꾸지 않았다.

## 아츠 캐스터 `tu_arts_caster`
- 기술 `tu_arts_units`(술사 부대 교리)로 해금한다.
- 전선 대대, 폭 2, 인력 750, 훈련 150일, 보급 0.15.
- 장비: 대전차포 36, 지원 장비 12.
- 대인 공격 +100%, 대전차 공격 +10%, 관통 +25%.
- 아이콘은 그림이 없어 대전차 아이콘을 쓴다 (`interface/tu_units.gfx`).
- 원본 표의 스페셜리스트 "적국 스파이 검거"는 대대 능력치로 만들 수 없어 넣지 않았다.
