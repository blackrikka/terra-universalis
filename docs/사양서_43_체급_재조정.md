# 사양서 43 — 나라별 공장·군대·인구 체급 재조정

> 작성·구현: Opus 5.5 · 2026-11-06
> 사용자 요구: "나라별 공장과 군대 체급 조정을 하자"

## 1. 문제
- 사양서 18의 체급표가 땅 크기와 맞지 않았다 (주 분할 뒤 통행 가능한 프로빈스 수 기준).
  - 사르곤 140칸이 A, 라테라노 5칸이 A에 민간 공장 16개, 이베리아 63칸·림 빌리튼 46칸이 B였다.
- 인구가 너무 적었다: 우르수스 190만, 카즈델 20만, 용문 6만.
  - HOI4는 인구의 약 2.5%만 징집할 수 있다. 그래서 카즈델은 사단 18개에 보충 병력이 약 5천 명뿐이었다.

- 나라별 성격:
  - 컬럼비아: 공업은 가장 크고 군대는 작다.
  - 우르수스: 군수 공업과 군대가 가장 크다.
  - 사르곤: 땅과 인구는 크지만 공업이 약하다.
  - 카즈델: 공업은 약하지만 군대가 많다.
  - 라테라노·용문: 땅은 작지만 부유하다.
- 리유니온은 시작 땅이 없어 체급에 넣지 않는다. 쉐이 분파와 황야도 넣지 않는다.

## 3. 인구
- `set_population`: 나라 인구를 통행 가능한 주에 나눠 각 주의 manpower에 쓴다.
  - 수도는 4배, 나머지 주는 1배다.
  - 다시 돌려도 결과가 같다.
- 공장·사단을 놓는 방식은 이전과 같다 (수도에 절반, 나머지는 인구가 큰 주 3곳).

## 4. 확인
- tiers → build_countries → validate_map 지도 규칙 통과, tu_lint errors=0.
- PC에서 확인할 것:
  - 시작 공장·사단 수
  - 징집 가능 인력이 시작 사단을 보충할 만큼 되는지
  - AI 대국 사이의 균형
