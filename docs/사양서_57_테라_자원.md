# 사양서 57 — 테라 전략 자원 6종

> 기획서 3.1 "자원 6종 치환", 원본 설계문서 3.1 변환표. 내부 키는 바닐라 그대로(AI·장비 호환), 이름과 산지만 바꾼다.

| 테라 자원 | 바닐라 키 | 산지 |
|---|---|---|
| 오리지늄 | oil | 카즈델, 우르수스 북부, 림 빌리튼 |
| 오리론 | steel | 모든 나라(군수 공장 x 2) + 빅토리아·염국 |
| 폴리에스테르 | rubber | 사르곤, 볼리바르 |
| 아케톤 | aluminium | 컬럼비아, 사미 |
| 망간 | tungsten | 우르수스, 카시미어 |
| 장치 | chromium | 컬럼비아(라인 랩), 라테라노 |

## 바꾼 것
- 이전에는 **어느 주에도 자원이 없었다**. `tools/mapgen/resources.py` 가 주 히스토리에 `resources = { }` 를 쓴다 (tiers.py 끝에서 부름).
  - 수도를 뺀 통행 가능한 주에 나눈다, 주 하나에 자원별 최대 8. 우르수스 오리지늄은 북쪽 주부터.
  - S 체급은 오리론 외 5종을 4씩, A 체급은 2씩 기본으로 가진다.
- `tools/resource_names.py`: 자원 이름 replace 로컬라이제이션 + 기존 문장의 옛 자원 이름(석유·철강·고무·텅스텐·크롬·알루미늄, 영어 Oil/Steel/…)을 새 이름으로.
  생성기를 다시 돌린 뒤에는 이 도구도 다시 돌린다.
- 염국 오리지늄 디시전 4개(광산·정제소·심층 갱도·비축 사일로)는 텅스텐 대신 오리지늄(oil)을 준다.

## 게임에서 확인할 것
- 자원 이름 키(`oil`, `steel` …)가 바닐라와 같은지: 생산·무역 화면에 "석유"가 남아 있으면 그 화면의 키를 알려 주면 추가한다.
- 아이콘은 바닐라 그대로다.
