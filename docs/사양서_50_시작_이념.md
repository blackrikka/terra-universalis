# 사양서 50 — 나라별 시작 이념

> 작성·구현: Opus 5.5 · 2026-11-05
> 사용자 요구: "모든 나라들이 다 비동맹이니깐 재미없어..."

## 1. 원인
- `countries.json`에 시작 이념(ruling_party)이 있는 나라는 염국과 쉐이 분파뿐이었다. 나머지 19개국은 기본값인 비동맹으로 시작했다.

## 2. 시작 이념 (`tools/mapgen/terra/countries.json` → build_countries)
| 이념 | 나라 (지지율) | 시작 지도자 |
|---|---|---|
| 파시즘 | 우르수스 (파 55 / 비 20 / 공 15 / 민 10) | 우르수스 황제 |
| 파시즘 | 카즈델 (파 60 / 비 25 / 공 15) | 카즈델 군사위원회 |
| 파시즘 | 이베리아 (파 50 / 비 40 / 민 10) | 대심판관 |
| 공산주의 | 리유니온 (공 80 / 파 10 / 비 10) | 탈룰라 |
| 민주주의 | 빅토리아 (민 45 / 비 30 / 파 15 / 공 10) | 대공 의회 의장 |
| 민주주의 | 컬럼비아 (민 60 / 비 25 / 공 10 / 파 5) | 컬럼비아 대통령 |
| 민주주의 | 카시미어 (민 50 / 비 35 / 파 15) | 상업 연합회 의장 |
| 민주주의 | 미노스 (민 65 / 비 30 / 파 5) | 민회 집정관 |
| 민주주의 | 볼리바르 (민 40 / 공 30 / 파 20 / 비 10) | 임시 대통령 |
| 황제일가 | 염국 (그대로) | 염국 황제 |
| 비동맹 | 로도스·용문·라이타니엔·라테라노·극동·사르곤·시라쿠사·사미·쉐라그·림 빌리튼 | 나라마다 지지율을 다르게 (예: 림 빌리튼 공산 35) |

- 민주주의 나라는 선거가 열린다 (`elections_allowed = yes`). 나머지는 선거가 없다.
- 시작 지도자 이념을 집권당에 맞췄다.
  - chargen 캐릭터: `data.py`의 L 역할.
  - 손으로 만든 캐릭터(우르수스 황제·빅토리아 대공 의회·탈룰라·테레시스·패트리어트): `data.py`의 `LEADER_IDEOLOGY`로 바꾸고, `build_characters.patch_leader_ideology()`가 적용한다.
- 확인: 모든 나라가 집권당 이념의 지도자를 갖고 시작한다.

## 3. 지도자 교체 = 집권당 교체 (`tools/ruling_party.py`)
- `promote_character = { character = X ideology = Y }`는 Y 정당이 집권 중일 때만 X를 국가 지도자로 세운다.
  - 시작 이념이 달라져서, 비동맹 지도자로 바꾸는 노선 결말이 파시즘·민주 나라에서는 지도자를 바꾸지 못하게 된다.
- 지도자 교체 51곳마다 바로 앞에 `set_politics = { ruling_party = <Y의 이념> }`을 넣었다.
  - 노선 결말이 정권(이념)도 함께 바꾼다.
  - 민주주의로 바뀌면 선거가 열린다.
- merge_focus(중점), content_lib(이벤트·디시전), hidden_routes(숨은 루트)가 파일을 쓸 때 자동으로 넣는다.
  - 손으로 쓴 파일에는 `python -I tools/ruling_party.py`로 넣는다. 다시 돌려도 결과가 같다.
- 결말 지도자 이념 조정:

| 결말 지도자 | 이념 |
|---|---|
| 우르수스 군정 평의회 | 파시즘 |
| 카즈델 테레시스 | 파시즘 |
| 리유니온 패트리어트 | 공산 |
| 림 빌리튼 광부 노조 위원장 | 공산 |
| 볼리바르 대통령 | 민주 |
| 빅토리아 의회 총리 / 드라코 / 우르수스 민주당 | 원래대로 민주 / 파시즘 / 민주 |

## 4. 함께 바뀐 것
- 쉐이 꿈(숨은 루트)의 선행 중점이 원래 설계인 "삼켜진 형제"(TU_YAN_p1_ruin_devour)로 돌아왔다.
  - 사양서 35 정리 때 합쳐졌다가 사양서 36에서 되살린 중점이다.
