# 사양서 72 — 대립(택일) 중점 줄 맞춤

> 2026-11-10. 플레이 보고: 대립되는 중점끼리 높이가 안 맞아 화살표(대립 표시)가 안 보인다, 겹쳐 보이는 곳도 있다.

## 점검 (트리 20개)
- 좌표가 겹치는 중점: 없음 (시라쿠사의 겹친 루트 5개는 의도한 것).
- **대립 쌍의 줄이 다른 곳: 52쌍** (빅토리아 9, 이베리아 8, 컬럼비아·쉐라그·사미 5, 카즈델 4 …).
  원인: autolayout 은 y = 1 + max(부모 y) 만 썼다. 서로 다른 갈래의 결말끼리 대립이면 갈래 길이만큼 줄이 어긋난다.
  HOI4 는 대립 표시를 같은 줄일 때만 제대로 그린다.

## 고친 것
1. `tools/focusgen/autolayout.py`: 대립 쌍 가운데 얕은 쪽을 깊은 쪽 줄로 내리고 그 아래 중점을 다시 계산한다.
   - 조상-자손 사이의 대립은 건너뛴다. 수렴하지 않으면 원래 줄을 쓴다.
   - **숨은 갈래**(allow_branch 로 가려진 중점과 그 아래)와 보이는 중점 사이의 대립은 맞추지 않는다.
     (이베리아의 이샤믈라 루트처럼 숨은 갈래가 길면 평소에 보이는 결말들이 다섯 줄씩 끌려 내려갔다.)
2. 모든 `tu_*.txt` 를 다시 배치하고 continuous_focus_position 을 다시 맞췄다. 결과: 줄이 다른 대립 쌍 52 → 0
   (숨은 갈래와의 대립 15쌍은 그대로 둔다).
3. 시라쿠사: 루트 안 **모든** 중점에 allow_branch 를 달았다 (예전에는 루트 머리에만). 다섯 루트가 같은 자리에 겹쳐 있어서,
   고르지 않은 루트의 중점이 하나라도 보이면 겹쳐 보이기 때문이다.

## 남은 것
- 같은 줄이지만 사이에 다른 중점이 끼어 있는 대립 쌍(갈래가 멀리 떨어진 결말들)은 붉은 선이 사이의 중점 뒤로 지나간다.
  갈래 순서를 바꿔야 줄일 수 있어 이번에는 손대지 않았다.
- 게임에서 겹쳐 보이는 곳이 남아 있으면 나라와 중점 이름(또는 스크린샷)을 받아서 본다.
