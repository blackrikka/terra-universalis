# 사양서 70 — 시라쿠사 패밀리 소요: 군대를 주둔시켜 진압

> 2026-11-10. 요청: 스페인 내전 전에 군대를 주에 배치해 통제도를 올리는 것처럼, 패밀리를 굴복시키기 전에는
> 주기적으로 주에 군대를 배치해 진압해야 하는 이벤트. 생성기 `tools/focusgen/content/sir.py` (패밀리 소요 구역).

## 흐름
1. 굴복하지 않은 경쟁 패밀리가 하나라도 있으면 (집권 패밀리 제외) **4달마다** 소요가 난다. 첫 중점 '늑대의 땅' 뒤부터.
   - 어느 패밀리인지는 무작위 (영향력 50 이상인 패밀리는 확률 2배).
2. 이벤트 `tu_sir_ev.60~62` "<패밀리> 패밀리의 소요" → '패밀리' 디시전 탭에 미션 **"소요 진압: 주 N"** 이 뜬다.
   - 주는 시라쿠사가 가진 본토 11개 주 중 무작위. 미션에 마우스를 올리면 지도에서 그 주가 강조된다.
3. **30일 안에 그 주에 사단 2개** (그 패밀리 영향력이 50 이상이면 **3개**)를 주둔시키면 진압. 이미 주둔해 있으면 바로 진압된다.

| 결과 | 효과 |
|---|---|
| 진압 | 그 패밀리 영향력 -10, 육군 경험치 +10, 안정도 +1% |
| 실패 (30일 경과) | 그 패밀리 영향력 +10, 안정도 -3%, 120일 동안 '패밀리가 장악한 거리' (건설 속도 -5%, 안정도 -3%, 정치력 -5%) |

4. 경쟁 패밀리를 모두 굴복시키면 소요는 더 일어나지 않는다.

## 구현 메모
- 주 번호는 생성할 때 `history/states` 에서 owner = SIR 인 주를 읽는다 (11개 미션 `TU_SIR_unrest_<주>`). 지도를 다시 만들면 sir.py 도 다시 돌린다.
- 조건은 `divisions_in_state = { state = <번호> size > N }` (숫자 주 번호라 확실히 동작하는 형태).
- 한 번에 하나만: 깃발 `TU_SIR_unrest_active`. 타이머 변수 `TU_SIR_unrest_timer` (매달 +1).
- **사람이 하는 시라쿠사에만** 일어난다 (`is_ai = no`). AI 는 군대를 일부러 주둔시키지 않아 계속 실패하기 때문.
- content_lib 의 디시전에 `highlight` (지도에서 강조할 주) 인자를 추가했다.
- 숫자: sir.py 의 `UNREST_EVERY, UNREST_DAYS, UNREST_DIVS, UNREST_DIVS_BIG = 4, 30, 2, 3`.
