# 사양서 23 — 용의 시대 판도, 캐릭터, 결말 지도자 교체, 국호 변경

> 작성·구현: 2026-11-04. 사용자 요구: (1) 염국 내전 현황판 (2) 중점에 따라 국호가 바뀌는 루트 (예: 카즈델 제국 재건 선언)
> (3) "테레시스의 옥좌" 같은 중점은 실제로 지도자를 바꾸기 (4) 나라마다 지도자·참모·장군 캐릭터.

## 1. 용의 시대 판도 (`tools/guigen/build_panels.py` 의 dragon_war)
- 새 디시전 분류 "용의 시대 판도": 염국과 12형제 세력 모두에게, 염국이 용의 시대(TU_YAN_age_of_dragons)일 때 보인다.
- 형제 세력마다 국호 · 지도자 · 상태(없음 / 해방 / 복속 / 교전 중 / 독립, 색 칸). 분류 안에 '전황 보고' 디시전(정치력 +15).

## 2. 캐릭터 (`tools/chargen/data.py` → `build_characters.py`)
- 13개국(cast): 일반 "○○ 지도자" 대신 시작 지도자 + 결말 지도자 + 정치 참모 + 참모장/이론가 + 장군. 기존 대국(카즈델·우르수스·빅토리아·용문·로도스·레유니온)은 보강.
- 115명. 원작 인물(믈리나르·마거릿·마리아 니어, 조피아, 사리아, 사일런스, 페데리코, 모스티마, 엑시아, 에벤홀츠, 울피아누스, 스카디, 글래디아,
  아이린, 카넬리안, 이프리트, 라비니아, 텍사스, 라플란드, 실버애쉬, 프라마닉스, 클리프하트, 사가, 로고스, 머드락, W 등) + 직함 인물.
- 참모 특성 15개는 테라 전용으로 정의 (`common/country_leader/tu_advisor_traits.txt`): 재정가, 아츠 학자, 원석 사업가, 첩보 수장,
  광석병 전문의, 외교관, 용병 중개인, 심판관, 민중의 기사, 기사단장, 수호대장, 병참의 달인, 훈련 교관, 전술 이론가, 아츠 전술가.
- 시작 영입은 `tools/mapgen/char_history/<TAG>.txt` (build_countries 가 붙인다). countries.json 의 `cast: true` = 일반 지도자를 만들지 않음
  (국가 선택 화면의 주요국 구분은 그대로 custom_characters).
- 카즈델: 시작 지도자는 군사위원회. 테레시스는 "테레시스의 옥좌" 중점에서 즉위.

## 3. 결말 지도자 교체 · 국호 변경 (`tools/focusgen/focus_hooks.py`, merge_focus 가 넣는다)
- 결말·즉위 중점 52개 훅: recruit_character + promote_character (이념 지정), set_cosmetic_tag.
- 국호 키 `TU_<TAG>_<키>` (이념별 이름·DEF·ADJ 로컬라이제이션, 깃발은 원래 깃발 복사).
- 예: 카즈델 제국 재건 선언 → "카즈델 제국" / 테레시스의 옥좌 → 테레시스 즉위 / 용병 왕국 선언 → W 즉위 + "카즈델 용병 왕국" /
  육왕의 옥좌 → 육왕 평의회 + "육왕의 카즈델" / 카시미어 기사의 나라 → 믈리나르 니어 + "카시미어 기사왕국" /
  이베리아 왕관의 부활 → 국왕 + "이베리아 왕국" / 우르수스 민주당 집권 → 민주당 대표 + "우르수스 공화국" 등.

## 4. PC에서 확인
- 결말 중점을 찍으면 지도자 초상·이름과 국호가 바뀌는지 (promote_character 이념이 집권당과 맞아야 한다).
- 참모 특성 아이콘(sprite 번호)이 이상하면 알려 주기. 초상화가 없는 인물은 게임이 일반 초상화를 고른다.
