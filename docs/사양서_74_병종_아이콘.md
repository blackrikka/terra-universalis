# 사양서 74 — 병종 아이콘: 명일방주 세부 분류 아이콘

> 2026-11-10. 요청: 세부 분류 아이콘을 명일방주 위키에서 가져와 게임에 쓸 수 있게 가공.

## 원본 (`reference/branch_icons/`)
- Arknights Terra Wiki (arknights.wiki.gg) 의 Class 문서에 있는 그림 80개: 포지션 8개 (`_<포지션>.png`) + 세부 분류 72개.
- 흰 아이콘, 투명 배경, 약 60~70px. 포지션별 폴더, 파일 이름은 세부 분류의 영문 (예: `vanguard/charger.png`).
- 사용자가 준 포지션 아이콘 8개 (`reference/class_icons/`, 약 28px)와 같은 그림이며 위키 쪽이 더 크다.

## 병종 -> 아이콘 (`tools/unit_names.py` 의 UNITS 를 따른다)
돌격수(기병), 척후병(차량화), 기수(기계화), 에이전트(정찰), 전술가(기동 정찰), 드레드노트(보병), 소드마스터(산악),
프로텍터·저거너트·포트리스(경·중·중전차), 포격사수(포병 계열), 명사수(대공 계열), 코어 캐스터(대전차 계열),
스플래시 캐스터(아츠 캐스터), 블래스트 캐스터(아츠 로켓), 멀티 타겟 메딕(야전 병원), 음유시인(통신), 기능공(정비),
처형자(공수), 매복자(헌병), 함정술사(공병), 상인(군수).

## 게임용 가공 (`python -I tools/unit_icons.py`)
게임은 병종마다 스프라이트 세 개를 쓴다: `GFX_unit_<병종>_icon_medium` (사단 편성 화면, 2프레임),
`_icon_medium_white` (지도 카운터, 2프레임), `_icon_small` (글 속 아이콘).
크기와 프레임 배치가 바닐라와 같아야 화면에서 어긋나지 않으므로, 도구는 바닐라 견본 세 개에서 크기·프레임별 색을 읽어 같은 모양으로 만든다.

## 바닐라 견본 (`reference/vanilla_icons/`, 사용자가 올림)
| 파일 | 크기 | 프레임 |
|---|---|---|
| unit_infantry_icon.dds (사단 편성 화면) | 152x42 | 2 x 76x42 |
| onmap_unit_infantry_icon.dds (지도 카운터) | 60x12 | 2 x 30x12 |
| unit_infantry_icon_small.dds (글 속 아이콘) | 60x12 | 2 x 30x12 |

세 그림 모두 **왼쪽 프레임 = 그림 아이콘 (바닐라는 철모), 오른쪽 프레임 = NATO 기호 (밝은 네모에 X)** 이다.
플레이어가 게임 설정에서 고른 쪽이 보인다.

## 만든 것
- 왼쪽: 흰 세부 분류 아이콘에 어두운 테두리. 바닐라 철모가 차지한 칸보다 1.3배 크게 (가는 선이라 작으면 안 보인다).
- 오른쪽: 바닐라 NATO 네모를 그대로 쓰되 X 를 지우고 (줄마다 가장 밝은 점으로 채움) 그 안에 검은 아이콘.
- 병종 29개 x 스프라이트 3개 = 87개 정의 (`interface/tu_unit_icons.gfx`, 모두 noOfFrames = 2),
  그림은 세부 분류 22종 x 3 = 66개 (`gfx/interface/tu_units/<세부 분류>_{medium,white,small}.tga`).
- unit_roles.py 가 아츠 캐스터에 빌려 주던 대전차 아이콘 정의(`interface/tu_units.gfx`)는 지웠다. 이제 스플래시 캐스터 아이콘을 쓴다.
- 해병(marine)은 배정이 없어 바닐라 아이콘 그대로.

## 게임에서 확인할 것
- 사단 편성 화면·지도 카운터·툴팁 글 속 아이콘이 어긋나지 않는지, 설정의 NATO 기호 표시를 켜고 끌 때 둘 다 보이는지.
- 작은 그림(높이 12px)은 선이 뭉개진다. 알아보기 어려운 세부 분류가 있으면 그 병종만 포지션 아이콘으로 바꿀 수 있다.
