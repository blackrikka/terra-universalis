# 사양서 40 — 등대 손상 단계와 복원 공사

> 작성·구현: Opus 5.5 · 2026-11-05 (`tools/focusgen/content/ibe.py`). 사양서 31의 손상 미션을 대신한다.

## 1. 고친 문제
- 손상 여부가 지도와 탭에 보이지 않았다.
- `등대가 무너진다` 90일 미션의 타이머가 처음으로 돌아가 다시 시작되는 일이 플레이 중에 나타났다.
  - 스크립트에는 손상된 등대의 미션을 다시 켜는 경로가 없다. 매달 손상 굴림은 손상 깃발이 없는 등대만 고르고, 깃발을 지우는 곳은 보수·토벌·시간 만료뿐이다.
  - 재현 시험은 하지 못했으므로 대상 지정 미션의 엔진 동작이 원인이라고 **추정**한다. 그래서 미션을 없애고 주 변수로 직접 센다.
- 정치력을 쓰면 등대가 바로 세워졌고, 손상 뒤 대응 기회가 한 단계뿐이었다.

## 2. 손상 진행
`손상 1단계 → 45일 → 손상 2단계 → 45일 → 붕괴` (`LH_STAGE_DAYS`)

- 주 깃발: `TU_IBE_lh_damaged`(손상), `TU_IBE_lh_severe`(2단계)
- 주 변수: `TU_IBE_lh_days`(다음 악화까지 남은 일수)
- `on_daily_IBE`의 `TU_IBE_lighthouse_daily`가 하루에 1씩 줄인다. 보수 중이거나 소유·통제를 잃은 주는 멈춘다.
- 1단계가 끝나면 이벤트 `tu_ibe_ev.53`, 2단계가 끝나면 붕괴(`tu_ibe_ev.51`, 등대 -1, 위협 +5)가 일어난다.
- 보수 완료와 토벌은 단계에 상관없이 손상을 모두 없앤다.
- 손상된 등대는 두 단계 모두 바다의 위협을 막지 못한다.

## 3. 표시
- 손상된 등대마다 표시 전용 디시전 `TU_IBE_lh_stage1`, `TU_IBE_lh_stage2`가 지도와 탭에 뜬다. 이름에 단계와 남은 일수가 나온다.
- 손상된 등대에는 위협 구간 표시를 띄우지 않는다.
- 보수 중에는 단계 표시 대신 보수 디시전이 보인다.

## 4. 복원 공사
`TU_IBE_restore_lighthouse`는 정치력 50과 함께 60일 동안 민간 공장 2개를 쓴다 (`LH_RESTORE_DAYS`). 공사가 끝날 때 그 주를 계속 가지고 있으면 등대 +1, 위협 -5, 기반시설 +1을 얻는다. 복원 사이 120일은 그대로다.
