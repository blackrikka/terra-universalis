# 사양서 37 — 바다 전략 지역 끊김으로 인한 로딩 크래시 수정

> 작성·구현: Opus 5.5 · 2026-11-05

## 1. 증상과 원인
- `f12b26d`(사양서 33 헥스 해안선)부터 일반 모드에서 로딩 중 강제 종료된다. 종료 코드는 `0xC0000409`이고 크래시 덤프는 남지 않는다. `game.log`는 `Loaded N provinces.`에서 끝난다.
- 해안을 칸에 맞추면서 만과 내해의 입구가 막혀 바다 전략 지역 9개가 여러 조각으로 끊어졌다.
- `hoi4.exe -debug`로 켜면 죽지 않고 `error.log`의 `MAP_ERROR`에 `Naval strategic region ... is fractioned!`이 찍힌다. 지도 크래시를 찾을 때 먼저 볼 것.
- 같은 커밋에서 1픽셀 프로빈스도 5개 생겼다(`798`, `4765`, `8435`, `8474`, `9032`). 이것만 고치면 크래시는 그대로다.

## 2. 고친 것
새 도구 `tools/mapgen/seal_sea_pockets.py`를 `hex_coast.py` 뒤, `fix_exclaves.py` 앞에 돌린다. 고칠 것이 없으면 아무것도 하지 않는다.

1. 16픽셀보다 작은 프로빈스를 같은 종류의 이웃 픽셀로 키운다. 이때 쪼개진 프로빈스의 조각은 맞닿은 프로빈스로 넘긴다.
2. 다른 바다와 닿은 조각(프로빈스 13개)은 가장 많이 닿은 바다 지역으로 옮긴다.
3. 어떤 바다와도 닿지 않은 조각 14개(프로빈스 45개)는 호수로 바꾸고 가장 가까운 호수 전략 지역으로 옮긴다.
4. `definition.csv`, `terrain.bmp`, `unitstacks.txt`, coastal 플래그, `buildings.txt`를 함께 고친다.
   - 해안 건물·dockyard가 가리키던 바다가 호수가 되면 프로빈스에 다른 바다가 있을 때 그쪽으로 돌린다.
   - 해안을 잃은 프로빈스의 해안 건물 위치는 지운다.
   - 해안을 잃은 dockyard는 같은 주의 해안으로 옮기고, 해안이 없는 주면 지운다.

클라리사이드(지역 171)는 지역 전체가 한 덩어리인 내해라서 끊긴 것이 아니다. 바다로 그대로 둔다.

## 3. 결과
| 항목 | 전 | 후 |
|---|---|---|
| 바다 프로빈스 | 5675 | 5630 |
| 호수 프로빈스 | 106 | 151 |
| 전략 지역 | 221 | 221 |
| 가장 작은 프로빈스 | 1픽셀 | 16픽셀 |

고립된 바다 조각에 닿아 있던 해안 프로빈스 일부는 해안을 잃었다. 호수가 된 곳은 항구로 쓸 수 없다. 해협의 Through로 쓰이던 프로빈스는 없다.

등대 해안 요새 목록(`TU_IBE_lh_fort_measure`)은 바뀌지 않는다. `content/ibe.py`를 다시 돌려도 효과 파일이 같다.

## 4. 검사 추가
`validate_map.py` 규칙 6에 두 항목을 넣었다.
- 바다 전략 지역은 한 덩어리여야 한다.
- 프로빈스는 9픽셀 이상이어야 한다 (게임은 8픽셀 이하에 경고를 낸다).
