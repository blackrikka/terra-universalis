## 수정 항목

### A. 초상화 (`portraits/tu_portraits.txt`, mapgen 또는 build_countries에서 생성)
- 바닐라 `portraits/00_portraits.txt`의 `continent = { name = europe ... }` 블록과 `portraits/998_scientist_portraits.txt`의 europe 블록을 읽는다.
- 이 둘을 합쳐 `continent = { name = terra ... }` 하나로 만든다 (army, navy, political, operative, scientist 등 하위 블록 전부).
- 텍스트 복사로 처리하고, GFX 이름은 그대로 쓴다.

### B. 이름 (`common/names/tu_names.txt`, build_countries)
- countries.json의 태그마다 male.names, female.names, surnames, callsigns를 ASCII 임시 이름으로 각 20개 이상 넣는다. 형식은 바닐라 `common/names/00_names.txt`와 같다.
- countries.json에 선택 필드 `names`가 있으면 그 값을 쓴다.

### C. 국가 지도자 (build_countries)
- `common/characters/<TAG>.txt`:
```
characters = {
	<TAG>_leader = {
		name = <TAG>_leader
		portraits = { civilian = { large = "GFX_Portrait_Europe_Generic_1" } }
		country_leader = { ideology = despotism expire = "1200.1.1.1" id = -1 }
	}
}
```
- history/countries 파일에 `recruit_character = <TAG>_leader`를 추가한다.
- 로컬라이제이션 `<TAG>_leader` 키를 한국어("<name_ko> 지도자")와 영어("<name_en> Leader")로 추가한다.
- validate: 이 GFX 이름이 바닐라 `interface/*.gfx`에 실제로 정의돼 있는지 검사한다 (대소문자 무시).

### D. AI 지역 (mapgen)
- descriptor 2곳에 `replace_path="common/ai_areas"`, `replace_path="common/ai_faction_theaters"`를 추가한다.
- `common/ai_areas/tu_areas.txt`: `areas = { terra = { continents = { terra } } }`
- `common/ai_faction_theaters/tu_theaters.txt`: 바닐라 `_documentation.md` 형식으로 theater 하나를 만든다. `TU_theater_terra`, name = TU_theater_terra, ai_will_do = { base = 1 }, regions = 모든 **육지** 전략 지역 id. 첫 번째 지역은 가장 큰 육지 전략 지역으로 한다. 로컬라이제이션 키도 추가한다.

### E. 8bit BMP 헤더
- terrain/rivers/cities/trees.bmp를 저장한 뒤, 헤더의 biClrUsed(오프셋 46)와 biClrImportant(오프셋 50)를 0으로 패치한다. 팔레트는 256색 그대로 유지한다.
- validate: 4개 파일 모두 이 두 필드가 0이고 팔레트가 바닐라와 같은지 검사한다.

### F. 프로빈스 경계 상자 제한 (mapgen)
- 모든 프로빈스는 경계 상자 폭 < W/9, 높이 < H/9를 지킨다.
- 위반한 프로빈스는 씨앗을 2개로 다시 뽑아 같은 영역 안에서 BFS로 다시 나눈다. 위반이 없어질 때까지 반복한다 (소형 합병과 X-교차 처리보다 먼저).
- validate: 같은 조건을 검사한다.
