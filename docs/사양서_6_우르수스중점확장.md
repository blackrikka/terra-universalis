## 0. 공통 규칙

- 5단계 사양서(`docs/사양서_5단계_1차주요국.md`) 0장의 함정 목록을 모두 지킨다: `country_exists = TAG`, 숫자 주 스코프(event_target 금지), 아이디어 `picture`에 `GFX_idea_` 접두사 금지, 중점 `icon`은 바닐라 전체 GFX 이름, 기간 효과는 `days_remove`, 한국어 파일을 PowerShell로 왕복 금지, 게임 실행 금지.
- 모든 효과·트리거·모디파이어·GFX·트레잇·이념 이름은 **바닐라에 실제로 있는 것만** (G:\SteamLibrary\steamapps\common\Hearts of Iron IV 를 grep해서 확인). DLC 전용 기능(MIO, 특수 프로젝트, 정부 망명, 첩보망 등) 금지.
- 다른 나라 대상 효과는 반드시 `country_exists` 조건으로 감싼다. 전쟁 목표는 태그 기반(`create_wargoal = { type = annex_everything target = KZD }` 등 바닐라에 있는 wargoal 타입), 영토 요구는 `TAG = { every_owned_state = { ROOT = { add_state_claim = PREV } } }` 같은 태그 기반 패턴. 숫자 주 id는 체르노보그 41, 우르수스 수도 58만 쓴다.
- 중점 비용: 일반 10(=70일), 갈래 시작점 5, 핵심 대형 중점 15. 각 중점에 `ai_will_do = { base = 1 }` 이상.
- 한 줄(y)에서 x 간격 ≥ 2 (린트 C3). **배정받은 x 범위 밖에 놓지 말 것.**
- 로컬라이제이션: 중점마다 `<id>`와 `<id>_desc` 를 한국어·영어 둘 다. 아이디어·캐릭터 키도 동일.
- 바닐라 국가 이념: 황제파·구귀족파는 neutrality 하위(despotism/oligarchism 등), 군부는 fascism, 개혁파는 democratic으로 전환 가능(`set_politics`, `add_popularity`). 이념 이름이 지구식으로 보이는 것은 이번 범위 밖.

## 1. 조립 방식 (조각 파일 → 합치기)

- 각 에이전트는 **조각 파일**에 중점 블록만 쓴다: `tools/focusgen/urs/<part>.txt` (focus_tree 머리말 없이, 각 블록은 탭 1개 들여쓰기의 `focus = { ... }`).
- 모든 중점은 **절대 좌표**(`x`, `y`)만 쓰고 `relative_position_id`는 쓰지 않는다.
- 합치기 도구 `tools/focusgen/merge_urs.py` (U0가 작성):
  - `python -I tools\focusgen\merge_urs.py` : `tools/focusgen/urs/_header.txt`(focus_tree 머리말) + 모든 조각(파일명 순) + 닫는 괄호를 이어 `terra_universalis/common/national_focus/tu_urs.txt` 생성.
  - `python -I tools\focusgen\merge_urs.py --check <part>` : 파일을 쓰지 않고 검사만 — 괄호 균형, ASCII, 중점 id 중복(모든 조각 대상), prerequisite·mutually_exclusive가 가리키는 id가 어느 조각에든 존재, x가 해당 part의 배정 범위 안, 같은 조각 안의 좌표 충돌(같은 y에서 |dx|<2), 모든 중점에 한·영 로컬라이제이션 키(`<id>`, `<id>_desc`) 존재.
  - 배정 범위는 merge_urs.py 안의 표(`PART_BANDS`)에 둔다.
