# 사양서 38 — 이베리아: 아비살 사냥꾼 지도자를 이벤트로 고르기

> 작성·구현: Opus 5.5 · 2026-11-05
> 사용자 요구: "어비셜 헌터스랑 만나고 스카디를 앞세우다 말고 이벤트로 누구를 지도자로 할지 결정하는 이벤트가 나왔으면 좋겠어"

## 1. 바뀐 흐름
- 중점 "스카디를 앞세우다"를 **"사냥꾼의 지도자"**로 바꿨다.
  - id `TU_IBE_hunter_skadi`는 그대로 둔다. 다른 결말과의 상호 배타, 이샤믈라 조건이 이 id를 쓴다.
  - 보상: 사냥꾼의 이베리아 국민정신, 육군 경험치 50, 그리고 이벤트 `tu_ibe_ev.42`.
  - 중점 훅이 스카디를 바로 지도자로 세우던 것은 지웠다 (`tools/chargen/data.py`).
- 이벤트 `tu_ibe_ev.42` "누가 이베리아를 이끄는가": 고른 사람이 지도자(전제정)가 되고 깃발 `TU_IBE_leader_<id>`가 선다.

| 선택지 | 보너스 | 지도자 특성 |
|---|---|---|
| 스카디: 가장 강한 사냥꾼이 앞에 선다 | 육군 경험치 +25, 전쟁 지지 +5% | 아비살 사냥꾼 (공격 +10%, 조직력 +5%, 전쟁 지지 +10%) |
| 글래디아: 사냥꾼들의 대장이 지휘한다 | 정치력 +75, 안정도 +3% | 사냥꾼의 대장 (조직력 +8%, 계획 속도 +10%, 정치력 +5%) — 새 특성 |
| 스펙터: 말 없는 칼날이 길을 연다 | 육군 경험치 +50 | 말 없는 칼날 (공격 +8%, 사기 +8%, 안정도 -3%) — 새 특성 |
| 울피아누스: 돌아온 옛 대장이 해안을 지킨다 | 바다의 위협 -15, 안정도 +3% | 옛 대장의 귀환 (방어 +10%, 안정도 +5%, 전쟁 지지 +5%) — 새 특성 |

- 글래디아·스펙터·울피아누스에게 지도자 역할을 더했다. 원래의 참모·장군 역할은 그대로다.

## 2. 이샤믈라 숨은 루트
- 조건에 **이벤트에서 스카디를 골랐음**(`TU_IBE_leader_skadi`)을 더했다.
  - 나머지 조건은 그대로다: 스카디가 지금 지도자, 등대 0개, 등대가 무너진 적 있음.
  - 다른 사냥꾼을 고르면 "노랫소리" 이벤트가 뜨지 않는다.

## 3. 확인
- build_characters, content/ibe, merge_focus(IBE) 통과. tu_lint errors=0.
- PC에서 확인할 것:
  - 이벤트 선택지 4개가 보이는지
  - 고른 사람이 지도자가 되고 특성이 붙는지
