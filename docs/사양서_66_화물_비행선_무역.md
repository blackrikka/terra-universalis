# 사양서 66 — 화물 비행선 무역 (원래 무역 화면 사용)

> 2026-11-07. 사양서 64 의 '항공 수입' 디시전을 대체한다. 생성기: `python -I tools/air_trade.py`

## 왜
HOI4 엔진은 바다 건너 무역을 호송선(convoy)으로만 나른다. 이 모드는 해군·조선소를 막아서 모든 나라의 호송선이 0척이었고,
그래서 바다 건너 나라와는 무역 화면에서 무역이 되지 않았다.

## 바꾼 것
1. 호송선 장비 이름을 **화물 비행선**으로 바꿨다 (`localisation/*/replace/tu_cargo_l_*.yml`, 키 convoy / convoy_1).
2. 시작 화물 비행선 (`tools/mapgen/tiers.py` -> history): S 60, A 40, B 25, C 10척.
3. 디시전 '화물 비행선 개조' (분류 '항공 화물', 모든 나라): 수송 비행선 5대 -> 화물 비행선 10척, 정치력 10, 30일마다.
   AI 는 화물 비행선이 40척 이하일 때 쓴다.
4. 사양서 64 의 자원별 '항공 수입' 디시전 6개는 지웠다. 모든 나라가 수송 비행선 기술을 가지고 시작하는 것은 그대로다.

## 게임에서 확인할 것
- 무역 화면에서 바다 건너 나라와 무역이 되는지, 화물 비행선 수가 무역에 쓰이는지.
- 화면 곳곳의 '호송선' 글자 중 바뀌지 않은 것 (바닐라 화면 문자열 키). 보이면 알려 주면 추가한다.
- 화물은 지도상 바다 지역을 지나간다 (해군이 없어 습격받지 않는다).
