# 사양서 80 — 빅토리아 리메이크 (왕관 없는 제국의 분열)

## 개요
1막: 론디니움 사변(카즈델 군사위원회가 수도 점거) → 2막: 사변 뒤 5대 세력의 패권 재편.
도구: `tools/mapgen/vic_start.py`(시작 상태), `tools/vic_dukes.py`(공작 의회·파편), `tools/focusgen/vic_acts.py`(1막·2막 중점), `tools/vic_projects.py`(특수 프로젝트). 모두 다시 돌려도 같다.

## 1. 시작 상태
- 론디니움(주 117)은 카즈델(KZD) 소유 (인구 80만, 공장 줄임, 빅토리아 core 유지). 빅토리아 수도는 글래스고(주 946, 공군기지 1).
- 직접 `tools/mapgen/terra/capital_overrides.json` 에 `{"VIC": 946}`.

## 2. 8대 공작 의회 (`tools/vic_dukes.py`)
- 8공작(캐스터·웰링턴·윈더미어·고도딘·노르망디·애버콘·스태퍼드·파이프) 각각 충성도/영향력 변수, 영지(주 8개씩).
- 세력: 귀족=캐스터+애버콘, 왕당=노르망디+파이프, 타라=웰링턴+윈더미어, 개혁=스태퍼드+고도딘.
- 충성도 40 미만: 영지 몫만큼 공장 효율 하락, 안정도 감소, 불만 이벤트. 라이벌 관계(영합): 밀어주면 라이벌 충성도·영향력 하락.
- 웰링턴 육상전함 사단·윈더미어 전선 돌파군 편제는 충성도 40 미만이면 월간 효과가 `set_division_template_lock` 으로 잠그고, 40 이상이면 푼다. 소집 디시전도 같은 조건.
- 현황판 GUI(`TU_VIC_dukes_status_ui`, `TU_VIC_shard_status_ui`).

## 3. 파편(The Shard) 카운트다운
- 론디니움을 되찾지 못하면 월 +5%, 600일 미션. 자구군 지원(-8%, +48일)·로도스 침투조(-16%)·시설 파괴(-24%) 디시전으로 늦춘다.
- 100% (타임아웃): 재앙 국민정신(조직력 -50% 등), 플래그 `TU_VIC_shard_fired`, 카즈델 강탈 루트 개방.

## 4. 1막 '공석인 옥좌와 붉은 안개' (중점 17개, `p0_act1.txt`)
뿌리 → 의회의 긴급 소집(붉은 안개 국민정신) → 공작군 동원령 / 자구군 비밀 접촉 / 웰링턴 회유 (택일, 각 후속 3개) → 론디니움 포위망 → 파편 저지 작전(영유권·전쟁목표) → 사변의 종결.
- 사변의 종결: 론디니움을 되찾았거나 파편이 발동했을 때만. 이벤트 `tu_vic_ev.41`: 세력 영향력이 80 이상인 세력의 루트를 고르거나 "가장 큰 세력을 따른다". 파편이 발동했으면 카즈델 강탈만.
- 별도 곁가지: 글래스고 거점 확보, 왕실 근위대 유산 (왕당 영향력).

## 5. 2막 5루트 (사용자 확정, `allow_branch` 플래그)
| 루트 | 플래그 | 핵심 지도자 |
|---|---|---|
| A. 아슬란의 새벽 | `TU_VIC_route_asl` | 비나 빅토리아 (시즈) — 모범군 해금 |
| B. 철혈의 대공 의회 | `TU_VIC_route_duk` | 캐스터 공작 |
| C. 자줏빛 불꽃 (타라) | `TU_VIC_route_drc` | 에블라나 / 웰링턴 (히든: 리드 — 웰링턴 충성도 80 이상일 때 즉위 중점에서 대신 즉위) |
| D. 자구군 혁명 (신규) | `TU_VIC_route_par` | 클로비시아 / 파이스트 (지휘관) |
| E. 살카즈의 용광로 | `TU_VIC_route_kzd` | 테레시스 / 고해신부 — 파편이 발동했을 때만. 강탈 조약(카즈델 보호국)→징발→저항→파편 해체→독립 봉기 |
※ 히든 지도자 리드의 조건(웰링턴 충성도 80+)과 E 루트의 개방 조건(파편 발동)은 구현 시 정한 값이다.

## 6. 특수 프로젝트 (임시, 디시전 기반)
원본 게임의 special_projects 파일이 없어 디시전(정치력+기간)으로 대체. 끝나면 편제 해금 + 사단 지급.
- 스팀 나이트 재건 (240일) → `TU_VIC_steam_heavy` 20폭
- 고속 육상전함 Dreadnought (300일, 웰링턴 충성도 60+ 또는 산업 헌장) → `TU_VIC_dreadnought` 30폭
- 모범군 창설 (180일, 아슬란 루트 `TU_VIC_exemplars_unlocked`) → `TU_VIC_exemplars` 20폭

## 7. 미검증 (게임에서 확인 필요)
`set_division_template_lock` 월간 반복, `add_days_mission_timeout`, 음수 `add_equipment_to_stockpile`, 이벤트 `tu_vic_ev.41` 옵션 조건 노출, 블록 배치(1막 모양)의 화면 겹침, 카즈델 강탈 루트의 `puppet`/`end_puppet`.
