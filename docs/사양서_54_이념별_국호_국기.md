# 사양서 54 — 이념별 국호·국기·정당 이름, 쉐이 분파 국기

> 작성·구현: Opus 5.5 · 2026-11-06
> 사용자 보고: "카시미어가 왜 카자흐스탄이 된거야? 볼리바르, 콜롬비아 국기가 명일방주 국기가 아니야. 내전 중 염국들도 국기를 적용해줘. 라이타니엔·사르곤·라테라노도 국기 적용 안 되어 있더라"

## 1. 원인
- HOI4는 나라 이름·국기를 찾을 때 `<태그>_<집권 이념>`을 먼저 찾는다 (예: `KAZ_democratic`, `gfx/flags/KAZ_democratic.tga`).
- 모드는 기본(`KAZ`)과 비동맹(`KAZ_neutrality`)만 만들었다.
- 사양서 50에서 시작 이념이 비동맹에서 바뀌자, 바닐라 태그와 겹치는 나라는 바닐라의 이념별 이름·국기가 나왔다.
  - KAZ: 카자흐스탄, COL: 콜롬비아, BOL: 볼리비아, LAT: 라트비아.
- 쉐이 분파 12개국은 문양 그림이 없어서, 단순 도형으로 만든 국기를 쓰고 있었다.

## 2. 고친 것 (`tools/mapgen/build_countries.py`)
- **이념별 국기**: 모든 나라에 `<태그>`와 `_neutrality`·`_democratic`·`_fascism`·`_communism`·`_imperial_house`·`_sui` 국기를 같은 그림으로 쓴다 (큰·중간·작은 3종).
- **이념별 국호**: 같은 7종 접미사마다 이름·`_DEF`·`_ADJ`를 쓴다. 염국의 황제일가·쉐이 이름은 이념 현지화 파일에서 이쪽으로 옮겼다 (같은 값).
- **정당 이름**: 모든 나라(염국 제외)에 이념별 정당 이름을 쓴다.

| 이념 | 정당 이름 |
|---|---|
| 비동맹 | <나라> 집권층 |
| 민주 | <나라> 의회파 |
| 파시즘 | <나라> 국가주의파 |
| 공산 | <나라> 혁명파 |
| 황제일가 | <나라> 황실파 |
| 쉐이 | <나라> 쉐이파 |

  - 염국은 원래 쓰던 정당 이름(조정 관료 등)을 그대로 쓴다.
- **쉐이 분파 국기**: `countries.json`의 `flag_emblem: "YAN"`으로 분파 12개국이 염국 문양을 빌려, 각 분파 색 바탕에 얹는다.
- **형제를 고른 염국의 외형 국기** (`TU_YAN_FAC_<형제>`): 그 형제 분파 국기와 같다. 깨어난 쉐이(`TU_YAN_FAC_SUI`)는 짙은 보라 바탕이다.

## 3. 확인
- 예: `KAZ_democratic` = "카시미어", `COL_democratic_party` = "컬럼비아 의회파".
- 국기 파일 669개 갱신. 엠블럼 국기 32개, 도형 국기 1개(무주지).
- tu_lint errors=0, validate_map 지도 규칙 통과.
- PC에서 확인할 것:
  - 국가 선택·외교 화면의 국호·국기
  - 정당 이름
  - 쉐이 내전 분파 국기
