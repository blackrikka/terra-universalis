## 3. 원본 설계 검토 — 구현 방식 결정

### 3.1 그대로 구현 가능한 항목
- 자원 6종 치환 (석유→오리지늄 등): 로컬라이제이션과 아이콘만 교체하고 내부 키는 바닐라를 유지해 AI·장비 호환을 보존
- 오프맵 공장(RIIC): `add_offsite_building`
- RIIC·기업 의회·12 패밀리 GUI: `scripted_gui` + 변수
- 무제한 의용군: `send_volunteers_tension`, `send_volunteer_size` 모디파이어
- 헤드헌팅(정예 소대 스폰): `create_unit` + 고경험치 전용 사단 템플릿
- 시라쿠사 장군 암살: 타겟 디시전 + 커맨드 파워 소모 + 캐릭터 제거
- 아미야↔닥터 / 쌍둥이 여황제 세력 균형: BoP(`common/bop`) — **기본 게임에서 동작하는지 0단계에서 검증**

### 3.2 설계 보완이 필요한 항목 (제안)
| 원본 설계 | 문제 | 제안 |
|---|---|---|
| "프로빈스 1칸" 정박지 | HOI4 소유 단위는 주(State)임 | 프로빈스 1개짜리 **정박지 주(Anchor State)**를 지도에 미리 8~12개 배치 |
| 육상함 도약 = 수도 이동 | 수도는 보유한 주에만 둘 수 있음 | 도약 시 목표 정박지 주를 로도스로 `transfer_state` → 수도 이전 → 기존 정박지는 원주인에게 반환 |
| 점령지 즉시 반환 | 이벤트 처리 필요 | `on_state_control_changed` 온액션에서 동맹 또는 원소유국으로 자동 이양 |
| "자금" (PMC, 헤드헌팅, 작전) | HOI4에는 돈이 없음 | **용문폐(LMD)** 변수 화폐를 추가하고 GUI 상단에 표시. 수입원은 무역소·용병 계약·무기 밀매 |
| 오리지늄 "연료" 소모 | 석유와 연료는 다른 시스템임 | 도약 비용은 연료(fuel) 직접 차감, 또는 오리지늄 자원 보유량 조건으로 처리 |
| 이동도시 | 지도상 이동 불가 | 정박지 메커니즘을 재사용 (도시국가 수도 이전 디시전) + "이동도시" 주 모디파이어 |
| 시본 위기 "1943년경" | 테라 연도와 맞지 않음 | 시작일을 **1097년**(테라력)으로 두고, 위기는 "시작 후 약 7년" 상대 시점에 발동 |
| 지부 = 첩보망 100% | 첩보망은 La Résistance 기능 | DLC가 있으면 첩보망 유지, 없으면 해당국 정보 모디파이어로 대체 |

### 3.3 클래스→병종
- 1차는 바닐라 서브유닛의 **이름·아이콘만 교체**합니다 (예: 기갑 대대 → 디펜더 중대).
- 아츠 캐스터 같은 고유 대대는 3단계 이후 **새 서브유닛**으로 추가합니다.

**MVP = 0~4단계 + 5단계의 우르수스/리유니온·용문.** 여기까지 끝나면 "로도스 아일랜드로 체르노보그~용문 사태를 플레이하는" 버전이 완성되고, 이후 단계는 이 위에 국가를 추가하는 방식입니다.

## 5. 지도 제작 방식 (1단계 상세)

1. **참고 지도 확보:** 테라 공식/위키 지도를 `reference\`에 두고 트레이싱 용도로만 사용합니다.
2. **마스크 작성 (Opus):** 육지/바다, 국가 영역, 지형(사막·설원·정글·산악) 마스크 PNG를 만듭니다.
3. **자동 생성 (Haiku, Python):** 영역별 푸아송 샘플링과 보로노이로 프로빈스를 나누고, 다음 파일을 생성합니다.
   - `provinces.bmp`, `definition.csv`, `heightmap.bmp`, `terrain.bmp`, `rivers.bmp`, `trees.bmp`, `world_normal.bmp`
   - `history/states/*.txt`, `strategicregions`, `supplyareas`, `adjacencies.csv`, `railways.txt`, `supply_nodes.txt`, `buildings.txt`, `unitstacks.txt`
4. **검증 (Opus):** 크기(가로·세로 256 배수), 색 중복, 프로빈스 연결성, 해안·항구 일관성을 정적 검사한 뒤 게임 로그로 확인합니다.

지도 해상도는 4096×2048을 기준으로 잡습니다(바닐라는 5632×2048).

## 7. 확정 사항 (2026-10-31)

1. **지도:** 테라 커스텀 지도
2. **1차 범위:** MVP (로도스 + 우르수스/리유니온 + 용문) 먼저 → **2026-10-31 변경: 로도스 아일랜드 + 우르수스 + 카즈델 3국 먼저** (나머지 국가는 껍데기, 상세: `docs/사양서_2단계_3국.md`)
3. **언어:** 한국어 + 영어 동시. 모든 로컬라이제이션 키는 `l_korean`과 `l_english`에 함께 작성하고, 린트 도구가 한쪽 누락을 오류로 처리
4. **시작 연도:** 테라력 1097년

5. **지도 범위:** 대륙 전체 (북쪽 미지 영역·인피 빙원, 남단까지 포함)
6. **영토:** 원작 영토(참고 지도의 육각형 범위) + 무주지 황무지. 황무지 대부분은 통행 불가로 두고, 일부만 지나다닐 수 있는 황무지 회랑으로 만들어 국지전 위주로 구성

참고 지도: `reference/Terra_world_map_redrawn_v.3.png` (arknights.wiki.gg 커뮤니티 제작 지도, 2756×3637, 저작권 Hypergryph). 트레이싱 전용이며 모드에는 넣지 않음.

### 1단계 지도 설계 메모 (Opus)
- 지도 크기는 **3072×4096**(세로형, 원본 비율 0.76에 맞춤, 256 배수)으로 한다. 세로형 HOI4 지도는 흔치 않으므로, 작은 테스트 지도(512×768)로 파이프라인과 게임 로드를 먼저 검증한 뒤 크게 만든다.
- HOI4는 소유국이 없는 육지 주를 허용하지 않는다. 그래서 통행 불가 황무지 주도 가장 가까운 국가에 소유를 걸어 두고, `impassable`로 처리해 실제 게임에는 영향이 없게 한다.
- 지나다닐 수 있는 황무지 회랑의 소유 방식(인접국 귀속 또는 별도 처리)은 사양서에서 정한다.
- 미지 영역과 인피 빙원 북부는 통행 불가 지역, 이베리아 앞바다 남쪽은 바다(에기르)로 둔다.
