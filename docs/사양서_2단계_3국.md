### 에이전트 간 연결 규약

1. **이름 있는 주 (A가 생성):** A는 `common/scripted_effects/tu_generated_states.txt`에 `TU_init_named_states` 효과를 만든다. 이 효과는 각 이름 있는 주를 `save_global_event_target_as = TU_STATE_<이름>`으로 저장한다. A의 `tu_generated_on_actions.txt`는 `on_startup`에서 이 효과를 호출한다. B·C는 주 id를 하드코딩하지 않고 `event_target:TU_STATE_<이름>`을 쓴다.
   - 이름 목록: `urs_capital`, `chernobog`, `kzd_capital`, `rho_start`, 그리고 정박지 10개 `anchor_<이름>` (아래 A.4)
2. **정박지 효과 (A가 생성, B가 사용):** 정박지마다 다음을 만든다.
   - 효과 `TU_anchor_<이름>_relocate_rho`: 이 정박지를 RHO에 이양하고, RHO 수도를 여기로 옮기고, RHO가 가진 **다른** 정박지는 각자의 원주인(host)에게 돌려준다.
   - 트리거 `TU_anchor_<이름>_available`: 이 정박지를 RHO가 갖고 있지 않고, host 국가가 존재하며, host가 RHO와 전쟁 중이 아니고, 현재 소유자가 host일 것.
3. **국가 히스토리 추가분:** build_countries는 `tools/mapgen/country_history/<TAG>.txt`가 있으면 그 내용을 생성되는 `history/countries/<TAG> - <name>.txt` 끝에 그대로 덧붙인다. B·C는 OOB, 아이디어, 지도자 임명, BoP 초기값, 정치를 이 파일에 쓴다.
4. **커스텀 캐릭터:** countries.json에서 `"custom_characters": true`인 태그(RHO, URS, KZD)는 build_countries가 `common/characters/<TAG>.txt`와 `recruit_character` 줄을 만들지 않는다. B·C가 직접 쓴다.
5. **월간 처리:** 각 에이전트는 자기 `common/on_actions/tu_<tag>_on_actions.txt`에서 `on_monthly` 안에 `if = { limit = { tag = <TAG> } ... }`를 쓴다 (on_actions 파일은 서로 병합된다).
6. **국가 시작 효과:** B는 `TU_RHO_startup`, C는 `TU_URS_startup`/`TU_KZD_startup`을 각자 자기 `on_actions` 파일의 `on_startup`에서 호출한다.

## A. 테라 지도 + 국가 껍데기 (에이전트 A)

1a 생성기(mapgen.py, build_countries.py, validate_map.py)를 **재사용**한다. 테스트 지도용 파일은 `tools/mapgen/test/`에 그대로 둔다.

### A.1 좌표계
- 참고 지도: `reference/Terra_world_map_redrawn_v.3.png` (2756×3637).
- 아래 좌표는 모두 **"소좌표"**다: 참고 지도를 1000×1320으로 줄였을 때의 좌표. 참고 지도 px = 소좌표 × 2.756.
- 게임 지도 3072×4096: 참고 지도를 s = 3072/2756 = 1.11466배로 키우면 높이가 4054가 되므로, 위아래에 바다를 21px씩 채운다. 게임 x = 소좌표x × 2.756 × s, 게임 y(행) = 소좌표y × 2.756 × s + 21.

### A.2 육지·바다 마스크 (`tools/mapgen/terra/extract_masks.py`)
참고 지도 원본 해상도에서 처리한 뒤, 마지막에 게임 해상도로 최근접 리샘플한다.

1. RGB를 int로 읽는다. sea_raw = `((b-r>12) & (lum<120)) | (|r-65|<12 & |g-80|<12 & |b-81|<12)` (lum = (r+g+b)/3). 그다음 binary_opening(반복 2).
2. 강제 바다 사각형 (소좌표, 범례·글씨 제거): (550,1075)-(595,1125), (605,1200)-(955,1275)
3. 테두리에 닿는 sea 성분 = **바다**. 나머지는 육지다.
4. 내륙 물 성분 가운데 아래 **호수 씨앗(소좌표)**을 포함하는 것만 **호수**로 둔다. 나머지 내륙 물(국가 육각형, 글씨 상자)은 육지로 돌린다.
   - 씨앗: 클라리사이드 내해 (430,780), 로살 호수 (395,465), (520,435), 인피 빙원 호수 (250,320), (380,345), (450,315), (540,295), (480,355), 북동 (570,175), 남서 만 (145,865), (265,985)
5. 64px 미만 조각은 정리한다 (1a의 마스크 정리와 같음).

### A.4 특수 구역
- **통행 불가 고정 구역** (국가 영역보다 우선하지는 않음):

### A.5 지형 (참고 지도 색, 가우시안 σ=12px로 흐린 뒤 분류)
- lum > 205 이고 채도 < 0.12 → snow_plains (소좌표 y < 520일 때만. 그 아래는 plains)
- g > r+5 이고 g > b → forest. 단, 소좌표 y > 690이면 jungle
- r > g+25 이고 r > b+50 → desert
- 그 밖 → plains
- 크제라그 산맥 다각형 (330,590)(375,590)(372,700)(335,700) 안의 육지 → mountain
- 통행 불가 지역은 A.4의 terrain을 우선한다.

### A.6 프로빈스·주 크기 (게임 px²)
- 국가 영역: prov_size 900, state_size 6
- 통행 가능 황무지: prov_size 2500, state_size 6
- 통행 불가: prov_size 12000, state_size 8
- 바다: prov_size 20000 (경계 상자 W/9×H/9 제한은 그대로 적용)

### A.7 생성기 확장
- `mapgen.py`가 1a 형식 외에 **레이블 맵 입력**도 받게 한다. `extract_masks.py`가 `tools/mapgen/terra/regions.png`(지역 색) + `regions.json`(1a 형식 + `named_states` + `anchors`)을 만들고, mapgen이 이를 처리한다.
- 이름 있는 주와 정박지를 처리하고, 연결 규약 1·2의 생성 파일을 만든다.
- 성능: 12.6M px이다. BFS와 거리 변환은 numpy/scipy 벡터화나 C 구현(scipy.ndimage)을 써서 **전체 파이프라인을 10분 안에** 끝낸다.
- `tools/mapgen/terra/countries.json`: 18개국. 색은 참고 지도의 국가 육각형 색을 참고해 서로 구별되게 정한다. RHO/URS/KZD는 `custom_characters: true`.
- 껍데기 국가 정치: neutrality 100.
- 깃발: 단색이 아니라, 국가 색 바탕 + 흰색/검은색 가로 띠 1개 + 태그 첫 글자 없이 단순 도형(원/마름모/십자 중 태그 해시로 고름)으로 만든다. 공식 로고는 따라 그리지 않는다.
- 실행 스크립트 `tools/mapgen/terra/build_terra.py`: 마스크 추출 → mapgen → build_countries → validate를 한 번에 돌린다.

### A.8 검증
- validate_map 전 항목 + 신규 항목: 이름 있는 주와 정박지가 정확히 1-프로빈스 주인지, 정박지 효과·트리거 파일이 10개분인지, 모든 국가에 통행 가능한 주가 1개 이상 있는지.
- `tools/mapgen/out/preview_*.png`에 프로빈스, 국가 소유(국가 색), 지형 미리보기를 각각 3072×4096의 1/4 크기로 저장한다.

## B. 로도스 아일랜드 (에이전트 B)

### B.1 국가 히스토리 (`tools/mapgen/country_history/RHO.txt`)
- `set_politics = { ruling_party = neutrality ... elections_allowed = no }`, popularities neutrality 100
- `recruit_character` = TU_RHO_amiya (지도자), TU_RHO_doctor, TU_RHO_kaltsit
- ideas: `TU_RHO_landship`, `TU_RHO_pharma_company`
- `oob = "RHO_1097"`, `add_political_power = 100`
- `set_variable = { TU_lmd = 500 }`, RIIC 레벨 변수 5개는 0
- `set_power_balance = { id = TU_RHO_bop set_default = yes }`

### B.2 캐릭터 (`common/characters/RHO.txt`)
- TU_RHO_amiya: country_leader (neutrality 하위 이념 중 바닐라에 있는 것, 예: despotism는 피할 것 — `neutrality`의 하위 이념 목록을 바닐라 `common/ideologies`에서 확인해 가장 온건한 것)
- TU_RHO_doctor: advisor slot = high_command (또는 theorist)
- TU_RHO_kaltsit: advisor slot = political_advisor
- 초상화는 바닐라 generic GFX (존재 확인).
- 로컬라이제이션: 아미야/Amiya, 닥터/Doctor, 켈시/Kal'tsit

### B.3 아이디어 (`common/ideas/tu_rho_ideas.txt`)
- TU_RHO_landship (육상함 본함): send_volunteers_tension = -1, send_volunteer_size = 4, send_volunteer_divisions_required = -1, conscription_factor −0.5
- TU_RHO_pharma_company (제약회사): political_power_gain +0.25, stability_factor +0.1
- TU_RHO_relocated (도약 직후, 30일 타이머로 제거): industrial_capacity_factory −0.5

### B.4 LMD (용문폐)
- 국가 변수 `TU_lmd`. 매월: +50 + 무역소 레벨 × 30 + 활성 PMC 계약 수 × 40
- 모든 RHO 디시전 카테고리 설명에 현재 LMD와 월 수입을 표시한다 (scripted localisation 또는 `[?TU_lmd]`)

### B.5 디시전 (`common/decisions/tu_rho_decisions.txt`, 카테고리 `common/decisions/categories/tu_rho_categories.txt`)
카테고리 3개는 모두 `allowed = { original_tag = RHO }`다.

1. **TU_RHO_landship_category (육상함 운항)** — 정박지마다 `TU_RHO_relocate_<이름>` 디시전
   - 조건: `TU_anchor_<이름>_available = yes`
   - 비용: PP 50, 연료 1000 이상 보유 시 연료 −1000 (`has_fuel` / `add_fuel`, 문서로 확인. 없으면 연료 비용 생략)
   - 효과: `TU_anchor_<이름>_relocate_rho = yes` + TU_RHO_relocated 30일
