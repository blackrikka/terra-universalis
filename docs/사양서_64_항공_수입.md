# 사양서 64 — 항공 수입 (수송 비행선 무역)

> 2026-11-07. 바다(해군·호송선)를 못 쓰므로 해외 무역이 막혀 있다. 공군으로 수입하는 방법을 만든다.
> 생성기: `python -I tools/air_trade.py`

## 디시전 분류 '항공 수입' (모든 나라)
자원마다 대상 디시전 하나: "오리지늄 항공 수입: <나라>" 등 6개. 대상은 그 자원을 파는 나라 (resources.py 의 산지, 오리론은 모든 나라).

| 항목 | 값 |
|---|---|
| 조건 | 수송 비행선 10대 이상 보유, 대상과 전쟁 중이 아님 |
| 비용 | 정치력 25 |
| 기간 | 180일 |
| 받는 것 | 수도 주에 그 자원 +8 (계약이 끝나면 되돌린다) |
| 내는 것 | 민간 공장 1개 (실제 무역 값과 같다: 자원 8 = 민간 공장 1), 수송 비행선 10대 투입 |
| 끝나면 | 수송 비행선 8대 귀환 (2대는 운항 손실) |
| 파는 나라 | 정치력 +15 |

- 대상 나라가 다르면 같은 자원이라도 계약을 여러 개 동시에 맺을 수 있다 (수송기만 있으면).
- 모든 나라가 시작부터 '수송 비행선' 기술(early_transport_plane)을 가진다 (`tools/mapgen/tiers.py` BASIC).
  수송 비행선은 직접 생산해야 한다.
- AI 는 수송 비행선이 30대 이상일 때만 쓴다.

## 함께 고친 것
- `tools/mapgen/resources.py`: 다시 돌릴 때마다 자원 블록 앞에 빈 줄이 하나씩 늘던 문제.

## 게임에서 확인할 것
- 계약 중 수도의 자원이 늘고, 생산 화면에서 민간 공장 1개가 '디시전'에 쓰이는지.
- 수송 비행선이 빠졌다가 돌아오는지 (`add_equipment_to_stockpile` 음수).
