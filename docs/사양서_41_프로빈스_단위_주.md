# 사양서 41 — 프로빈스 하나 = 주 하나

> 작성·구현: Opus 5.5 · 2026-11-05
> 사용자 요구: "여러 프로빈스가 하나의 주를 이루는데, 각 프로빈스 하나가 하나의 주가 되게 했으면 좋겠어"

## 1. 결과
| 항목 | 이전 | 이후 |
|---|---|---|
| 주 | 621 | 1,205 |
| 나눈 주 | — | 통행 가능한 주 151개 → 새 주 584개 (번호 622~1205) |
| 통행 불가 황야(WLD) 주 | 그대로 | 그대로 (들어갈 수 없는 땅 3,531 프로빈스) |

- 통행 가능한 육지 프로빈스 812개가 모두 프로빈스 1개짜리 주다. 바닐라(약 1,000개)와 비슷한 규모다.
- 손으로 쓴 참조가 깨지지 않도록 **원래 주 번호는 그 주의 중심 프로빈스(승점 프로빈스)에 남겼다.**
  - 수도·체르노보그·이름 있는 주·정박지는 원래 프로빈스 1개짜리라 바뀌지 않았다 (validate 24번 고정 id 통과).

## 2. 주 내용 (`tools/mapgen/split_states.py`)
- 원래 번호의 주: 범주·건물(수도 공장 포함)·승점 그대로. 인력은 프로빈스 수로 나눈 몫.
- 새 주:
  - 범주 `tu_hex` (건설 슬롯 1, `common/state_category/tu_hex.txt`)
  - 소유국·코어·인프라는 원래 주와 같고, 인력은 나눈 몫.
  - 모두 town(슬롯 4)으로 두면 건설 슬롯이 몇 배로 불어나 공장 수가 크게 늘어나므로 슬롯 1로 정했다.
- `map/buildings.txt`:
  - 프로빈스 단위 건물 위치는 주 번호만 고친다.
  - 나뉜 주의 주 단위 건물 위치(공장·비행장 등)와 조선소 위치는 주마다 다시 만든다.
- `out/state_index.json` 갱신.
- `out/split_states.json`: 원래 주 → 나뉜 주 목록. 손으로 쓴 참조를 넓힐 때 쓴다.

## 3. 함께 고친 것
- 손으로 쓴 주 참조:
  - 리유니온의 우르수스 클레임 디시전 2개: 주 7개 → 나뉜 주 전부 (클레임 22개).
  - 염국 철도망 디시전: 수도 주 64 인프라 +1 → 수도권 8개 주 전부.
  - 그 밖의 참조(체르노보그, 수도, 염국 시작 사단 배치)는 원래 프로빈스 1개짜리 주거나 중심 프로빈스로 충분해서 그대로 뒀다.
- 쉐이 내전 분할: 형제 분파가 "씨앗 주 + 이웃 주 1번 확장"에서 **이웃 주 5번 확장**으로 바뀌었다.
  - 분파마다 약 6 프로빈스로, 예전 땅 비율과 비슷하다.
- 다시 생성: 철도·요새 효과(`rail_effects`), 체급별 공장·사단(`tiers`, 사단 209개 그대로), 이베리아 등대(`content/ibe`, 해안 주마다), 국가 파일(`build_countries`).
- `validate_map.py`: `tu_hex` 범주 인프라 규칙, 건설 슬롯 1.
