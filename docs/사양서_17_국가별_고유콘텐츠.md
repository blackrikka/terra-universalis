# 사양서 17 — 국가별 고유 콘텐츠 (중간 규모, 장치 중심)

> 작성·구현: Opus 5.5 · 2026-11-02
> 사용자 요구: 전부 이름만 다른 공용 중점 같다. 각 국가의 컨셉에 맞는 중점·디시전·이벤트를 염국·우르수스 정도로.
> 결정: 나라마다 고유 장치 1~2개 + 중점 약 120~150개, 디시전 20~30개, 이벤트 15~20개. 원작 비중 순서로 하나씩 완성해 적용.
> 순서: 카시미어 → 컬럼비아 → 라테라노 → 시라쿠사 → 사르곤 → 이베리아 → 라이타니엔 → 쉐라그 → 극동 → 미노스 → 림 빌리튼 → 사미 → 볼리바르.

## 1. 틀 (`tools/focusgen/content_lib.py`)
- 나라마다 `tools/focusgen/content/<태그>.py`에 데이터를 쓰고 `Country.write()`로 중점 조각·국민정신·디시전·이벤트·세력 균형·scripted effect·로컬라이제이션·시작 상태(country_history)를 만든다.
- 중점 보상은 직접 쓴 효과 + 이름 테마 보상(사양서 16). 장치 효과(세력 균형·변수·깃발·이벤트)는 직접 쓴다.
- 세력 균형 단계마다 깃발을 세울 수 있다 (켜질 때 set, 꺼질 때 clr). 중점·디시전은 이 깃발로 조건을 건다 (세력 균형 값을 직접 묻는 조건은 쓰지 않음).
- `minor_trees.py`는 content 파일이 있는 나라를 건너뛴다.
- 실행: `python -I tools/focusgen/content/<태그>.py` → `python -I tools/focusgen/merge_focus.py --tag <태그>` → (시작 상태가 바뀌면) build_countries.

## 2. 카시미어 (`content/kaz.py`) — 중점 122, 국민정신 19, 디시전 20, 이벤트 16
- **세력 균형 "상업 연합회 대 기사의 명예"** (시작 -0.35, 연합회 쪽). 연합회 쪽: 건설 속도·정치력, 높으면 안정도·전쟁 지지 감소. 기사 쪽: 조직력·전쟁 지지·공격. 2단계 이상이면 깃발 `TU_KAZ_union_strong` / `TU_KAZ_knights_strong`.
- **기사 명성** `TU_KAZ_fame` (0~100, 시작 10): 메이저·기사 중점·디시전으로 오른다. 정예 중점·디시전 조건 (챔피언 기사단 50, 전설의 기사들 80, 무광 기사단 40, 유목 기사 계약 20).
- **카시미어 메이저**: 중점 "메이저의 부활" 뒤 디시전 "메이저 개최"(1년에 한 번) → 개막(기업 후원 / 기사의 명예) → 준결승(감염자 출전 허용 / 실격 / 승부 조작 조사) → 결승(우승자 무작위: 기업 기사·떠돌이 기사·명문 가문·감염자 기사 — 감염자는 출전을 허용했을 때만). 정례화하면 명성이 더 오른다.
- **기사 계약** 디시전: 유목 기사단·기업 기사(기병 사단 생성), 용병 고용, 기사 해외 파견(정치력), 용병 무기 조달.
- **정치 결말 셋** (서로 배타): 주주의 나라(연합회 2단계 이상) / 기사의 나라(기사 2단계 이상) / 모두를 위한 기사도(감염자 우승자 또는 명성 60 이상).
- 시작 국민정신: 연합회의 손아귀, 저무는 기사도 (중점으로 바뀜).
- 그 밖 갈래: 기사단 군사(기병·기갑·포병·공군), 국방과 용병(대우르수스 전쟁 계획 → 전쟁 명분 디시전), 경제(건설), 외교(라이타니엔 교류, 중립 / 반우르수스 연대 → 카시미어 연맹 창설·초청).
- 무작위 이벤트 3개 (기업 기사 스캔들, 유목 기사단의 방문, 무광 기사의 귀환).

## 3. 컬럼비아 (`content/col.py`) — 중점 122, 국민정신 16, 디시전 18, 이벤트 15
- **라인 생명 연구 프로젝트**: 과학 수치 `TU_COL_science` (0~200, 시작 10). "라인 생명과의 협약" 뒤 디시전으로 프로젝트를 시작하면 정해진 날짜(90~240일) 뒤 결과가 나온다 (`days_remove` + `remove_effect`).
  - 원석 동력 연구, 생체 공학, 통신·레이더, 신형 장갑 합금 (언제나) / 기상 제어 실험, 항공우주 연구 (과학 40) / 하늘 너머 (과학 100 + 천공 프로젝트 준비 중점).
- **대통령 선거**: 게임 시작 1년 뒤 첫 선거(on_startup 예약), 그 뒤 4년마다. 산업·국방·과학 공약 중 하나 → 행정부 국민정신 교체. 2년 뒤 중간 선거.
- **볼리바르 개입**: 무기 판매 → 친컬럼비아 파벌 지원 → 개입(괴뢰 전쟁 목표). 자유 동맹 결성·초청.
- **정치 결말 셋** (서로 배타): 공화국 수호 / 기업 공화국(과학 40) / 개척자 연방. 시작 국민정신 "무법의 서부"는 개척지 보안관 중점으로 "개척지의 질서"가 된다.
- 무작위 이벤트: 라인 생명 실험 사고, 연구의 돌파구, 서부의 무법자들, 이동 도시의 도착.

## 4. 라테라노 (`content/lat.py`) — 중점 119, 국민정신 11, 디시전 20, 이벤트 15
- **순례자** `TU_LAT_pilgrims` (0~200, 시작 20): 매달 +2 (순례길 정비 +2, 열린 성도 +3, 전쟁 중 -3; `on_monthly`). 디시전으로 헌금(정치력)·의용대(인력)·성인 축제(전쟁 지지)·대희년으로 쓴다.
- **영향력** `TU_LAT_influence` (0~100, 시작 10): 축성 총기 수출(대상 디시전, 소총 300정)·특사·공증으로 오른다. 성약 진영 창설(30), 초청(20씩 소모, 주요국 제외).
- **타락 천사 문제**: 시작 국민정신. 명부 → 추적(안정) / 사면(→ 화해한 타락 천사) 갈래와 이벤트.
- **정치 결말 셋** (서로 배타): 교황의 신정 / 공증인 공화국 / 열린 성도(사면 뒤, 순례자 80).
- 시작 국민정신 "성도": 안정도·정치력 +, 징집 -20% (작은 성도).

## 5. 시라쿠사 (`content/sir.py`) — 중점 120, 국민정신 11, 디시전 20, 이벤트 16
- **세 패밀리 영향력** `TU_SIR_bellone/gambino/saluzzo` (시작 40/35/30, 매달 +1): 거래(영향력 +10, 법 -5, 벨로네=공장·감비노=인력·살루초=정치력) / 단속(영향력 -15, 증인 보호 뒤 -25, 법 +5). 50 이상이면 그 패밀리의 응접실 중점(협력 국민정신). 두 패밀리가 함께 60 이상이면 패밀리 전쟁 이벤트(반복).
- **법의 권위** `TU_SIR_law` (시작 20): 법원 개혁 뒤 매달 +1. 침묵을 깨다(40, 오메르타 제거), 대부 체포 작전(50).
- **늑대 군주의 유산**: 이벤트 사슬 → '늑대의 흔적 추적' 디시전 → 늑대의 징조 → 숨은 결말.
- **정치 결말 셋** (서로 배타): 패밀리 연합 정부(두 패밀리 50) / 법의 시라쿠사(법 70) / 늑대 군주의 귀환(늑대의 징조).
- 시작 국민정신: 오메르타, 패밀리의 도시들.

## 6. 사르곤 (`content/sar.py`) — 중점 120, 국민정신 11, 디시전 20, 이벤트 16
- **영주들의 충성** `TU_SAR_loyalty` (시작 40, "다투는 영주들"이 있는 동안 매달 -1): 30 미만이면 영주 반란 이벤트(반복). 영주 소집·황금 하사·영주 처벌로 올리고, 조공 요구로 내린다.
- **황금** `TU_SAR_gold` (시작 20, 조공 체계 뒤 매달 +2): 대상단 디시전(45~60일 뒤 귀환)으로 모으고, 용병·충성·도로·공장·연구에 쓴다.
- **푀엔 원정**: 90일 원정 디시전 → 결과 이벤트(유적 35% / 황금 35% / 실종 30%). 유적을 찾으면 "고대의 지식" 중점과 유적 발굴 디시전이 열린다.
- **정치 결말 셋** (서로 배타): 파디샤의 제국(충성 70) / 영주 연합(충성 40 이하) / 황금 상인 정부(황금 100).
- 시작 국민정신: 다투는 영주들, 끝없는 사막 (→ 사막의 주인).

## 7. 이베리아 (`content/ibe.py`) — 중점 120, 국민정신 9, 디시전 20, 이벤트 16
- **바다의 위협** `TU_IBE_threat` (시작 40): 매달 +2, 복원한 등대 하나마다 0.5 덜 오른다 (`on_monthly`, 임시 변수 계산). 70 이상이면 '심해의 침식' 이벤트가 반복. 해안 순찰·정화 작전·해변 방어 디시전과 중점으로 낮춘다.
- **등대** `TU_IBE_lighthouses` (0~5): '등대 복원' 디시전 (기반시설 + 위협 -5).
- **세력 균형 "심판소 대 왕관"** (시작 -0.3, 심판소 쪽). 2단계 이상이면 깃발 `TU_IBE_inquisition_strong` / `TU_IBE_crown_strong`.
- **아비살 사냥꾼**: 소문 중점 → 수소문 디시전 → 만남 이벤트 → 사냥꾼 지원 디시전.
- **정치 결말 셋** (서로 배타): 심판관의 나라(심판소 2단계) / 왕관의 부활(왕관 2단계) / 바다와의 화해(위협 20 이하 + 사냥꾼과 만남).
- 시작 국민정신: 대침묵의 상흔(정화된 해안·바다와의 화해로 제거), 바다의 공포(→ 깨어 있는 해안).

## 8. 라이타니엔 (`content/lei.py`) — 중점 120, 국민정신 11, 디시전 20, 이벤트 16
- **선제후 표** `TU_LEI_electors` (0~7, 시작 3): 설득·연회·혼인·표결로 늘고, '선제후의 이탈' 이벤트(반복)와 특권·징병으로 준다. 5 이상이면 '제국 칙령'(1년 국민정신).
- **아츠 공명** `TU_LEI_resonance` (0~100): 연주회·오페라·중점으로 쌓는다. 공명 30으로 교향곡 하나를 90일(대교향곡 뒤 180일) 건다: 전투 교향곡 / 재건 협주곡 / 치유의 노래. 90 이상이면 '아츠 폭주' 이벤트.
- **마왕의 유물** `TU_LEI_relics` (0~3): 봉인된 서고 → 120일 탐색 디시전(50%). 봉인·연구 디시전.
- **정치 결말 셋** (서로 배타): 쌍둥이 여제의 통치(선제후 5) / 선제후 연방(선제후 2 이하) / 마왕의 귀환(유물 3).
- 시작 국민정신: 쌍둥이 옥좌, 마왕의 그림자(추종자 숙청으로 제거).

## 9. 남은 확인 (PC에서)
- 세력 균형 창과 단계 이름, 메이저 이벤트 사슬, 결승 선택지(우승자에 맞는 하나만 보임).
- 기사 명성은 지금 화면에 숫자로 보이지 않는다 (툴팁 "기사 명성 +N"과 조건으로만). 필요하면 국민정신이나 디시전 분류 설명에 표시를 붙인다.
