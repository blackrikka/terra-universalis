# 사양서 17 — 국가별 고유 콘텐츠 (중간 규모, 장치 중심)

> 작성·구현: Opus 5.5 · 2026-11-02
> 사용자 요구: 전부 이름만 다른 공용 중점 같다. 각 국가의 컨셉에 맞는 중점·디시전·이벤트를 염국·우르수스 정도로.
> 결정: 나라마다 고유 장치 1~2개 + 중점 약 120~150개, 디시전 20~30개, 이벤트 15~20개. 원작 비중 순서로 하나씩 완성해 적용.
> 순서: 카시미어 → 컬럼비아 → 라테라노 → 시라쿠사 → 사르곤 → 이베리아 → 라이타니엔 → 쉐라그 → 극동 → 미노스 → 림 빌리튼 → 사미 → 볼리바르.

## 1. 틀 (`tools/focusgen/content_lib.py`)
- 나라마다 `tools/focusgen/content/<태그>.py`에 데이터를 쓰고 `Country.write()`로 중점 조각·국민정신·디시전·이벤트·세력 균형·scripted effect·로컬라이제이션·시작 상태(country_history)를 만든다.
- 중점 보상은 직접 쓴 효과 + 이름 테마 보상(사양서 16). 장치 효과(세력 균형·변수·깃발·이벤트)는 직접 쓴다.
- 세력 균형 단계마다 깃발을 세울 수 있다 (켜질 때 set, 꺼질 때 clr). 중점·디시전은 이 깃발로 조건을 건다 (세력 균형 값을 직접 묻는 조건은 쓰지 않음).
- `minor_trees.py`는 content 파일이 있는 나라를 건너뛴다.
- 실행: `python -I tools/focusgen/content/<태그>.py` → `python -I tools/focusgen/merge_focus.py --tag <태그>` → (시작 상태가 바뀌면) build_countries.

## 2. 카시미어 (`content/kaz.py`) — 중점 122, 국민정신 19, 디시전 20, 이벤트 16
- **세력 균형 "상업 연합회 대 기사의 명예"** (시작 -0.35, 연합회 쪽). 연합회 쪽: 건설 속도·정치력, 높으면 안정도·전쟁 지지 감소. 기사 쪽: 조직력·전쟁 지지·공격. 2단계 이상이면 깃발 `TU_KAZ_union_strong` / `TU_KAZ_knights_strong`.
- **기사 명성** `TU_KAZ_fame` (0~100, 시작 10): 메이저·기사 중점·디시전으로 오른다. 정예 중점·디시전 조건 (챔피언 기사단 50, 전설의 기사들 80, 무광 기사단 40, 유목 기사 계약 20).
- **카시미어 메이저**: 중점 "메이저의 부활" 뒤 디시전 "메이저 개최"(1년에 한 번) → 개막(기업 후원 / 기사의 명예) → 준결승(감염자 출전 허용 / 실격 / 승부 조작 조사) → 결승(우승자 무작위: 기업 기사·떠돌이 기사·명문 가문·감염자 기사 — 감염자는 출전을 허용했을 때만). 정례화하면 명성이 더 오른다.
- **기사 계약** 디시전: 유목 기사단·기업 기사(기병 사단 생성), 용병 고용, 기사 해외 파견(정치력), 용병 무기 조달.
- **정치 결말 셋** (서로 배타): 주주의 나라(연합회 2단계 이상) / 기사의 나라(기사 2단계 이상) / 모두를 위한 기사도(감염자 우승자 또는 명성 60 이상).
- 시작 국민정신: 연합회의 손아귀, 저무는 기사도 (중점으로 바뀜).
- 그 밖 갈래: 기사단 군사(기병·기갑·포병·공군), 국방과 용병(대우르수스 전쟁 계획 → 전쟁 명분 디시전), 경제(건설), 외교(라이타니엔 교류, 중립 / 반우르수스 연대 → 카시미어 연맹 창설·초청).
- 무작위 이벤트 3개 (기업 기사 스캔들, 유목 기사단의 방문, 무광 기사의 귀환).

## 3. 남은 확인 (PC에서)
- 세력 균형 창과 단계 이름, 메이저 이벤트 사슬, 결승 선택지(우승자에 맞는 하나만 보임).
- 기사 명성은 지금 화면에 숫자로 보이지 않는다 (툴팁 "기사 명성 +N"과 조건으로만). 필요하면 국민정신이나 디시전 분류 설명에 표시를 붙인다.
